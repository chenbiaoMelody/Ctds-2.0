## 1. 准入标准（章程 3.1.1，全部满足才可入名单）

1. 企业级合约或明确的个人使用授权条款；
2. 承诺输入数据不用于模型训练（或可关闭训练选项）；
3. 支持私有化部署，或已通过数据出境合规评估；
4. 国内可直连（无预算购买跨境网络通道）。

## 5. 切换接口预留（D-3 原则：演示优先、接口预留、平滑切换）

工具可替换性在四个层面固定下来，任何一层更换工具都不应推倒重来：

1. **状态载体层**：任务卡、规格、ADR、开发日志、追溯矩阵全部为纯文本 Markdown + git 管理。任何具备"文件读写 + git"能力的智能体可无缝接管，不锁定在任何 AI 产品上。
2. **模型层**：模型网关抽象（ADR-003）——统一 OpenAI 兼容协议 + Provider 适配器，换模型只改配置不改代码。
3. **CI 层**：质量门禁实现为独立脚本（`scripts/gates/`），只依赖"能执行命令行"的环境；未来接入任何 CI 平台（GitHub Actions/Gitee Go/自建 Jenkins）均只需调用该脚本并检查退出码。
4. **供应链层**：依赖一律经国内镜像 + 锁定文件 + 包名在官方注册表人工核验后引入（防 Slopsquatting，章程附录 F）。

## 6. 红线摘引（违反即停用工具并上报）

- 白名单外工具不接触任何项目资产（代码、PRD、规格、日志）；
- 禁止在任何工具的输入中出现真实密钥、生产数据、个人信息；
- 发现资产泄露面 → 立即停用、评估、报告安全专员并复盘（章程 9.6）。
