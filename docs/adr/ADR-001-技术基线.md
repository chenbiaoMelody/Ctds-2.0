## 1. 背景

平台为城市级数据流通基础设施（微服务 + 前端 + 连接器），含策略引擎、计量计费、国密加解密、存证、AI 中枢等模块。团队全员无编程经验，代码 100% 由 AI 编写（章程 4.1）：**技术选择的第一准则是"AI 生成质量最高、外部顾问最容易接手的主流技术"**，而非技术先进性。零预算约束：全部组件须开源免费。

## 2. 备选方案与业务影响对比表

## 3. 决策（推荐方案 A，请 PM+PO 批准）

**后端**：Java 17 LTS + Spring Boot 3.x + Spring Cloud（Nacos 注册/配置）+ Maven 多模块 monorepo + MyBatis-Plus + MySQL 8 + Redis
**前端**：Vue 3 + TypeScript + Element Plus + Vite
**质量工具链**（第一道防线，WBS 2.2）：Maven 编译 + JUnit 5 + JaCoCo 覆盖率 + Checkstyle/Spotless + PMD CPD 重复度 + ArchUnit 分层规则 + gitleaks 密钥扫描 + PIT 变异测试（核心模块）

## 4. 理由

对齐章程 4.1 三条理由的全部三条：AI 语料最充分、外部顾问最容易接手、未来引入人类工程师接手成本最低；国密与信通院案例生态贴合本项目合规主线。资源占用是方案 A 唯一短板，以"演示环境单机 16G 内存"化解（当前开发机满足）。

## 5. 备选项保留

方案 B（Go）作为"资源受限部署"场景的备选记录在案；若未来边缘侧连接器有轻量化需求，连接器 SDK（独立仓库，ADR-002）可单独选 Go，不影响平台侧决策。

## 6. 业务影响说明（给非技术读者）

- **成本**：全栈开源免费，零许可费；
- **工期**：框架成熟、AI 生成效率最高，对 22 周基线最有利；
- **风险**：开发机内存要求 ≥16G；Java 应用启动较慢，演示时需预留启动时间；
- **影响范围**：全平台所有模块；本决策批准前，任何编码工作包不得开工（依赖链见 WBS 2.1.1）。

## 7. 可替换性评估（D-3）

Java/Spring 为最主流栈，工程师与顾问市场充足，不存在单供应商锁定；各中间件（MySQL/Redis/Nacos）均有国产云托管替代，迁移路径标准（数据导出/协议兼容）。风险等级：低。
