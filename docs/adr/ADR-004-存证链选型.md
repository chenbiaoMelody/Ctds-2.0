## 1. 背景

数据流通合约、交付凭证与使用控制事件需要可信存证。约束：零预算、国密要求、上链数据不得含原文与个人信息（安全红线）。

## 2. 备选方案与业务影响对比

| 维度 | 方案 A：FISCO BCOS 自建（推荐） | 方案 B：云 BaaS（蚂蚁链/腾讯云） | 方案 C：长安链 ChainMaker 自建 |
| --- | --- | --- | --- |
| 费用 | 开源免费（单机演示零成本） | 持续云服务费 | 开源免费 |
| 国密支持 | 原生（SM2/SM3/SM4） | 支持 | 原生 |
| 社区与案例 | 国内联盟链最大社区，AI 语料最丰富 | 托管省心但锁定供应商 | 信通院背书强，社区较小 |
| 运维负担 | 单机 Docker 可跑，1 人可维护 | 无 | 单机可跑，资料较少 |
| 出证公信力 | 自建链公信力弱，需配合司法鉴定/公证通道增强 | BaaS 背书较强 | 同 A |

## 3. 决策（推荐）

1. 选型 **FISCO BCOS**（单群组单机 Docker 部署，仅存证用途）；
2. 业务代码**只依赖存证网关抽象接口**（`EvidenceGateway`：存证/核验/查询），链实现为可插拔适配器——未来换 BaaS 或长安链只改适配器；
3. **上链数据范围**：仅业务凭证的哈希摘要（SM3）+ 最小元数据（业务单据号、时间戳、操作类型、主体 DID 摘要）；**禁止上链**：任何原文、个人信息、商业密文数据、密钥材料；
4. 公信力增强路径（V1.5 评估）：司法鉴定/公证处存证通道对接，同样走网关抽象。

## 4. 理由与业务影响说明

**理由**：零预算约束直接排除有持续费用的 BaaS；FISCO BCOS 在国产联盟链中社区最大、国密原生支持、单机 Docker 即可运行，是"1 人可维护 + AI 语料最丰富"的唯一交集；自建链公信力短板以存证网关抽象预留公证/司法通道增强来补足。

- **成本**：零许可费；单机部署复用演示环境资源；
- **工期**：存证网关 + FISCO BCOS 适配器属 3.8.2 既有工作项；
- **风险**：① 自建链公信力弱——以"外部可验证的出证通道"为增强路径；② 顾问复核缺位——已列 D-2 代偿控制并在顾问立项后补复核；③ 链上数据一旦上链不可删除——以上链范围白名单严格控制，白名单外数据上链按 S0 事件处理；
- **影响范围**：存证服务（C-8.x 合约/交付存证、C-4.3 使用控制留痕）。

## 5. 可替换性评估（D-3）

网关抽象使链实现可替换（BaaS/长安链/公证通道均为适配器级变更）。风险等级：中（链上数据格式兼容性需在适配器中冻结版本）。
