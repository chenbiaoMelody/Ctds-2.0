## 1. 背景

章程 4.3 / AGENTS §3：信通院测评、互联互通相关实现一律收敛 `std-adapter`，不得散落业务代码。WBS §1.7 强依赖清单：std-adapter 骨架是"DID 互认、互联互通、测评证据"三类下游工作包的地基（G1 标准解耦）。风险手册 PR-3：标准演进导致测评返工——对策即本模块独立演进 + 契约测试隔离，业务服务对标准协议零感知。

## 3. 决策（契约正文，实现 = `std-adapter`，设计定稿 `docs/designs/WBS-2.4.8-hifi.md`）

1. **收口纪律**：全平台一切"与外部标准打交道"的代码（互联互通协议、身份互认协议、测评证据格式）只允许落在 `std-adapter`；业务服务不得绕过本模块自行对接标准协议（同"国密唯一入口"红线逻辑）；
2. **能力域清单（= 契约）**：`StdDomain` 枚举三值固定——`INTERCONNECT("interconnect","互联互通")`、`DID_INTEROP("did","跨空间身份互认")`、`EVIDENCE("evidence","测评证据")`；**新增/合并/改名域 = 本 ADR 变更 + 新任务卡**；各域稳定域码进入 API 响应，变更即契约破坏；
3. **探活契约**：基础接口 `StdDomainApi { StdDomain domain(); StdDomainStatus status(); }`——"这个标准域今天什么状态"的唯一入口，永不抛错；`StdDomainStatus(domain, implemented, message)` 为 record，紧凑构造器拒绝空域/空白文案（`IllegalArgumentException`）；三域标记子接口 `InterconnectStandardApi` / `DidInteropStandardApi` / `EvidenceStandardApi` 骨架期无新增方法；
4. **占位实现与替换规则**：每域一个 `Placeholder...Api`（纯常量返回：`implemented=false` + 定稿业务文案，无状态无副作用无配置开关——**不存在"配置一下就能用"的假象**，启用能力 = 交付新实现）；后续工作包交付真实实现时替换使用方 Bean 注册（example-service 演示接线即替换点示范），并删除对应占位类；`implemented` 恒 false 是骨架期事实，非永久约束；
5. **错误码模块位 1003**：`StdAdapterErrorCodes.NOT_IMPLEMENTED = 1003C0001`"该标准互联功能尚未开放"（C 型 → 400 默认映射）；工厂 `notImplemented(StdDomain)` 域参数 null 快速失败；**对外文案三域统一、不拼接域名/类名/实现细节**（章程 4.3 不暴露内部实现）；后续 1003 段新增码在本 ADR 登记；
6. **探活端点契约**：`GET /api/v1/std-capabilities`（example-service，只读，沿既有演示端点鉴权口径）→ 封套 `code="0"`，data 按枚举声明序（interconnect→did→evidence）输出 `{code,name,implemented,message}`；
7. **契约测试自动轨落点**：章程 G1"std-adapter 通过互联互通契约测试后申报"——测试轨道建设归 M2 测评演练工作包，代码落点 = evidence 域（本次仅预留，观察项不阻塞）。

## 4. 理由与业务影响说明

- **理由**：标准适配层先立"门牌号"，后续工作包在统一边界内填实现，避免互联互通协议知识散落到各业务服务（AI 并行开发的经典失控面）；"未开放"给出明确信号而非"找不到这个类"，调用方可提前做降级；
- **成本**：零新增外部依赖（仅 common-errorcode）；1 天工作量符合 WBS 2.4.8 预算；
- **风险**：① 域划分如与信通院规范正式文本冲突 → 走本 ADR 变更（预期演进，非返工）；② 探活端点若被误当生产接口：本端点属演示服务 example-service，生产各服务引入 std-adapter 依赖不自动暴露端点；
- **影响范围**：后续全部标准相关包（3.1.4、3.1.10、4.x、M2 演练）与标准测评申报路径；既有 2.4.x 组件零改动。

## 5. 可替换性（组件级替换路径，防锁定）

1. **实现可替换**：域实现 = 接口注入，占位类与真实实现同接口互换，使用方零改动（Bean 覆盖沿 2.4.6 KeyProvider 惯例）；
2. **规范演进隔离**：协议细节全部收口 std-adapter 内部，信通院规范改版影响面 = 本模块（对齐风险手册 PR-3）；
3. **不可替换边界（红线）**：任何服务不得绕过本模块直接实现标准协议（章程 4.3 收口义务）。
