## 1. 背景

C-6.3（PRD 行 147，P0）要求"多源适配：适配政务共享交换平台、数据库、对象存储、API 网关等"，规格行为 11~14 进一步要求：四类源全量接入、每类源由对应适配器承载、先登记后使用、凭据经 `common` 国密组件加密存储、连通性自检三类失败原因可读、先判定后取数且拒绝不触达源。

立卡实测三项事实决定了本 ADR 的关键裁决：

1. `connector-sdk` 的 `spi/` 已冻结 7 个类型（`SourceAdapter` / `SourceType` 四值 / `SourceRegistration` 凭据引用制 / `SourceCheckResult` / `SourceCheckFailureType` 三类 / `SourceReadRequest` / `SourceReadResult`），但**实现类零个**，且 `SourceRegistration` **不含明文凭据字段**（编译期阻断明文路径）；
2. `connector-service` 现有 8 表 / 21 端点 / 1010 段 11 码 / 6 权限点中**无任何 source 或 credential 的表列与端点**；
3. 交付链当前取的是 catalog 产品元数据读面，**非源端取数**（网关仅 1 条探针路由），因此"先判定后取数"的次序与触达控制在链上尚不可验证。

## 2. 决策

### 2.1 能力落位

- **适配器实现落 `connector-sdk/adapter/gov`**（随连接器分发，兑现行为 11 规则 1"适配器随连接器分发〔SDK 框架，3.6.2〕"）：`GovExchangeSourceAdapter`（`type()` = `GOV_EXCHANGE`）+ `CredentialResolver` + 标准报文模型 + 进程内模拟源；
- **平台侧编排落既有 `connector-service`增量**：迁移 `V3__create_connector_source_tables.sql`（2 表 + 1 列放宽）、**6 端点（对外 5 + 内部 1）**、+1 权限点、+2 码；
- **零新模块 / 零新第三方依赖 / 零新服务 / 零新端口 / 零网关改动 / 零门禁配置改动**；仅 +2 个**模块依赖**（`connector-sdk` / `common-crypto`，均为既有坐标）。

| 表 | 用途 | 关键约束 |
| --- | --- | --- |
| `connector_source` | 源接入登记（四类源全量） | `uk_source_no`(SR) / **`uk_connector_type_endpoint(connector_no, source_type, endpoint(128))`**（同连接器同类型同地址防重登记） / `idx_source_connector` |
| `connector_source_no_seq` | SR+6 位取号（1 行） | `UPDATE … SET next_no = LAST_INSERT_ID(next_no + 1)` |
| `connector_action_log`（既有，+1 列放宽） | 自检失败原因可机读 | `reason_code` 16 → 32 字符（`INSUFFICIENT_PERMISSION` 22 字符） |

### 2.2 凭据保护（行为 12 规则 2 硬约束）

- **三列并存**：`credential_ref`（`SC` + 32 位十六进制不透明引用，对外唯一凭据标识）+ `credential_ciphertext`（`Sm4Service.encryptText` 信封，keyRef 默认 `connector-source-credential`）+ `credential_masked`（展示 / 留痕唯一形态：≤4 全掩，否则 `****` + 末 4 位）；
- **唯一入口 = `common-crypto`**（ADR-006 / ADR-015，禁自实现密码学）；本地密钥文件或 KMS 托管二选一（组件原生覆盖），**明文永不落库、不进日志 / 异常 / 响应**；
- **fail-closed**：密钥不可用（未配密钥文件 / KMS 不可达）或密文不可解 → 503 `1010S0004`，**禁止明文降级**；
- 适配器调用期凭据经 `CredentialResolver` 解析（平台注入），明文只在方法内存活。

### 2.3 政务标准报文模拟源（Q2-A 诚实承载）

- **进程内标准报文模拟器**，仅 `mock://gov-exchange/**` 生效：`/ok` 通过、`/bad-credential` 凭据无效、`/unreachable` 网络不可达、`/forbidden` 权限不足、其余视为正常源；
- `http(s)://` 走真实 HTTP 客户端（超时来自 `ctds.connector.source.adapter-timeout`，默认 3s），但 **V1.0 未与真实政务平台联调**，报文协议为**本地约定**（真实对接属部署实施期，规格 §6-3）；
- 模拟源为**演示期正式承载形态**（沿 `MockCertificationChannel` 先例），界面与文档一律标注"模拟"，不虚称已对接真实平台。

### 2.4 自检与读取语义

- 自检 = 只读三查（连通 / 凭据 / 权限），**失败 = 200 业务结论**（`passed=false` + 三类原因枚举 + 可读文案 + `FAILURE` 留痕）；**适配器非预期异常 = 502 中性文案**（不暴露内部、不归为三类业务原因）；
- 自检**不写任何授权态**：读取前置不含"自检通过"条件（行为 13 规则 3）；
- 内部读取端点契约明写"仅使用控制判定放行后调用"：**本地前置四校验**（连接器 `REGISTERED` / 源归属 / 参数合法 / 类型有适配器），**前置拒绝时适配器零调用**；判定次序与端到端"拒绝不触达源"归 **WBS-3.6.8**；
- 未开放类型（`DATABASE` / `OBJECT_STORAGE` / `API_GATEWAY`）：**登记受理**（行为 11 验收 1）、**自检 / 读取 → 400 `1010C0011`**（3.6.6 承接，仅注册适配器即可放开，端点与服务零改动）；
- **适配器非预期异常的出站口径**（补记）：状态码 502、码位复用平台通用 `1000S9999`（S 型语义 = 系统侧不可用），文案为服务端常量「源连通性探测失败，请稍后重试」；该"码位 + 状态覆写"为本卡明列约定，**不新增 1010 段码**（零突破 Q7-A 的"+2 码"契约）；根因仅记异常类名，不记 message（防地址 / 凭据入日志）。

### 2.5 端点与码位

| # | 方法 / 路径 | 权限点 |
| --- | --- | --- |
| 1 | `POST /api/v1/connectors/{connectorNo}/sources` | `connector.source.manage` |
| 2 | `PUT /api/v1/connectors/{connectorNo}/sources/{sourceNo}` | `connector.source.manage` |
| 3 | `GET /api/v1/connectors/{connectorNo}/sources` | `connector.read` |
| 4 | `GET /api/v1/connectors/{connectorNo}/sources/{sourceNo}` | `connector.read` |
| 5 | `POST /api/v1/connectors/{connectorNo}/sources/{sourceNo}/checks` | `connector.source.manage` |
| 6 | `POST /api/v1/connectors/internal/{connectorNo}/sources/{sourceNo}/reads` | `connector.internal.read` |

1010 段 +2 码：`1010C0011`「该源类型的适配承载尚未开放」/ `1010S0004`「源凭据保护组件不可用，暂不能登记或自检」；复用 `1010C0001`（参数 / 重复登记 / 重复变更）/ `1010C0003`（防枚举同码同文）/ `1010C0004`（状态门槛）；**`1010S0003` 保持预留不启用**（零回改 ADR-028）。

**平台通用码的复用面（补记，避免与 hifi 早期表述冲突）**：`1000C0001` 承载"请求体不可解析 / 枚举值非法 / 分页越界"（Spring 解析期与 `common-pagination` 既有口径，**不改既有端点的错误码语义**）；`1000S9999` 承载适配器非预期异常的 502 面（见 §2.4）。上述两码不属 1010 段增量，不改变"1010 段 +2 码"计数。

### 2.6 与注销 / 3.6.6 / 3.6.7 / 3.6.8 的边界

- **注销不级联源**（Q8-A）：注销后源不可读取（读面校验 `REGISTERED`），源档案与留痕**保留可查**；零回改 3.6.4 注销事务；
- **3.6.6**：复用本卡登记面 / 凭据保护 / 自检编排 / 适配器注册表，只新增三类适配器实现；
- **3.6.7**：源清单与详情（含最近一次自检）已就位，控制台直接消费；
- **3.6.8**：交付链在判定放行后调内部读取端点；判定次序与"拒绝不触达源"的完整证明由其承担。

### 2.7 源地址受理规则（补记：评审循环 1 安全加固）

| 规则 | 口径 | 理由 |
| --- | --- | --- |
| scheme 按类型白名单 | `GOV_EXCHANGE` = `mock`（仅 `mock://gov-exchange/` 前缀）/ `http` / `https`；`DATABASE` = `http(s)` / `jdbc`；`OBJECT_STORAGE` = `http(s)` / `oss` / `s3`；`API_GATEWAY` = `http(s)` | 四类源均受理（行为 11 验收 1）与最小实现；不臆造 3.6.6 的原生协议 |
| 禁 URL 内嵌凭据 | 分层 URI 查 `userInfo`，不透明 URI（`jdbc:`）在 authority 段查 `@`；**查询串凭据样键**（`password` / `passwd` / `pwd` / `secret` / `token` / `credential(s)` / 各写法 `access-key` / `secret-key` / `api-key` / `private-key` / `passphrase` / `authorization` / `auth`，完整键、大小写不敏感）命中即 400 `1010C0001` | 凭据只能经 `credential` 字段落国密密文，避免地址成为明文旁路（行为 12 规则 2）；查询串与 userinfo 同构（可入库、可回显）。黑名单不完备残余由 3.6.6 适配器调用边界按源类型补强，新形态经变更流程扩充 |
| 默认拒绝内网地址 | `http(s)` 主机命中回环 / `10.` / `172.16-31.` / `192.168.` / `169.254.` / IPv6 ULA·链路本地 / 整数形态即拒绝；**字面量规范化后判定**：IPv4-mapped IPv6（`::ffff:` 后点分与十六进制两态）、前导零段按 JDK `InetAddress` 十进制语义、1~4 段 inet_aton 变体展开比对；畸形 / 不可判定 host（Java URI 层解析失败或 host 为空）一律默认拒绝（fail-closed）；`ctds.connector.source.allow-private-endpoint=false` 为默认，联调与测试显式放开 | 防 SSRF（服务端代用户发起请求），CWE-918；编码形态不改写真实连接目标，放行即绕过。校验层不做 DNS 解析（避免校验期联网与 TOCTOU），主机名解析到内网的残余由 3.6.6 调用边界实施解析级校验 |
| 留痕地址脱敏 | `source.register` / `source.amend` 的 detail 只记 `scheme://authority/path`（去查询串与片段；authority 中 userinfo 一并剥离——存量脏行留痕防护；`jdbc:` 等不透明 URI 无独立 authority → 整体记 `<redacted>`） | URL 里的 token / password 不进入 `connector_action_log` |
| 调用期复校 | 自检 / 读取在调适配器前按同一规则复校库中地址 | 存量脏数据不因"登记时放行"而在调用期绕过 |

## 3. 备选方案

| 备选 | 不采理由 |
| --- | --- |
| 新建一级模块 `connector-adapters/`（每类源一子模块） | 需新模块骨架 + 根 pom + 门禁扫描面 + 3.6.6 再复制，1 会话预算内风险高，收益在 V1.0 演示期不可见 |
| 适配器实现放 `connector-service` 内 | 适配器未随连接器分发（违行为 11-1 与 ADR-026 分发语义），3.6.6 需二次裁决 |
| 落 `std-adapter` 新增"政务交换"域 | 需 ADR-008 变更（域清单 + 1003 段扩码），且政务交换不在信通院互联互通三/四域内，扩域缺乏规范依据 |
| 独立 mock 容器 | 新增部署资产与运维面，演示需人侧额外起容器；模拟器不因独立部署更"真实" |
| 只做测试桩（`@TestConfiguration`） | 行为 11-3 与剧本政务步骤不可演示（违章程原则 4） |
| 凭据交 KMS 托管只存引用 | 需 KMS 新增"密文托管"接口，超 ADR-015 现行边界 |
| 凭据明文列 + 掩码展示 | 违反行为 12-2 硬约束与 AGENTS 原则 7 |

## 4. 理由

与规格"适配器随连接器分发"逐字一致；零新模块、零新第三方、零部署与门禁改动；凭据保护复用 `common-crypto` 既有能力（本地文件 / KMS 覆盖双形态），不自实现密码学；三类通用源落地只需注册实现（登记面与端点零改动），3.6.6 可平移复用；模拟源为规格明文认可的 V1.0 承载形态，演示与自动化测试同源。

## 5. 业务影响说明

- **四类源均可登记**：政务 / 数据库 / 对象存储 / API 网关登记即受理，签发 `SR` + 6 位编号；
- **政务源可自检、可读取**（模拟源，界面与文档如实标注"模拟"）：通过 = 业务结论成功，失败明确告诉是"网络不可达 / 凭据无效 / 权限不足"；
- **凭据只显掩码**（如 `****abcd`），加密组件不可用时宁可拒绝登记也不明文凑合；
- **未开放类型明确拒绝**（"该源类型的适配承载尚未开放"），不假装支持、不虚报通过；
- **注销后源不再可读但档案可查**（历史可追溯）；
- **诚实边界**：判定次序与"拒绝不触达源"的完整证明留 WBS-3.6.8；本卡只证明"前置拒绝时适配器零调用"。

## 7. 可替换性

- **适配器按 `SourceType` 注册可替换**：注册表按类型索引，同类型多实现启动失败（防第二实现）；新增类型只需注册实现，服务层零改动；
- **真实政务平台对接** = 替换 `GovExchangeClient` 的 HTTP 实现 + 关闭 `mock://` scheme（服务层与端点零改动，ADR-026 §9 演进路径）；
- **凭据存储**可由 KMS 托管替换（`common-crypto` 既有覆盖机制：配置 `ctds.crypto.kms.base-url` 即整体切换，业务代码零改动）；
- 回退 = 下线 6 端点 + 保留 2 表（数据不删，符合可追溯义务）；源能力整体可回退而不影响 3.6.3 / 3.6.4 的 21 个端点。

## 8. WBS-3.6.8 补记（2026-10-31）

- **内部读取作业凭证（§2.6 / DB-89 承接）**：读取请求必填 `jobRef`（≤64），服务端核验 OCCUPY 占用在册（核验顺序 = 参数 → 凭证 → 本地四校验 → 端点策略 → 适配器）；占用登记 / 释放仅 `connector-internal` 服务身份可写（admin 仅持 `internal.read`）→ **凭证不可伪造**。负向四腿（缺 jobRef / 无占用 / 已释放 / admin 直调）测试锚 T5 全绿。
- **判定次序完整证明（ADR-026 §4-1 联动）**：端到端探针链 B 实证"先判定后取数"——越界用途 `403 1008C0020`、占用清单零新增、适配器零调用；合规腿全链成功（判定 → 占用 → 属主核对 → 内部读取 → 释放 → SM4 落包 → 记录留痕）。
