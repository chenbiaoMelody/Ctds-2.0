## 2. 校验规则表（前后端逐字一致）

| 项 | 规则 | 正则 |
| --- | --- | --- |
| 手机号 | 1 开头、第二位 3~9、共 11 位 | `^1[3-9]\d{9}$` |
| 座机 | 区号 0 开头 3~4 位＋`-`＋7~8 位 | `^0\d{2,3}-\d{7,8}$` |
| 联系电话（二选一） | 手机**或**座机，其余（汉字/无连字符/位数错/带空格括号分机）拒绝 | `^(1[3-9]\d{9}|0\d{2,3}-\d{7,8})$` |
| 管理员账号 | **不变**（V1.0 既有实现），规格 V1.2 第 7 条补写：`^[A-Za-z0-9._-]{1,64}$`，必填 | 代码零改动 |
| 查询凭证比对 | 两侧 trim；信用代码统一转大写后与库值全等（lofi Q4） | — |

> 原"联系电话超长（最长 32 字符）"规则被格式规则天然覆盖（最长 13 字符），后端删除该长度检查、前端不变（现无长度规则）。

## 3. 接口契约表（新增 1 个端点，其余零改动）

| 项 | 内容 |
| --- | --- |
| 端点 | `GET /api/v1/subject/registrations/{subjectNo}/progress?uscc={统一社会信用代码}` |
| 权限 | `@RequirePermission("subject.read")`（复用既有权限点，申请人/审核员均持有；无"我的主体"关联，凭证=双要素比对） |
| 入参校验 | subjectNo 非空（复用既有 requireSubjectNo 口径）；uscc `@NotBlank` + 既有 18 位 USCC 正则（不合法 → 参数错误，不查库） |
| 成功出参 | `ProgressView { subjectNo, subjectName, subjectType, status, rejectReason }`——**仅此五字段**，无联系人/电话/证照/核验信息（规格行为 8 第 2 条最小必要）；`rejectReason` = 最近一条"转已驳回"流转备注，非驳回态为 null |
| 失败 | 编号不存在、或信用代码不匹配 → 统一 `RESOURCE_NOT_FOUND`（HTTP 语义不变）＋文案 **`未查询到匹配的申请`**；不引入新错误码（变更单 §3 零新增） |
| 留痕 | 成功→审计 SUCCESS（action `subject.progress_query`，actor/subjectNo/时间）；凭证不匹配→审计 DENIED（reason `progress_denied`）；编号不存在→仅 404 不另落 DENIED（无对象可归属，与 OwnershipGuard 口径差异在 hifi 留痕：该端点不走归属断言，走凭证断言） |
| 幂等/缓存 | 只读 GET，不加 @Idempotent；不引入缓存（最小实现） |
| 数据模型 | **零迁移**：查询复用 `findBySubjectNo`＋`findTransitions`，无新表新列 |

后端落点：`SubjectRegistrationService` 新增 `progress(subjectNo, uscc)` 方法（注册聚合查询同源，不再拆类）；`SubjectRegistrationController` 新增端点＋`ProgressView` DTO；`requireValid` 与 `RegisterRequest.contactPhone` 按 §2 规则表补电话格式。

前端落点：`api/subject.ts` 新增 `fetchRegistrationProgress(subjectNo, uscc)`＋`RegistrationProgressView` 类型；`router/index.ts` 新增路由（meta 见 §1.2）；新文件 `views/subject/ProgressQueryView.vue`；`RegisterView.vue` 两处增量。

## 4. 边界值与异常行为

| 输入 | 预期 |
| --- | --- |
| `13800001234` / `0571-87654321` / `010-12345678` / `0571-1234567`（7 位座机） | 通过 |
| `12345678901`（12 开头）/ `1380000123`（10 位）/ `057187654321`（无连字符）/ `测试电话` / `0571-87654321#8001`（分机） | 拒绝·电话格式提示 |
| 电话留空 | `联系电话不能为空`（必填口径不变） |
| 管理员账号 64 字符 / 65 字符 / 含汉字 | 通过 / 拒绝 / 拒绝（既有行为，新增用例锁定） |
| 重报（已驳回后修改信息重新注册）电话填错格式 | 与首报同规则拒绝（校验在 register 入口统一生效） |
| 查询：编号存在＋uscc 小写带空格 | trim＋归一后匹配成功 |
| 查询：编号不存在 vs 编号存在但 uscc 不符 | 响应文案一致 `未查询到匹配的申请`；仅后者落 DENIED 审计 |
| 查询：uscc 填 17 位 | 参数错误（前端必填/格式红字优先；后端 @Pattern 兜底） |
| 已入驻主体查询 | 状态徽标"已入驻"，rejectReason=null，无驳回 alert |
