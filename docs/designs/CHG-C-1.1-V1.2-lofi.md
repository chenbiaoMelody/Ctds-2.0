## 1. 改动方向（业务可读）

| # | 界面/行为 | 现状 → 目标 |
| --- | --- | --- |
| 1 | 注册页·联系电话 | 只查必填 → 填错格式（汉字、缺连字符、位数不对）当场红字提示、提交被拦；手机/座机双格式二选一 |
| 2 | 注册页·管理员账号 | 零说明 → 输入框下**常驻指引文字**（"贵单位自己的平台管理员账号名，待账号体系上线后生效；仅允许字母、数字与 . _ -"），必填不变 |
| 3 | 新页面·入驻进度查询 | 无 → 侧边栏新增"入驻进度查询"菜单：输入申请编号＋统一社会信用代码，显示主体名称/类型/当前状态；已驳回时附驳回理由；提供"前往认证页"按钮 |
| 4 | 后端 | 注册校验补电话格式（与前端同规则）；新增进度查询接口（双凭证比对，防枚举） |
