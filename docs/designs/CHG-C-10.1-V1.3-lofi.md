## §2 业务可读行为清单（改造前后对照）

| 场景 | 改造前 | 改造后 | 业务含义 |
| --- | --- | --- | --- |
| 本人读自己的资源详情 | 200 + 资源元数据 | 200 + 资源元数据（不变） | 正常读面零变化 |
| 同空间其他成员读他人资源详情 | 404 + `1007C0005` + "资源不存在或无权访问" | **400 + `1000C0003` + "资源不存在"** | 与平台统一出站口径对齐 |
| 跨空间成员读资源详情 | 404 + `1007C0005` + 同上 | **400 + `1000C0003` + "资源不存在"** | 跨空间即非属主，同码同文 |
| 任何人读不存在的资源详情 | 404 + `1007C0005` + 同上 | **400 + `1000C0003` + "资源不存在"** | 与"非属主"逐字一致（防存在性枚举） |
| 非属主读 R14 留痕 | 404 + `1007C0005` + 同上 | **400 + `1000C0003` + "资源不存在"** | 同一读面族口径统一 |
| 非属主读 R14 留痕（治理例外） | 200 | 200（不变，且不新增留痕） | 治理读面能力不受影响 |
| 写面非属主 / 写面对象不存在 / R13 / 产品面 | 403 + `1007C0006` / 404 + `1007C0005` / 404 + `1007C0005` / 404 + `1007C0005` | **全部不变** | 本卡隔离线，回归锚 T8 |
| 未认证 / 无功能权限 | 401 + `1000C0002` / 403 + `1000C0005` | **全部不变** | 鉴权前置门槛不受影响 |

**内部审计**：非属主探测 R2/R14 仍落 `DENIED_READ`（谁、何时、对象、被拒动作可查），对外仍与"不存在"同形；新行 reason_code 随新出站码记 `C0003`。

## §4 决策点全文（Q1~Q6，**已全部确认采建议口径 A**）

> 与任务卡 §二 摘要表一一对应；此处为业务影响全文。

- **Q1 改造范围含 R14**。A（建议 / 已确认）：R2 + R14 一并改造——两者同属"资源域属主读面"、同一防枚举分支；只改 R2 会在同一读面族留下第二种口径，后续大概率二次改造。B（仅 R2）不采。
- **Q2 统一文案 = "资源不存在"**。A（建议 / 已确认）：资源域语境的"对象不存在"直白表述，与平台 `NoResourceFound` 通用字面一致（`GlobalExceptionHandler:56`），且只需从现文案删去"或无权访问"。B（"记录不存在"）与审计面语境强、资源域语境弱；C（沿用旧文案）不符合 A 案统一方向。三案均须三态逐字一致。
- **Q3 DENIED_READ reason_code = `C0003`**。A（建议 / 已确认）：留痕字段定义为"拒绝码尾号"，随新出站口径；历史行不回改。B（保留 `C0005`）会与出站码不一致，不采。
- **Q4 前端零改动**。A（建议 / 已确认）：视图不按码值分支、错误原文展示；`RESOURCE_NOT_ACCESSIBLE_TIP` 当前无视图消费（仅定义 + 值守卫用例，保留不删）；已复核全仓无视图硬编码旧文案。B（同步改常量）会新增前端改动面且无消费方，不采。
- **Q5 测评面评估 = 文档评估 + 留痕**。A（建议 / 已确认）：全仓 grep + std-adapter 接口清单核对 + 交付说明写清"哪些外部行为变了、谁可能消费、是否需复测"；如发现固定预期，登记改造后复测项。B（新建测评回归脚本）超出本卡范围，不采。
- **Q6 S2-5 合约 / 交付腿不扩面**。A（建议 / 已确认）：本卡仅资源域；S2-5 复验以资源域控制腿按新口径 PASS；非资源域腿按实测如实登记，若拒绝族与 S2-3 不一致按红线 4 申报并呈报（可能另立卡），本卡不擅自扩面。B（本卡一并改造两域）初检未见空间归属承载，体量 / 风险不可控，不采。
