## 1. 接口契约表（对外出站——唯一权威口径）

**承载端点**（`DatasetController`，功能权限门槛 `@RequirePermission` 先行、不在本卡改动面）：
- **W1** `PUT /api/v1/datasets/{datasetId}`（`dataset.update`）→ `DatasetCommandService.update`（:140-178）
- **W2** `POST /api/v1/datasets/{datasetId}/cancellation`（`dataset.cancel`）→ `DatasetCommandService.cancel`（:197-217）

| 端点 | 情形 | 现状出站 | **改后出站（W1/W2 一致）** |
| --- | --- | --- | --- |
| W1/W2 | 资源不存在（`load` :146/:199 落空） | 404 + `1007C0005` + "资源不存在或无权访问" | **400 + `1000C0003` + "资源不存在"** |
| W1/W2 | 存在但非属主（`requireOwner` :147/:200，含空间管理员、含跨空间主体） | DENIED 留痕（reason `C0006`）+ 403 + `1007C0006` + "仅登记主体本人可执行该资源操作" | DENIED 留痕恰 1 行（reason **`C0003`**）+ **400 + `1000C0003` + "资源不存在"** |
| W1/W2 | 未认证 | 401（既有） | 不变 |
| W1/W2 | 无功能权限 | 403 + `1000C0005` + "无权限执行该操作"（common/auth 既有） | 不变 |
| W1/W2 | 属主 + 终态（已注销再操作） | 409 + `1007C0007` + "资源已注销，不可再变更或注销" | 不变 |
| W1/W2 | 属主 + 空变更 / 缺二次确认 | 400 参数码 | 不变 |
| W1/W2 | 属主 + 分级放宽 | `1007C0004` + DENIED 留痕 | 不变（属主路径，不可达性不受影响） |

**三态响应白名单**（防枚举断言基准）：W1/W2 对"不存在 / 非属主 / 跨空间"三态的 HTTP status、`code`、`message`、`data`（null）与错误封套结构**逐字一致**——不存在任何可区分字段。

## 2. 异常类型与 handler 路径（零 handler 配置改动）

- 写面统一拒绝构造 = `BizException(ErrorCodes.RESOURCE_NOT_FOUND, CatalogErrorCodes.DATASET_READ_NOT_FOUND_MESSAGE)`——与读面 `DatasetQueryService.readNotFound()`（:92-94）**同款构造**；
- 路径：`BizException`（非 `CatalogBizException`）→ `CatalogExceptionHandler` 仅映射 1007 段、非 1007 码 rethrow（:34-37）→ 全局 `GlobalExceptionHandler` 按 `ErrorType.CLIENT` 落 **400**；
- **`CatalogExceptionHandler` 零改动**：`MAPPED_CODES`（:26）与 403 映射（:44）保持——`1007C0005` 仍服务治理面/产品面，`1007C0006` 仍服务入驻资格门槛（:44 的 `1007C0015` 亦不动）。
