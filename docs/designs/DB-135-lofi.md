# DB-135 低保真设计：资源域写面存在性枚举通道改造（V1.0，2026-11-21）

> 任务卡 `docs/tasks/DB-135-写面存在性枚举通道改造-2026-11-21.md`；Q1~Q4 已按建议口径一次确认（Q1-A1 / Q2-A / Q3-A / Q4-A，2026-11-21）。
> 设计只从规格 V1.2 B3-R2/B3-AC2/B4-R2/B4-AC2 与 Q 裁决派生，零规格外新增。
> **确认记录（2026-11-21）**：编排师定稿确认（指示原文"确认"）——本设计与 hifi 同步转 **V1.0 = 编码契约即时生效**（V0.9 呈报历史保留）。

## 一、业务目标（一句话）

资源域**写操作**（资源变更 / 资源注销）对"不是你的资源 / 别的空间的资源 / 不存在的资源"三种情况，统一回复 **400 + 错误码 `1000C0003` + "资源不存在"**（与读面 DB-132 交付口径同一字典），消除"用 403 区分存在与不存在"的试探通道。

## 二、行为清单（改什么）

| # | 行为 | 现状 | 改后 |
| --- | --- | --- | --- |
| A1 | `PUT /api/v1/datasets/{id}`（资源变更）对**不存在**的资源 | 404 + `1007C0005` + "资源不存在或无权访问" | **400 + `1000C0003` + "资源不存在"** |
| A2 | 同端点对**存在但非属主**（含空间管理员，含跨空间主体） | DENIED 留痕（reason `C0006`）+ 403 + `1007C0006` + "仅登记主体本人可执行该资源操作" | DENIED 留痕保留（reason 改 `C0003`，Q2-A）+ **400 + `1000C0003` + "资源不存在"**（与 A1 逐字一致） |
| A3 | `POST /api/v1/datasets/{id}/cancellation`（资源注销）对上述两态 | 同 A1/A2 现状 | 同 A1/A2 改后口径（两动作同字典） |

**留痕规则不变的部分**：非属主恰好 1 条 DENIED 留痕（动作名 `DENIED_UPDATE`/`DENIED_CANCEL` 不变，仅 reason_code 尾号新行改 `C0003`）；不存在的资源**零留痕**；历史留痕行不回改。

## 三、行为清单（不改什么——隔离线）

| # | 面 | 不改理由 |
| --- | --- | --- |
| B1 | 属主本人正常变更/注销（200 成功路径） | 正向行为零涉及 |
| B2 | 已注销资源**属主本人**再操作 → 409 + `1007C0007` | 终态自环门槛在属主门槛之后，属主已知该资源（无枚举泄露） |
| B3 | 空变更请求 / 缺二次确认 → 400 参数码；分级放宽 → `1007C0004` | 字段校验族在属主门槛之后，仅属主可达，不涉枚举 |

| B5 | R13 治理读面 / 产品封装来源检查 → 404 + `1007C0005` | 共享常量 `DATASET_NOT_FOUND_OR_NO_ACCESS` 语义不变（Q3-A 不扩面；静态核查登记见 hifi §6） |

## 四、外部消费方影响（Q4-A 文档评估口径）

- **前端**：视图不按码值分支、错误文案原样展示（既有口径）；旧写面文案"仅登记主体本人可执行该资源操作"全仓前端 **grep 0 处硬编码**（2026-11-21 实证）→ **前端零改动**；
- **std-adapter**：`1007C0006` 零引用（grep 实证）→ 零影响；
- **外部联调/测评**：若外部用例固定了写面旧的"403 + `1007C0006`"或"404 + `1007C0005`"预期，需按新字典复核——测评面影响评估在编码段落盘（grep 证据 + 消费方清单 + 复测项登记）。

## 五、边界值与异常行为（业务级）

1. **三态逐字一致**：不存在 / 非属主 / 跨空间 → 状态码、错误码、文案、响应体结构完全一致（无任何可区分字段）；
2. **状态不泄露**：非属主探测**已注销**资源也得统一响应（属主门槛先于终态门槛的判定顺序保持不变）；
3. **留痕仍可审计**：试探行为内部可追溯（DENIED 留痕恰 1 行 + reason `C0003`），只是对外不泄露存在性；
4. **两动作同字典**：资源变更与资源注销的三态响应逐字相同。

## 六、体量预估

主源 ≈ 30~60 行（`DatasetCommandService` 写面专用拒绝路径 + 留痕 reason + 注释）；测试 ≈ 80~150 行；文档另计；单 PR ≤400 行，无需拆分。DB-132 实测 +106/-35 可作参照。
