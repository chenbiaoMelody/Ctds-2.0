# DB-139 低保真设计（lofi）：产品面封装来源存在性枚举通道统一

> 任务卡 `docs/tasks/DB-139-产品面封装来源存在性枚举通道统一-2026-11-22.md`；Q1~Q4 已一次确认（Q1-A1 / Q2-A / Q3-A / Q4-A，2026-11-22 编排师"Q1~Q4 确认"）。高保真见 `docs/designs/DB-139-hifi.md`。

## 1. 业务目标一句话

把产品封装（W8）对"引用的资源不存在"与"引用的资源不是你的"两种情况的提示统一为**与资源域同一句话术**（400 + `1000C0003` + "资源不存在"，DB-132 读面 / DB-135 写面同款字典），让持产品创建权限的人无法再靠"话术差异"探测某个资源编号是否真实存在。

## 2. 行为清单（改造后，业务可读）

| 编号 | 场景 | 改造前 | 改造后 |
| --- | --- | --- | --- |
| B1 | 封装时引用的资源**不存在**（无论谁操作） | 404 + `1007C0005` + "资源不存在或无权访问"，零留痕 | **400 + `1000C0003` + "资源不存在"**，零留痕（不变） |
| B2 | 封装时引用的资源**存在但不是你的**（含同空间他人、其他空间——封装无空间上下文，跨空间语义归并入非属主） | 403 + `1007C0006` + "仅登记主体本人可执行该资源操作"，资源域留痕 1 行（reason=`C0006`） | **400 + `1000C0003` + "资源不存在"**（与 B1 逐字一致），留痕行为保留：恰 1 行 DENIED_CREATE 落资源域 `dataset_action_log`，reason 改记 `C0003`（Q2-A，历史行不回改） |
| B3 | 未入驻主体封装（ADMITTED 门槛先行） | 403 + `1007C0006` + "主体未入驻或不存在，无法使用统一目录服务"（Q8-A 统一文案） | **不变**（另一语义，非本卡面） |
| B4 | 引用已注销资源 / 已解散空间资源（状态门槛） | 409 + `1007C0016` | **不变**（属主通过后才会触达，优先序不变） |
| B5 | 属主正常封装 / 幂等重放 / 名称-定价-类目校验 / 未认证 401 | — | **全部不变** |

防枚举本质代价（B1+B2 合并的代价）：封装失败时"没权限"与"不存在"对外不可区分——资源域读面（DB-132）与写面（DB-135）已同款接受并经 PO 批准，本卡为同一字典的第三处落地（产品封装引用面）。

## 3. 边界与异常行为

1. **校验链顺序不变**：认证 → 未入驻拒绝（B3）→ 载体/定价校验 → **来源检查（本卡改造面）** → 状态门槛（B4）→ 类目/幂等。本卡只换来源检查两分支的"对外话术"，不动链序——非属主对已注销资源同样得 B1 口径（不新增"状态侧信道"）。
2. **留痕语义保留**：越权封装仍是资源域动作（"谁在何时试图封装谁家的资源"要可取证——规格行为 3 AC :96 "被拒绝**且留痕**"）；只是留痕里记录的错误码尾号随出站口径改记 `C0003`；资源不存在仍零留痕（规格未要求，且留了反而多一条可探测信号）。
3. **共享常量零变化**：`1007C0005`/`1007C0006` 两码继续服务治理读面与资格门槛族（登记门槛/入驻门槛），只是**退出"封装来源检查"这一处消费**；不改常量定义、不改异常处理器映射。
4. **前端零改动预期**：封装失败提示原样展示（前端无按码分支、无旧文案专有常量——立卡段实证）。
5. **同型偏差不扩面**（Q3-A）：产品面其他 `1007C0006` 字面引用（`ProductCatalogQueryService:24` / `ProductInteractionService:22` 为注释；`ProductCommandService:218` 为上架资格门槛语义）均非"资源 id 引用型出站"，设计段核查登记、本卡零触碰。

## 4. 验收业务口径（对应任务卡验收标准②③④）

- 封装两态（B1/B2）响应**逐字一致**：HTTP 状态、错误码、提示文案、响应结构四样全部一样；
- 越权留痕仍可查（恰 1 行、reason=`C0003`、不存在零行、历史行原样）；
- B3/B4/B5 各回归锚零变化。
