## 目录规则

- 命名：`<任务卡编号>-lofi.md`（低保真，方向确认）、`<任务卡编号>-hifi.md`（高保真，定稿确认 = 编码契约）。任务卡编号沿用任务卡（如 `C-4.3`、`WBS-2.4.4`）。
- 界面类任务的原型页：`<任务卡编号>/prototype/`，入口 `index.html`，浏览器直接打开即可查看（每页可点开，含报错与空态示意）。
- 模板：`docs/templates/设计文档模板.md`（与章程附录 H 同源）。
- 确认记录：设计文件头部"确认记录"块由 PO 签署；未签署 = 未确认 = 禁止进入编码。
