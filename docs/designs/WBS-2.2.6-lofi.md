## 1. 方向概述（业务语言）

给项目装一条"出厂包装线"：每天（或每次手动触发）一条命令把整个项目**完整构建一遍**（后端 jar + 前端静态产物），**自动生成两份"材料清单"（SBOM）**——后端用了哪些第三方组件、前端用了哪些第三方组件，逐项列清（这是信通院测评与供应链安全的硬要求），并按**统一规则给每个模块算出将来的镜像名字和版本号**（镜像本身等 2.5.1 容器化时再真正打包，本任务只把"命名规则 + 计算工具"定下来）。全部结果归档到一个带时间戳的输出目录，附一份业务可读的汇总报告（每步成功/失败、耗时、产物清单、清单文件校验值）。

质量把关仍由既有门禁（`scripts/gates/run-gates.ps1`）承担，包装线**先跑门禁、全绿才继续打包**，不重复造检测，也不重复跑测试（门禁已跑过的测试，打包阶段跳过）。

## 2. 范围判定（逐项）

| # | 判定项 | 结论 | 理由 |
| --- | --- | --- | --- |
| 1 | **落地形态** | 本地脚本版：`scripts/pipeline/nightly-build.ps1`（一条命令全流程）+ `scripts/pipeline/image-tag.ps1`（镜像名计算工具） | 无 CI 平台（现状即本地门禁）；沿 2.2.2"与 CI 平台解耦"先例。定时调度、制品远程仓库推送登记 PENDING-CI，待 CI 接入时平移 |
| 2 | **SBOM 工具** | CycloneDX 双插件：后端 `org.cyclonedx:cyclonedx-maven-plugin`（官方注册表最新 2.9.3），前端 `@cyclonedx/cyclonedx-npm`（npmmirror 官方注册表 latest 6.0.1，Node ≥20.18 本机满足） | CycloneDX 是业界事实标准的 SBOM 格式（信通院/OWASP 生态广泛采纳）；两插件均 Apache-2.0、官方维护、版本锁定在仓库内可复现。备选 Syft 弃：需运行时拉取外部镜像（供应链面更大、版本不可锁定） |
| 3 | **新依赖** | 2 项（上 row），走"核验→审批→登记→锁版"流程，登记 `docs/dependencies.md` | 章程 3.5；核验记录见 hifi"依赖核验与登记"节 |
| 4 | **镜像 tag 规范** | `ctds/<模块名>:<版本>-<构建时间 yyyymmdd-hhmm>-<git 短哈希>`，示例 `ctds/example-service:2.0.0-SNAPSHOT-20260912-1430-1bfb279`；工作区有未提交改动时追加 `-dirty` 后缀 | 三段式可同时回答"哪个版本/何时构建/哪份代码"，出问题可追溯到提交；模块名清单 = Maven 8 模块 + frontend + connector-sdk（占位）。**本任务不写任何 Dockerfile、不构建镜像**（容器化是 2.5.1） |
| 5 | **规范载体** | 新建 ADR-012《制品与镜像流水线规范》（tag 命名、SBOM 范围、输出目录契约）+ `scripts/pipeline/README.md`（业务可读操作说明） | 2.5.1 容器化、2.5.2 一键部署、2.5.3 监控都要消费同一套命名与目录契约，跨任务规范沿 ADR-009/010/011 惯例固化 |
| 6 | **验证方式** | 实跑一次全流程（门禁 GREEN → 打包 → SBOM 产出 → tag 计算 → 汇总报告），人工核对三件套产物齐全 + SBOM 内容抽查（能查到已登记依赖）+ 失败即停边界实测 1 项（制造一次前端构建失败验证中止行为） | 流程编排类交付物无单测框架，验证=实测演练（与 2.2.2 门禁、2.5.2 一键部署同口径） |

## 3. 流水线阶段草图（每阶段做什么，详细行为清单见 hifi）

```
nightly-build.ps1
  N1 环境自检      java/mvn/node/npm/git 在位（docker 仅探测记录，本任务不构建镜像）
  N2 质量门禁      调用既有 run-gates.ps1，非 GREEN 即停
  N3 后端打包      mvn package -DskipTests（测试已由门禁跑过）→ 收集 jar
  N4 前端打包      npm run build → 收集 dist/
  N5 SBOM 生成     后端聚合 BOM + 前端 npm BOM → 各出 XML+JSON
  N6 镜像 tag 计算 image-tag.ps1 → tags 清单
  N7 汇总报告      每阶段结果/耗时/产物清单/SBOM sha256
输出目录：build-output/<yyyymmdd-hhmmss>/（gitignore），任一阶段失败即停、保留现场
```
