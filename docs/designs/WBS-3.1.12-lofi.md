## 1. 方向（业务可读）

C-1.2 身份链路四包（签发 `3.1.8` → 解析/验证 `3.1.9` → 跨空间互认 `3.1.10` → 管理界面 `3.1.11`）已陆续交付并验收。本包**不加任何新业务功能**，只做三件事：

1. **补缺口**：把 C-1.2 规格 5 个行为的验收标准与既有测试**逐条对账**，补齐上游评审登记的测试类遗留项（`3.1.11` §七 S4~S10、`3.1.10` §七 第 7/8 条），每条补测都要求"**删掉实现必变红**"（红锚），杜绝"假绿"；
2. **测出达标数字**：按章程硬指标实测——`did` 属**核心模块**（AGENTS.md §4）：**行覆盖 ≥80%、变异杀除率 ≥60%**；整体 **≥70%**。本包**只测量、不开门禁**（覆盖率/变异门禁接入属质量基建包 WBS-2.2.8 / DB-06 职权），**不改 pom、不改门禁配置**（红线 3）；
3. **联调验证**：在真实环境把 C-1.2 端到端链路（主体审核 → 自动签发 → 解析/验证 → 吊销/重签 → 跨空间互认）跑通并留痕，证明"**下游可按 DID 消费身份**"。

**关于"与连接器注册联调"（本卡最大不确定点，须先裁决）**：连接器注册服务（WBS `3.6.3`）当前**无规格、无实现、未开工**（`connector-sdk/` 仅 `.gitkeep`，未纳入根 pom），且**不在本卡依赖链**（`3.1.9~3.1.11`）内；C-1.2 规格自身存在张力——§4 非目标第 5 项写明"连接器 DID 绑定归 WBS 3.6.3，**本规格不定义连接器行为**"，而 §6.1 又写"测试补全与集成（3.1.12，**含与连接器注册联调**）"。→ **不许自行解释**（红线 2），处置见 §3 Q1。
