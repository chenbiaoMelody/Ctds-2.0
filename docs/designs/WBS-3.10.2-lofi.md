## §2 业务可读行为清单（"按意思找数据"对照）

| 场景 | V1.0 行为 | 业务含义 |
| --- | --- | --- |
| 需求方检索"金融风控" | 名称/简介/语义标签相关的已上架产品按相似度排序靠前 | 不只匹配字面关键词，相关产品更容易被找到 |
| 产品刚下架 | 下一次语义检索立即不再出现（即使向量缓存还在） | 目录呈现范围与 R6 一致，下架零泄漏 |
| 产品简介或语义标签变更 | 下一次检索按新文本排序（自动重算该产品向量） | 运营改元数据后，语义检索随之更新 |
| 产品从未上架/已注销 | 永不出现 | 与 R6 同一呈现范围口径 |
| 未入驻主体来检索 | 统一拒绝（与 R6 同文案，防枚举） | 资格门槛与目录检索一致 |
| 用纯标点检索 | 返回空结果页（200） | 不报错、不把全量产品倒出来 |
| 未来数据量触顶换向量库 | 新增 pgvector/Milvus 适配器 + 改配置，检索端点与业务代码不动 | ADR-003 §5 可替换性；V1.0 不为演示引入新中间件 |
| 真实模型调用 / 费用 / 密钥 | **不会发生**（本地确定性向量，零外呼） | V1.0 零消耗；真实 embedding 归 V1.5 |
| 语义能力预期 | 能打通整条向量检索链；同义词/深层语义能力有限 | 诚实边界：不承诺 Top5 ≥90% 上线指标 |

## §6 风险与诚实边界

1. **语义能力边界**：本地确定性向量不是真实语义模型，同义词/深层语义弱；**不得声称**达到 PRD :263"目录语义检索 Top5 命中率 ≥90%"上线指标；
2. **介质边界**：MySQL 8 + Java 余弦为 O(n) 演示规模实现，**不是生产级向量数据库**；10k 以上规模/并发容量归 WBS-4.2.1 / V1.5；未来切 pgvector/Milvus 仅新增适配器；
3. **冷启动成本**：首次检索需为全部候选产品计算并回写向量（惰性索引），首查耗时高于稳态；基准须记录首查成本，不隐藏；
4. **缓存残留**：下架/注销产品的向量缓存行不主动清理，靠 `status='LISTED'` 硬过滤保证不泄漏；缓存 GC 归未来适配器/运维策略；
5. **ADR 口径**：Q2-A 是对 ADR-003 §2.2/§3"pgvector 首版实现"的显式收敛；**ADR-003 §7 增补勘误已随定稿确认一并批准（2026-11-17）**，不改历史原文；
6. **网关存量缺口**：`/api/v1/catalog/**` 无网关路由是既有事实（R5/R9/R10 同样），本卡不扩面；验收直连 8084。
