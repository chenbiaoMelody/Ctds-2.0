## 1. 做什么 / 不做什么

**做**（= 任务卡交付物 ①~⑧；**按建议口径 A 书写，Q1 若改选 B/C 则本设计随确认重写**）：

1. 在既有宿主 `services/catalog-service`（8084 / 库 `ctds_catalog`）上续建，迁移顺延 **V3**（不新建服务、不新建库）；
2. **类目树单表（2 级）+ 种子类目随迁移内置**（沿 3.2.5/3.3.3 种子先例）+ 类目树读面 1 端点；
3. **数据产品最小载体表**（Q1-A：字段全部来自规格已裁决明文）+ **统一目录检索端点**（分类过滤〔含子树展开〕+ 关键词〔名称/简介，长度上限 + 转义〕+ 分页〔`common-pagination`〕+ 默认上架时间倒序）+ **产品详情端点**（目录元数据白名单 + 防枚举同形）；
4. **收藏/订阅双动作四端点**（收藏/取消/订阅/退订：幂等 / 仅本人 / 不可对未上架新发起 / 四动作 + 拒绝全程留痕）+ **我的收藏/我的订阅两列表**（状态联动 = 读时计算，Q5-A）；
5. **ADMITTED 资格门槛接入**检索/详情/收藏/订阅全链（复用 `SubjectAdmissionPort` 既有通道，防枚举统一文案沿 1007C0006）；
6. **资源分类申报接入类目成员校验**（Q2-A：`declare_category` 非类目树内类目拒绝——沿 3.3.3 词表校验同款插入点与零副作用性质，兑现 3.3.2 移交）；
7. **产品变更留痕表载体**（`product_action_log`，写入归 3.3.5）+ 订阅感知最小读面（我的订阅含产品当前状态 + 订阅产品变更留痕可查，Q6-A）；
8. 迁移探针 + 检索/收藏/订阅正反向测试 + 资格门槛三态 + 防枚举同形对照 + **3.3.3 既有 80 例零回归**；
9. 分级落级复核回写（分级规范 §6.1）。

**不做**（归下游，任务卡纪律声明同）：

- **产品封装 / 定价数值字段 / 上下架流程 / 强制下架治理兜底 / 注销引用保护实体化 / 治理查看留痕机制复用形态** → **3.3.5**（本卡 `product_action_log` 只建载体，写入随 3.3.5）；
- **界面**（检索门户页 / 产品详情页 / 收藏订阅入口）→ **3.3.6**（剧本界面入口仍占位）；
- **语义检索本体**（向量库 / AI-0 对接）→ **3.10.2**；本卡只按 Q7-A 落定预留接口契约形态（hifi 登记），**代码零占位**；
- **实时推送 / 消息通道** → 3.7.2 评估（规格明示 V1.0 不承诺实时推送，Q6-A 落定"留痕可查"）；
- **覆盖率达标 / 变异 / 万级目录数据集 / 性能基准** → **3.3.7**（规格仅登记"目录检索为性能敏感路径"预期）；
- **类目树维护写面**（新增/停用/移动类目）→ 不做（平台受控、随迁移内置，V1.0 只读；同 3.3.3 Q7-A 词表口径）；
- **元数据 AI 识别（C-3.5）/ AI 分类分级（C-3.6）/ 供需撮合（C-3.4）** → 规格 §4 非目标 3/4，V1.0 不做；
- 订购 / 合约 / 交付（"订购入口"按钮等消费动作）→ C-7.3 / C-4.x（规格 §4 非目标 5——目录检索 ≠ 可访问，资源本体访问须经订购）。

## 2. 方向要点（设计骨架）

### 2.1 宿主与迁移

| 项 | 取值 | 理由 |
| --- | --- | --- |
| 服务 / 端口 / 库 | `services/catalog-service` / 8084 / `ctds_catalog`（**均不变**） | 一域一服务（3.3.2 Q1-A 已裁决）；3.3.3~3.3.5 同宿主续建 |
| 迁移版本 | **V3**（V1 = 3.3.2 四表，V2 = 3.3.3 词表两表） | 沿 ADR-009 顺序迁移；既有 V1/V2 零改动（不新增列、不改语义） |

- 权限点命名与角色映射随 hifi 定稿（方向：读面一枚 + 交互一枚；映射 `provider`/`admin` 既有角色，**不动既有六点**）；W5/W7 是否要求 ADMITTED 随 hifi 定稿（本人条目操作，条目本身产生于 ADMITTED 期）；
- 判定为**纯本地 + 既有跨域通道复用**：资格判定复用 `SubjectAdmissionClient`（既有 UNAVAILABLE 语义沿用，不新增 S 型码）；类目树为同库本地字典（无网络调用）；**本卡不触碰 subject / space / did / kms 任何文件**。

### 2.4 类目过滤与关键词口径（方向）

- **类目过滤含子树**：选父类目 = 命中该节点及其全部后代的产品（业务直觉：目录按"金融"过滤应见"普惠金融"子类目产品）；实现 = 先查子树 code 集（同库一次查询）+ `IN` 过滤；类目 code 不存在 → 参数校验拒绝（码值随 hifi）；
- **keyword 匹配面 = 名称 / 简介**（规格行为 5 规则 3 明列两字段），DB 侧 LIKE + 转义（**转义符与 catalog 既有 `escapeLike` 同一套**——不新增第二副本，沿 DB-33 登记的收敛方向；3.3.3 评审跟踪项"keyword 长度上限"在本卡兑现为参数校验）；keyword 归一化**不做**（LIKE 模糊匹配非精确判重，与 `DatasetNameNormalizer` 的判重用途不同源，不混用）；
- **检索 ≠ 可访问**：响应字段集 = 目录元数据白名单，测试显式锚定（无资源本体、无敏感原文、无个人信息）。

### 2.5 资源分类申报接入类目校验（Q2-A 兑现 3.3.2 移交）

```
catalog-service（本卡改动面全部在模块内）
├─ interfaces/ProductCatalogController        ← 新建（R5~R10 读面 6 端点）
├─ interfaces/ProductInteractionController    ← 新建（W4~W7 写面 4 端点）
├─ application/ProductCatalogQueryService     ← 新建（检索/详情/列表/留痕查询）
├─ application/ProductInteractionService      ← 新建（收藏/订阅四动作 + 留痕）
├─ application/DatasetRegistrationService     ← 既有文件改 1 处：校验链插入 declare_category 类目成员校验
│    （沿 3.3.3 词表校验同款插入点——资格/空间/重要数据拒收之后、判重取号之前；零副作用性质不变）
└─ infrastructure/Jdbc*Repository ×N + domain/* 新建（CategoryNode/DataProduct/ProductFavorite/
     ProductSubscription/ProductActionLog/枚举/Port）+ CategoryPort（类目树本地字典通道）
```

- 类目成员校验**只作用新写入、不回填历史**（沿 3.3.3 Q6-A 先例）；种子类目**必含走查/测试实际已用的申报值**（Q3 盘点义务，编码会话实测测试字面量回填）；
- 校验匹配口径 = DB 侧精确比对 `category_code`（申报值与类目码的匹配规则——直接等值还是归一化等值，随 hifi 定稿；倾向申报值即类目码或类目名，hifi 定一种并说明）；
- 语义标签词表校验链**零改动**（两套受控集合物理分离：词表通道 `TagTermPort` / 类目通道 `CategoryPort`，术语不相混）。

### 2.6 状态联动与订阅感知（Q5-A / Q6-A 方向）

- **状态联动 = 读时计算**：`product_favorite` / `product_subscription` 无状态列；R9/R10 查询联 `data_product.status` 返回 `productStatus` 字段——"下架/注销后条目保留但标记当前状态"自然成立（历史不删除）；"不可对未上架产品新发起"由 W4/W6 链上产品状态门槛承载（非在架拒绝 + 新码防枚举同形）；
- **订阅感知 = 留痕可查**：R10 我的订阅（含产品当前状态）+ R8 订阅产品变更留痕（`product_action_log` 载体本卡建、写入归 3.3.5）；**无消息通道、无推送、无定时任务**（最小实现，规格明示不承诺实时推送）。

### 2.7 语义检索预留接口契约（Q7-A 方向，hifi 登记全文）

- 预留形态 = **本卡 hifi §9 登记**：R6 检索端点的路径/参数/响应结构作为 3.10.2 语义检索扩展基线（届时语义检索以独立端点或扩展参数接入，消费 R6 响应契约与类目树词典）；**本卡代码零占位**（无 501 端点、无 AI 依赖包、无向量库引用）——"预留"的交付物 = 契约文档本身，AI-0 开工时按约定对接。
