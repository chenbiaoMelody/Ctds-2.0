## 1. 做什么

1. **产品封装写面**（行为 3）：从**自有有效资源**封装数据产品——要素齐备（名称/简介/形态/定价模型/关联资源）、四形态四档定价、**同一提供方内产品名称唯一**（归一化判定）、**一资源多产品**、封装幂等（ADR-007）、全程留痕；
2. **上下架管理写面**（行为 4）：状态机 `未上架→已上架⇄已下架` + **已注销**（二次确认、不可逆、仅可从未上架/已下架发起）——上架前提（要素齐备含定价 + 资源有效未注销 + 资源所在空间未解散 + 提供方仍 ADMITTED）、下架效果（目录不再呈现、不可新订购——订购归 C-7.3）、**平台运营方强制下架**（理由必填、留痕）、可重新上架（均留痕）、越权拒绝；
3. **产品信息与定价变更**（行为 4 规则 5）：已上架产品允许变更（留痕含从何值→到何值）；
4. **注销引用保护实体化**（行为 2 规则 2 + 3.3.2 移交）：`NoopProductReferenceGuard` 恒放行实现替换为实体检查——存在未注销产品引用的资源不得注销，兑现 C-3.1 剧本 S3 步骤 4（拒绝错误码随本卡定）；
5. **治理例外与查看留痕**（行为 7 规则 3 + §末未定义项）：平台运营方（admin）可读**产品侧与资源侧**治理详情（含未上架/已下架/已注销对象），每次查看写留痕（沿 DB-29 运营档治理查看留痕已交付先例）——C-3.2 剧本 S3-3 判定面（"全部产品与资源"）落地的硬需求；
6. **产品业务编号规则、定价数值字段、形态一致性校验、数量上限**四件落定权行使（Q1~Q4）；
7. **债务承接评估**：DB-34（幂等窗口收口）/ DB-35（频控评估）/ DB-36（表示口径）/ DB-37（读面拒绝留痕口径落定）/ DB-38（补测份额）/ DB-39（孪生 DTO 裁决）——Q5~Q8 与测试计划承载。

## 2. 不做什么（边界划清）

- **不做界面**（产品上架页/检索门户页）——归 3.3.6；C-3.3 剧本界面入口占位不变；
- **不做订购/合约/交付/计费**——归 C-4.x / C-7.x / 3.7.6；下架"既有权益不受影响"本卡不改变；
- **不做平台复核工作流深化**（V1.0 = 自申报 + 治理兜底）；不做产品信息 AI 复核（C-3.6 = P1）；
- **不做语义检索**（3.10.2）；**不做实时通知**（订阅感知 = 留痕可查，3.3.4 Q6-A 已定）；
- **不做 V1/V2/V3 既有表结构破坏性变更**——本卡 **V4 增列扩展**（3.3.4 Q1-A 明文授权"其迁移增列"），既有列与约束零改动；
- **不引新依赖、不改既有服务（subject/space/did/kms/std-adapter）、不改门禁配置与 ADR**；错误码仅 1007 段顺延；
- **不做类目树/词表维护写面**（V1.0 平台受控只读）；两套受控集合不得混用术语（3.3.3 hifi §9 红线）；
- **不做万级数据集与性能基准**（3.3.7）；**不做网关限频**（DB-35 评估结论 = 运维侧跟进，见 Q7）。

## 3. 方向要点（供快速表决）

1. **宿主续建**：仍在 `catalog-service`（8084 / `ctds_catalog`），迁移顺延 **V4**（增列 + 唯一键 + 动作码值域注释登记，沿 DB-29 V4"仅列注释值域登记"先例）；
2. **产品载体扩展**（Q1-A 方向）：`data_product` 为 3.3.4 已建最小载体，本卡 V4 增列 `price_amount`（定价数值）与 `normalized_product_name`（归一化名，唯一判定口径沿 dataset 先例）+ 新唯一键；**不建取号构件**（产品对外沿 R2/R7 先例以自增 id 为路径参数）；
3. **端点**（编号续 W4~W7/R5~R10）：写 6 = 封装 W8 / 变更 W9 / 上架 W10 / 下架 W11 / 强制下架 W12 / 注销 W13（动词子资源沿 W3 `/cancellation` 先例）；读 2 = 提供方产品管理列表 R11（沿 `/datasets/mine` 先例）+ 治理详情读面 R12（产品侧）/ R13（资源侧，admin + 新权限点 + 查看留痕）；
4. **状态机硬约束在服务端**：转换矩阵封闭（DRAFT→LISTED/CANCELLED；LISTED⇄DELISTED〔DELISTED→LISTED = 重新上架〕；LISTED→CANCELLED 拒绝须先下架；CANCELLED 一切动作拒绝）；`listed_at` 上架写、下架清（V3 注释"非在架态为 NULL"口径）；
5. **校验链复用既有通道**：ADMITTED（`SubjectAdmissionPort`）/ 空间成员与状态（`SpaceMembershipPort`，封装与上架均查空间未解散）/ 类目成员校验（`CategoryTreeService` 既有）/ 名称归一化（`DatasetNameNormalizer` 既有组件）——零新跨服务调用面；
6. **留痕**：产品侧动作统一落 `product_action_log`（载体 3.3.4 已建、写入动作码集合随本卡登记——V3 注释明文授权）；动作码 = CREATE/UPDATE/PUBLISH/DELIST/FORCE_DELIST/CANCEL + DENIED_* 六 + GOVERNANCE_VIEW；**R8 订阅者可见值域 = 变更类六码**（DENIED_* 与 GOVERNANCE_VIEW 不对订阅者暴露——"动作码集合随 3.3.5 登记"的应有之义）；
7. **治理查看留痕复用形态**（Q5-A 方向）：沿 DB-29 先例 = 既有动作留痕表 + 1 个通用码 GOVERNANCE_VIEW + 实际登录主体 + 仅运营方触发；资源侧写 `dataset_action_log`、产品侧写 `product_action_log`（各自域表，零新表）；
8. **DB-34 顺手收口**（Q6-A 方向）：收藏/订阅写面 catch `DuplicateKeyException` 转幂等重放语义，消除并发 500 态（沿本卡新写面"命名唯一并发=唯一键兜底+业务码转译"同款手法）；
9. **分级落级复核**（Q9-A 方向）：`data_product`（含新增列）与 `product_action_log` 维持 3.3.4 已落 **CAT-03 L1**（目录公开元数据、检索≠可访问；规格锚 CAT-04 的 L3 行=合约/账单归 C-4.x/3.7.6），复核结论回写分级规范 §6.1。
