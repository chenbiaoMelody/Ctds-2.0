## 3. 主要流程（业务语言）

1. **逛目录**：打开左侧菜单「数据目录」→ 左侧类目树（平台受控类目，点父类目含其下全部子类）+ 关键词检索 → 结果分页列表（名称 / 简介 / 形态 / 定价 / 类目 / 提供方）→ 点行进入**产品详情**（地址可直接复制粘贴——深链可直达）。详情只显示目录元数据，**没有任何数据本体内容**（检索 ≠ 可访问）。
2. **收藏与订阅**：详情页点「收藏」→ 成功；再点一次（或重复收藏）不产生第二条（幂等）；点「订阅」→ 订阅关系登记成功；**订阅后**详情页出现「变更记录」区（提供方改价 / 下架的记录）；下架后回到「我的收藏 / 我的订阅」，条目仍在并标注"已下架"（历史不删除），但对已下架产品**新发起**收藏/订阅会被拒（原样展示后端文案）。
3. **管好自己的数据（提供方）**：菜单「资源登记」→ 我的资源列表 → 「登记资源」填名称 / 类型 / 简介 / 语义标签（从受控词表多选）/ 分类分级申报（类目 + 级别 + 是否重要数据）→ 选空间（**可直接填空间编号**；下拉"我的空间"可快捷回填并显示空间状态）→ 提交。申报"重要数据"会被**拒收**（硬约束）；填了词表外的标签、类目外的分类、非成员空间、未启用/冻结/解散空间都会被拒——**界面原样展示后端文案**。变更：只能改简介 / 标签 / 分类申报，级别**只能收紧**（下调会被拒）；注销：二次确认（明示不可逆），取消则什么都不发生。
4. **封装与上下架（提供方）**：菜单「产品上架」→ 我的产品列表（所有状态可见）→「封装产品」选来源资源（本人资源）、名称、简介、形态（API / 数据集 / 报告 / 模型）、定价（免费 / 按次 / 包月 / 交易额分成，免费也要显式选，付费须填正数）→ 提交后产品处于"未上架"。定价没填齐就点上架 → **被拒**（上架须要素齐备）；上架后可被目录检索到；下架后目录不再出现，可**重新上架**；在架产品不能直接注销（须先下架）；被平台强制下架的产品由提供方**自助重新上架**。
5. **平台治理（平台运营方）**：切档到"平台运营方"→ 菜单「目录治理」→ 输入产品编号或资源编号 → 查看任意状态对象的治理信息（含未上架 / 已下架 / 已注销）→ 对在架产品填理由**强制下架**。每次查看都会留下"治理查看留痕"（提供方在自己的留痕区能看到"某运营方主体何时看了这个产品"）。
6. **留痕核对**：「资源登记」与「产品上架」两页各带**操作留痕区**：登记/变更（含从何值→到何值）/注销/上下架/强制下架（含理由与操作者）与**所有拒绝记录**都在这里逐条可见（谁 / 何时 / 对象 / 动作），不含任何敏感原文。「数据目录」页的「我的互动留痕」页签展示本人收藏/订阅/取消/退订与拒绝记录。
7. **切换演示身份**（演示期）：顶栏沿用"演示身份"控件（主体编号 + 档位）——换主体即可扮演剧本中的 A / B / C / D 主体；切"平台运营方"档即可执行治理类动作。**普通档绝不携带平台角色**（否则"越权被拒"类剧本步骤会被放行，让判定失真）。
8. **越权类步骤的界面观察口径**（剧本修订时逐条标注）：非本人打开他人资源/产品 → 界面按编号/深链尝试 → **同形拒绝**（资源 `1007C0005` / 产品 `1007C0011`，不区分"不存在"与"无权"）；**写面越权拒绝的留痕**（如 D 主体尝试变更/注销他人资源）由技术侧接口直调承载（沿 C-3.2 S3-2 技术侧配合先例）——界面不提供、也不应提供"对他人对象提交写操作"的入口（服务端强制是安全面，界面隐藏不构成权限）。
