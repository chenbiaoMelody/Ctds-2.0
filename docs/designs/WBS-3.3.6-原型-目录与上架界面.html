画面 9：同形提示与错误展示纪律（口径板）

① 资源不存在 / 非本人：同一条提示「资源不存在或无权访问」（1007C0005）——不区分"不存在 / 非本人"
② 产品不存在 / 未上架 / 已下架 / 已注销 / 非订阅者：同一条提示「产品不存在或未在架」（1007C0011）或管理面「产品不存在或无权操作」（1007C0012）——不区分差异
③ 未入驻检索：统一业务文案「主体未入驻或不存在，无法使用统一目录服务」（不提示"主体不存在"）
④ 一切写动作不做乐观更新：被拒后界面状态不变，一律以响应为准刷新；错误文案原样展示（不吞、不改写）
⑤ 危险动作（注销 / 强制下架）二次确认；取消 = 零请求；必填留空 = 前置拦截（零请求）
⑥ 认证失效（1000C0002）→ 提示后端文案 → 清登录态 → 回登录页（复用共享 authGuide）
