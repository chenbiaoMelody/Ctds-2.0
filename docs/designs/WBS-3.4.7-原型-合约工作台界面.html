画面 9：口径板（同形提示 / 角色头 / 错误展示纪律）

① 模板不存在 / 已停用：同一条提示「模板不存在或不可用」（1008C0001）——不区分差异
② 合约不存在 / 非参与方：同一条提示「合约不存在或不可见」（1008C0012）——防枚举（含治理直查对象缺失）
③ 未入驻（浏览 / 发起 / 维护三语境）：后端统一业务文案原样展示（不提示"主体不存在"）
④ 模板维护越权「无权进行模板维护操作」（1008C0002）/ 产品不可发起「产品不存在或未在架，无法发起合约」（1008C0010）/ 模板不可发起「所选模板不可用于发起合约」（1008C0017）——一律原样展示
⑤ 一切写动作不做乐观更新：被拒后界面状态不变，一律以响应为准刷新；错误文案原样展示（不吞、不改写）
⑥ 模拟"拒绝"是数据不是错误（不弹错误提示，结果面板展示）；模拟零副作用——界面不本地增减计数
⑦ 危险动作（终止协商 / 拒签终止 / 合意解除 / 启停 / 强制终止）二次确认；取消 = 零请求；必填留空 = 前置拦截（零请求）
⑧ 认证失效（1000C0002）→ 提示后端文案 → 清登录态 → 回登录页（复用共享 authGuide）
⑨ 角色头：普通档 = provider（不含 admin，硬约束）；运营档 = admin；跨域产品检索走目录角色头；两套页面级头互不污染
⑩ 诚实边界常驻：模拟结论不是放行承诺 / 受控执行为演示期形态；受控执行每次提交计一次使用（无幂等键，如实提示）
