## §1 做什么（业务可读行为清单，7 条）

> 每条对应规格的承载点，业务人员可据此验收；技术实现见 hifi。

1. **统一交付入口（行为 2 规则 1）**：数据产品的 API 交付调用**一律经网关**进入平台；不经网关的直连不在平台承诺范围内（诚实边界，登记）。
2. **先认人、再放行（行为 7 规则 1 / ADR-005 §3-7）**：调用方必须持有有效身份令牌方可通过；**伪造的身份头一律被无条件剥离**（网关统一生成权威身份）；未认证 → 401；无权限 → 403。
3. **限流保护（行为 2 规则 5 / ADR-005 §3-6）**：按"**调用主体 + 接口**"做频率保护，阈值可配置；超限 → 拒绝（HTTP 429）；**限流不是业务次数配额**（配额唯一由合约策略判定与计数）。
4. **转发前先判定策略（行为 2 规则 2 / 规则 3）**：网关在把请求转给数据源**之前**调用合约域判定；**越界（超次数 / 超期 / 用途不符 / 域外 / 再分发）一律被拒，且请求不会触达数据源**；拒绝口径**沿用合约域原码**（越界 403 / 状态失效 409 / 合约不存在或非参与方 404 同码同文防枚举）。
5. **凭合约交付、发起人唯一（行为 1 规则 1 / 规则 2）**：API 交付调用须声明**已生效合约编号**；未生效 / 已终止 / 已完结不可发起；**发起人 = 合约需求方**（提供方与运营方不可发起，只读）。
6. **放行才计量（行为 2 规则 6）**：放行 1 次产生 **1 条计量事件**；**拒绝不产生计量事件**（拒绝留痕不受影响）；事件**不含数据本体与数据原文**（CAT-04 / CAT-07 口径）；事件口径本卡定义，**计量流水与计费归 3.7.5 / 3.7.6**。
7. **可查可核（行为 2 标准 4 / 行为 7 规则 3·5）**：判定与拒绝留痕可核（不落原文）；服务端强制——**绕过界面直接调用接口同样被拦**（界面与参数均不构成绕过路径）。

**本卡不做（划清）**：交付记录（`deliveries`）模型与读面 / 文件交付与国密加密传输（3.5.3）/ 沙箱（3.5.4）/ 审核导出（3.5.5）/ 交付界面（3.5.6）/ 计量采集与账单（3.7.5、3.7.6）/ 上链存证（3.8.3）/ 独立 API Key 签发轮换（未定义项）/ 前端代理与部署单入口切换 / 真实数据源接入（连接器 3.6.x）。

## §2 不做什么（边界划清）

1. **不改既有业务端点语义**（subject / kms / did / space / catalog / contract 全部零语义改动；contract 仅**新增**一个内部判定端点 + yml 1 行授权 + ADR-016 §6 补记）；
2. **不改既有错误码码值**（只新增 1009 段码位；越界一律透传合约域原码）；
3. **不改门禁配置**（`gates-config.json` / `run-gates.ps1` 零触碰）；**不改 ADR-001 技术基线条目**；
4. **不做第二套判定**（不复制策略语义；不支持任何"跳过判定 / 强制放行"入参）；
5. **不自行实现密码学 / 不落盘密钥**（本卡不涉加解密本体；令牌密钥仅环境变量）；
6. **不做交付记录面**（建议 Q5-A：归交付域宿主包）；
7. **不切换前端代理与部署单入口**（建议 Q4-A：登记切换动作）；
8. **不夹带** DB-40 清理脚本改写（沿 4.2.1）、跟踪项 T1 台账脱敏（另立 DB 族工具包）、性能调优（发现慢只登记；正式压测归 4.2.3）；
9. **不擅自改规格与剧本**（缺口走变更流程；他域剧本零改动）。

- **A（建议）**：新建 **`ADR-022 网关交付链契约`**——固化：链路顺序 / 判定唯一与集成面（消费 `check`，越界原码）/ 限流与配额分工 / 信任边界与头处置（剥离 + 注入）/ 交付面与凭据形态 / 计量事件口径 / 未收敛面与诚实边界 / 演进与退役触发（真实令牌 3.9.1、数据源 3.6.x、分布式限流）+ ADR-016 §6 消费方补记与 §2.7 关口注明。

## §5 边界值与异常行为（业务可读）

| 场景 | 期望行为 |
| --- | --- |
| 未携带令牌 / 令牌过期 | 401 + `1000C0002`（统一文案，不暴露内部原因） |
| 伪造 `X-Ctds-Subject` / `X-Ctds-Roles` 头 | **一律被剥离**，下游只见网关按令牌生成的权威值 |
| 交付面路径未在白名单（默认拒绝） | 拒绝，不进入判定（fail-closed） |
| 缺失 / 格式非法的合约编号凭据 | 拒绝（1009 段码），不触达判定与数据源 |
| 合约未生效 / 已终止 / 已完结 | 拒绝（沿用合约域 `1008C0013`，HTTP 409） |
| 越界（超次数 / 超期 / 用途不符 / 域外 / 再分发） | 拒绝（`1008C0020`，HTTP 403）+ **不触达数据源 + 不产生计量事件** |
| 合约不存在 / 非参与方 | 拒绝（`1008C0012`，HTTP 404，**同码同文防枚举**） |
| 非合约需求方发起（提供方 / 运营方） | 拒绝（发起人唯一口径） |
| 超过限流阈值 | 拒绝（HTTP 429）；**不影响业务配额计数** |
| 判定服务不可达 | **fail-closed** 拒绝（503）——不放行 |
| 放行调用 | 转发数据源 + 1 条计量事件（1:1 对账）；事件不含数据本体与原文 |
| 绕过界面直接调用 | 与界面路径**同一判定面**（服务端强制） |
