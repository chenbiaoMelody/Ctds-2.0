## §1 做什么（业务可读行为清单，8 条）

> 每条对应规格的承载点，业务人员可据此验收；技术实现见 hifi。

1. **凭生效合约交付、发起人唯一（行为 1 规则 1 / 2）**：文件交付和 API 交付记录都只能由**合约需求方**凭**已生效合约**发起；未生效 / 已终止 / 已完结的合约一律拒绝；提供方与平台运营方只能查看，不能代发起。
2. **形态必须对得上（行为 1 规则 3 / 行为 3 规则 3）**：API 形态的数据产品只能走 API 交付；**数据集 / 报告 / 模型**形态的产品才能走文件交付；形态不符一律拒绝，不产生交付记录、不生成交付包。
3. **文件交付 = 国密加密包 + 完整性校验（行为 3 规则 1）**：平台把源文件用**国密 SM4/GCM** 加密成“加密交付包”，同时计算**国密 SM3** 完整性校验值；加密与摘要一律走平台唯一国密组件，**不自研密码学**。
4. **按合约最小必要（行为 3 规则 3）**：交付的文件必须属于合约锚定的产品（文件清单按产品登记）；请求里给一个不属于该产品的文件 → 拒绝；超过平台加密上限（64MiB）→ 明确拒绝并提示上限。
5. **交付记录可核、但不含本体（行为 3 规则 2 / 4 / 行为 7 规则 4 / 5）**：每次交付产生一条交付记录（谁 / 何时 / 哪份合约 / 哪个产品 / 文件标识 / 校验值 / 结果）；记录、审计、日志、界面都**不含文件本体与数据原文**。
6. **领取加密包（行为 3 规则 1 / 行为 7 规则 1）**：只有**合约需求方**可以下载该次交付的**加密交付包**；提供方与平台运营方可以查看记录，但不能领取数据；**接收方解密所需的密钥分发不在 V1.0**（诚实边界，见 §5）。
7. **幂等与防重复（行为 1 规则 5 / 行为 3 规则 5）**：同一幂等键重放 → 返回首次结果，**不增加记录、不重复生成交付包**；重复提交不会产生第二份包。
8. **可查与治理例外（行为 7 规则 1 / 2 / 3）**：合约双方可查本合约的交付记录；平台运营方可走**治理读面**查看并留痕；非参与方与“记录不存在”**同码同文**，防枚举；一切判定在服务端，界面隐藏不构成权限。

**本卡不做（划清）**：沙箱（3.5.4）/ 结果审核导出（3.5.5）/ 交付界面（3.5.6）/ 计量流水与计费（3.7.5、3.7.6）/ 上链存证（3.8.3）/ 连接器跨机构文件通道（3.6.x）/ 独立 API Key（规格 §6-5 未定义项）/ 前端代理切换 / 提供方文件上传端点（生产级文件接入登记演进）/ 接收方密钥分发（登记边界）。

## §2 不做什么（边界划清）

1. **不改网关**：3.5.2 网关的四件（鉴权 / 限流 / 策略执行点 / 计量埋点）与内部判定响应**零改动**；文件交付是独立通道，不重复网关链路。
2. **不改既有业务端点语义**：contract/catalog 只做**加性**内部面（只读摘要 + `productType` 字段 + `delivery-internal` 授权 1 行），既有端点、既有码值零改动。
3. **不做第二套状态/策略判定**：合约是否生效、参与方是谁、策略是否放行**一律由合约域回答**；交付域只消费结果，不复制语义。
4. **不自研密码学 / 不落密钥**：SM4/SM3 一律 `common-crypto`；密钥只来自 KeyProvider/KMS；演示密钥文件 gitignored、不进日志、不进提示词。
5. **不让本体进留痕**：DB、审计、日志、错误消息、界面均无文件本体与数据原文；文件路径不入库、不对外。
6. **不做规格外功能**：不新增提供方上传端点、不做接收方解密服务、不做 API Key、不做文件在线预览、不做跨机构传输。
7. **不改门禁配置 / 技术基线**：`gates-config.json`、`run-gates.ps1`、ADR-001 条目零触碰。
8. **不擅自改剧本**：G1 缺口走变更流程，PO 批准后由剧本维护流程修订。

### G1 剧本 S2 与规格形态一致性缺口（需变更流程）

**事实**：剧本 S2 步骤 1（`docs/manuals/C-5.1-数据交付-验收剧本.md:38`）写“对**同一已生效合约**发起文件交付”；附录 A（同文件 `:70~:71`）主凭据 = **API 形态**合约，补充凭据 = **数据集形态**合约。规格行为 3 规则 3（`docs/specs/C-5.1-5.2-交付与沙箱.md:89`）明文“交付形态与产品形态（数据集 / 报告 / 模型）一致”，行为 1 规则 3（`:51`）要求形态与合约锚定产品形态一致。→ **用 API 形态合约做文件交付应被拒绝，S2 原文与规格冲突**；若按 Q4-A 调用策略判定，S2 还需携带 purpose/territory（剧本当前未写）。

| 口径 | 内容 | 业务影响 |

## §5 边界值与异常行为（业务可读）

| 场景 | 期望行为 |
| --- | --- |
| 未生效 / 已终止 / 已完结合约发起 | 拒绝（`1008C0013`，语义与合约域一致） |
| 合约不存在 / 非参与方 | 拒绝（`1008C0012`，同码同文防枚举） |
| 提供方或运营方代发起 | 拒绝（`1009C0003`，403） |
| API 形态合约请求文件交付 / 数据集合约请求 API 交付 | 拒绝（`1009C0006`，400） |
| 文件标识不在清单 / 不属于合约产品 | 拒绝（`1009C0006`，400） |
| 文件超过 64MiB | 拒绝（`1009C0008`，400，提示上限） |
| 文件源未配置 / 文件丢失 / 合约或目录服务不可用 | **fail-closed** 拒绝（`1009S0002`，503），不生成包、不记录 |
| 加密/存储失败 | 拒绝（`1009S0003`，500），不记录；不留半写包 |
| 策略越界（超次数 / 超期 / 用途不符 / 域外 / 再分发） | 拒绝（合约域原码 `1008C0020` 等，**零计数**） |
| 同一幂等键重放 | 返回首次结果；记录不增加、包不重复生成 |
| 非需求方下载加密包 | 拒绝（`1009C0009`，403；提供方/运营方不可领取数据） |
| 非参与方查看/下载 | 拒绝（`1009C0007`，404，与“不存在”同码同文） |
| 治理查看 | 可查看记录且产生治理查看留痕；仍不含本体 |
| 交付包生成成功 | 记录含文件标识/展示名/大小/包标识/SM3/结果；响应含包标识与 SM3 |
| 下载加密包 | 返回加密件（`application/octet-stream`）+ SM3 头；响应不含明文 |
