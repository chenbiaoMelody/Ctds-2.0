## §1 做什么（业务可读行为清单，8 条）

> 每条对应规格的承载点，业务人员可据此验收；技术实现见 hifi。

1. **凭生效合约申请、只有需求方能进（行为 1 规则 1 / 2 / 4；行为 4 规则 1）**：沙箱任务必须绑定**已生效合约**，申请人必须是合约**需求方**；未生效 / 已终止 / 已完结合约一律拒绝，提供方与平台运营方只能查看、不能代申请；非参与方与“任务不存在”**同码同文**，防枚举。
2. **容器隔离的独立环境（行为 4 规则 2；行为 5 规则 2）**：每个沙箱任务一个**独立容器**，容器**无网络**、非 root、只读根文件系统、能力全部丢弃；只挂载本任务自己的输入（只读）与输出目录，**看不到其他沙箱、其他合约的数据**，也**碰不到宿主机的数据链路**。
3. **数据进得去、带不出（行为 5 规则 1 / 行为 7 规则 4）**：合约产品已登记的数据文件在开通时**复制**到平台工作区的只读输入目录，容器只能读、不能改源文件；平台**不提供任何文件内容下载入口**（输入、输出都不提供），唯一出口留给 3.5.5 的“审核后导出”。
4. **资源配额与并发上限（行为 4 规则 3；行为 5 规则 5）**：每个任务有统一的 CPU / 内存 / 时长配额与并发上限，**申请时不能自选**；配额到顶（到期或作业超时）即不可继续使用，配额判定在服务端。
5. **生命周期与到期自动关闭（行为 4 规则 3）**：任务状态 = 运行中 → 已关闭 / 已到期；到期由服务端**自动停止容器并置为已到期**，之后任何使用请求一律拒绝；需求方可主动关闭，关闭后不可再用。
6. **沙箱内使用 = 平台预置作业（行为 4 规则 4；行为 5 规则 3 / 4）**：需求方在沙箱内通过**平台预置的受控作业**使用数据（作业清单由平台配置，请求只给作业编号 + 用途 / 地域，不给命令、不给路径）；每次执行产生**使用留痕**（谁 / 何时 / 哪个任务 / 哪个作业 / 结果），不含数据本体与原文。
7. **使用时策略仍然生效（行为 5 规则 4；规格 Q7-A）**：每次作业执行都视为**一次数据使用**，先调合约策略判定（用途 / 地域 / 次数等），**放行才执行并计数 1 次**，拒绝零计数、零作业记录；沙箱不是策略的例外通道。
8. **可查与治理例外（行为 4 规则 4；行为 7 规则 1 / 2 / 3 / 5）**：合约双方可查任务、配额、生命周期、作业留痕与**结果物元数据**（名称 / 大小 / SM3，不含内容）；平台运营方可走**治理读面**查看并留痕；其余主体一律拒绝且留痕；一切判定在服务端，界面隐藏不构成权限。

**本卡不做（划清）**：结果物审核与导出（3.5.5）/ 交付管理界面与沙箱工作台界面（3.5.6）/ 计量流水与计费（3.7.5、3.7.6）/ 上链存证（3.8.3）/ 连接器跨机构沙箱（3.6.x）/ 任意命令执行与代码上传 / 用户自选镜像或配额 / 生产 K8s 沙箱编排（登记演进）/ 隐私计算与 TEE（C-5.3 / C-5.4）。

## §2 不做什么（边界划清）

1. **不改网关**：3.5.2 网关四件与内部判定响应零改动；沙箱不经网关。
2. **不改合约 / 目录域**：合约内部只读摘要与内部判定 `check`、目录内部 `productType` 均已在 3.5.3 落地并对 `delivery-internal` 授权——**本卡零跨域改动**（ADR-016 §6 消费方不新增）。
3. **不做第二套策略判定**：合约状态、参与方、策略越界一律由合约域回答，1008C 结论码原码透传。
4. **不自行实现密码学**：结果物 SM3 一律 `common-crypto` `Sm3Service`。
5. **不让本体进留痕**：DB、审计、日志、错误消息、响应均无文件内容、无宿主机路径、无容器 ID、无密钥材料；作业 stdout/stderr **不落库、不落审计、不落日志**。
6. **不实现规格外功能**：不开放任意命令、不做代码上传、不做结果物下载、不做沙箱重启/克隆、不做多租户配额审批。
7. **不改门禁配置 / 技术基线**：`gates-config.json`、`run-gates.ps1`、ADR-001 条目零触碰；如确需新增容器基础镜像，按 `docs/dependencies.md` 容器基础镜像节登记并审批（Q3）。
8. **不擅自改剧本**：剧本缺口走变更流程（本卡登记的 G1 为规格未定义项）。

## §5 边界值与异常行为（业务可读）

| 场景 | 期望行为 |
| --- | --- |
| 未生效 / 已终止 / 已完结合约申请 | 拒绝（合约域 `1008C0013` 原码，409） |
| 合约不存在 / 非参与方申请 | 拒绝（`1008C0012`，404，同码同文防枚举） |
| 提供方或运营方代申请 / 非需求方操作 | 拒绝（`1009C0003`，403） |
| API 形态合约申请（G1-A） | 拒绝（`1009C0006`，400） |
| 合约产品未登记任何数据文件 | fail-closed 拒绝（`1009S0004`，503），不建任务 |
| 并发任务达上限（单需求方 / 全局） | 拒绝（`1009C0013`，429） |
| 开通成功 | 任务为“运行中”，配额、有效期、数据文件数可查；容器已按安全基线启动 |
| 主动关闭 | 状态“已关闭”，容器停止并移除；重复关闭返回当前状态（幂等） |
| 到期 | 服务端自动停止容器并置“已到期”，留痕；之后使用一律拒绝（`1009C0011`，409） |
| 作业编号不在允许清单 | 拒绝（`1009C0014`，400），零计数、零作业记录 |
| 作业用途 / 地域越界 | 拒绝（合约域 `1008C0020` 原码，403），零计数、零作业记录 |
| 作业超时 | 作业记录 `TIMEOUT`，容器内进程被杀；不产生结果物 |
| 作业执行失败（非零退出） | 作业记录 `FAILED`；不产生可用结果物 |
| 请求输入 / 输出文件内容（任意路径） | 一律拒绝（`1009C0012`，403）并留痕 |
| 查看他人任务 / 作业 / 结果元数据 | 拒绝（`1009C0010`，404，与“不存在”同码同文） |
| 治理查看 | 可查看并产生治理查看留痕；仍不含内容与路径 |
| Docker 不可用 / 镜像缺失 | 拒绝（`1009S0004`，503），不建任务、不写半成品 |
| 容器启动后写库失败 | 停止并移除容器、清理工作区，不留下孤儿任务 |
| 同一幂等键重放开通 | 返回首次任务，**任务数不增加、容器不重复创建** |
| 同一幂等键重放作业 | 返回首次作业结果，**不重复计数** |
