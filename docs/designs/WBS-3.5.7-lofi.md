## 1. 做什么（四件事，不加任何业务功能）

1. **达标盘点与映射回填**：规格 7 行为 38 条验收标准 ↔ 测试锚点（delivery 194 例 16 类 + gateway 35 例 7 类 + 前端交付域 6 spec 73 例）↔ 剧本步骤全量勾稽回填任务卡 §三。立卡盘点结论：**验收标准层面零净缺口**（锚点类#方法级全承载、双向用例四条链路面双腿齐备、防枚举/幂等全覆盖）——本件以复验确认为主，不产新实现。
2. **补测净口子**（唯一测试侧实质缺口 + 逾期债务测试面吸收）：
   - **B2 跨域对账锚**：deliveries 单一事件源按形态行数 ≡ 放行/成功路径计数的收敛自动化锚（拒绝与未放行路径零新增行）；跨域本体（合约 usage_log/counter）**不做跨库自动化连接**——真链只读 SELECT 对账 + 对账本体转移 3.7.x 登记（3.4.8 B1 同款口径与诚实边界）；
   - **DB-50**：gateway `DeliveryCredentialGlobalFilter` 非法 UTF-8 负向子路径补 1~2 例（统一时钟口径 `gatewayNanoClock` 注入已随 3.5.2 修复批在位，顺带覆盖）；
   - **DB-53 八项负向用例逐项核对**：TOCTOU / check 空体 / 预检拒绝审计 / pageNum 非数字 / 序号上界 / realpath / null body / 空号——部分或已被后续批次用例承载（如 3.5.6 下载空主体拦截），逐项核对后**未覆盖才补、已覆盖登记收口**；
   - **gateway 择项**（3.5.2 补登记 15）：T3 后半审计 FAILURE 事件字段断言 + T10 空白名单起点；其余边界缺口（畸形 JWT/空 roles/上游 5xx 计量口径/限流并发）维持登记留痕。
3. **行覆盖实测达标数字**：jacoco 0.8.12 命令行临时注入（零 pom 变更）实测 delivery-service 行覆盖 **≥70% 判定**（ADR-018 overall 档）+ gateway-service 数字留痕；**只测量不开门禁**（沿 3.4.8 Q2-A）。
4. **两剧本真链联调**：演示环境复验 C-5.1/C-5.2 关键链 + ⚙ 技术侧步全量补走 + **网关 8086 交付链真调补验**（3.5.6 走查全经 5173→8087 直连，网关链未复验）+ G8 治理面抽验；"与计费联调" = B2 + 对账本体转移 3.7.x 登记（3.7.5/3.7.6 未开工的依赖边界沿 3.4.8 声明口径）。

## 2. 不做什么（边界清单）

- **零业务功能**：不新增端点/字段/状态/错误码/库表/迁移，不改任何 src/main 与前端业务代码（Q4-B 获裁的 F-W1 ≈3 行除外——裁决前不碰）；
- **零门禁配置改动**：不改 gates-config.json / run-gates.ps1 / CI workflow（红线 3）；coverage 档位修正、mutation 纳入归门禁增强卡；
- **零演示库脚本接触**：不跑造数/清理脚本（DB-64 红线）；业务流产生的新留置并入 DB-64 第⑤段登记；沙箱容器清场不属库清理（沿 3.5.6 清场口径）；DB-64 本体清理归下次真机演示前人工处置；
- **评估件零实施**：受控执行端点退役、ADR-025 §6 四项收敛重构、DB-54 实现口径固化、DB-56~62 各项、E-5 菜单按档隐藏、前端代理单入口切换（Q5-A 默认）——本卡只出评估结论/再排期建议/裁决建议留痕；
- **不碰他域**：contract/policy/metering 域测试零改动（B2 只落 delivery/gateway 测试）；3.6.x 连接器、3.7.x 计量计费、3.8.x 存证、3.9.x 部署收口均不涉；
- 发现实现与已确认口径不一致 → 停止上报编排师，不擅自修（红线 4）。

## 3. 待确认问题（Q1~Q5 详述）

### Q1 联调形态与造数收口

- **背景**：WBS 行 294 要求"与策略引擎/计费联调"。策略引擎联调面 = 交付链 `check` 消费真链（3.5.2/3.5.4/3.5.5 走查已多轮实证）；计费（3.7.6）未开工，只能做对账数据源准备。**关键差异 vs 3.4.8**：本域 DB-64 明令严禁对演示库跑造数/清理脚本 → 3.4.8"造→验→清三步收口"在本域**不适用**。
- **A（建议）**：演示环境真链复验两剧本关键链（C-5.1 S1 网关合规调用/幂等 + S2 文件交付全链 + S3 防枚举直调；C-5.2 S1 开通 + S2 作业与审核 + S3 导出与绕过被拒）+ ⚙ 技术侧步全量补走 + 网关 8086 链真调 + G8 抽验；**新增留置并入 DB-64 第⑤段登记**（联调前 SELECT 快照留档、联调后增量对照）+ 沙箱容器清场 + 真链只读 SELECT 对账留痕（deliveries 按形态 ≡ 合约 used_count 增量，沿 3.5.5 走查对账口径）。理由：真链价值最高、与 DB-64 红线兼容、增量留置可控并登记。
- **B**：独立测试库/容器全造全清（脱离演示环境，环境重建成本超 1 会话预算，且失去"演示环境可复演"价值）。
- **C**：仅自动化门禁不联调（"联调"要求落空，不可期）。

### Q2 达标口径与门禁边界

- **A（建议）**：jacoco 0.8.12 命令行临时注入（`org.jacoco:jacoco-maven-plugin:0.8.12:prepare-agent test report`，agent 仅临时落 target/，零 pom/依赖变更）实测 **delivery-service 行覆盖 ≥70%**（ADR-018 overall 档现行口径；不在 coreModules 属设计现状）+ gateway-service 同批实测数字留痕 + 用例数只增不减 + 全仓门禁 GREEN；**档位修正与 PIT 纳入归门禁增强独立卡**（沿跟踪-20/DB-43）。理由：沿 3.4.8 Q2-A 完全同款先例，只产出达标数字不越门禁红线。
- **B**：接入门禁（改 gates-config/pom——红线 3 越界）。
- **C**：不测覆盖率（无达标数字，"测试达标"无从判定）。

### Q3 债务与移交吸收范围

- **A 全吸收（建议）**：补测 B2 + DB-50 + DB-53 逐项核对 + gateway 择项（T3/T10）+ **DB-63/66 裁决建议**（建议维持现状：权限层 `1000C0005` 先拦 = fail-closed 正确分层 + 最小泄露，界面已按统一权威文案展示〔3.5.6 E-5 走查实证〕；裁决维持即双条关闭——裁决权在编排师）+ **DB-65 顺手文案勘正**（hifi §5 快照不一致拒绝文案与状态机对齐，纯文档一句）+ **DB-54/56~62 再排期建议留痕**（时限多已逾期，逐项给出归属批次建议）+ **ADR-025 §6 演进债 4 项评估留痕** + **受控执行端点退役评估留痕**（ADR-021 §2.10 触发条件已成立；倾向结论"维持至 3.7.5 计量落库后再退役"，编码会话按演示依赖实证后定稿）+ **性能豁免留痕**（正式压测归 4.2.3，沿 3.4.8 Q5-A）+ **台账计数残段补记**（L1-3 39/73→40/73、V1.0 68/136→69/136、DB-64 行补 ④ 段、关闭统计刷新——3.5.6 收口批未落账部分，grep 实测为准）。理由：均为测试面/文档面/评估面，与本包性质同型；沿 3.4.8 Q3-A"全吸收八项"先例。
- **B**：仅义务项 B2 + DB-50，余挂账（逾期债务继续悬空，不可期）。
- **C**：全挂账（同上不可期）。

### Q4 F-W1 搭车裁决

- **背景**：F-W1 = run-job 成功后结果物区不自动刷新（`SandboxDetailView.vue:431-433`，重进即现、服务端正确），台账登记"随下一前端卡顺手修"。本卡联调若重演 run-job→结果物链会再次踩到该现象。
- **A（建议）**：不吸收归下一前端卡——测试包不碰前端业务代码（纪律边界），台账口径维持。
- **B**：本卡顺手修（约 3 行刷新逻辑 + 前端门禁复跑）——省一次前端门禁往返，但前端业务代码改动超测试包边界，须编排师显式裁定。

### Q5 前端代理与部署单入口切换（3.5.2-hifi §12 行 168 逾期项）

- **背景**：3.5.2 高保真设计建议"前端代理与部署单入口收敛归 3.5.6/3.5.7 前统一执行"（vite/nginx API 转发统一改指网关 8086 = ADR-005 唯一流量入口）；3.5.6 未执行（E-1：nginx 零改动、vite 直连 8087），时限已逾期。
- **A（建议）**：本卡不执行 + 评估留痕转后续部署收口批次（3.9.1 侧）——属部署配置变更非测试面；联调演示口径维持 vite 直连 8087（沿 3.5.6 E-1）。
- **B**：本卡执行切换（vite/nginx 转发键改指 8086 + 前端门禁复跑 + 走查口径更新）——超测试包边界，须编排师显式裁定。
