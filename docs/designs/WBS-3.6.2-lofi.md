## §1 做什么（业务可读行为清单，8 条）

> SDK = **参与方业务系统接入平台的标准化客户端库**（"六项功能以连接器 SDK 框架承载"——规格行为 2 规则 1）；业务能力全部由平台对应域提供，SDK 只做统一封装，**零第二业务口径**。

1. **六项功能一站式门面（行为 2 规则 1 映射表）**：参与方业务系统引入一个 SDK，即可经**六个能力门面**（身份管理 / 资源管理 / 产品管理 / 合约管理 / 交付 / 使用控制）发起六类业务动作——每门面对应平台既有端点（映射表见 hifi §5），**同一主体身份、同一校验、同一留痕、同一错误语义**（行为 2 规则 2 路由一致性）。
2. **身份锚随行（行为 1 规则 2 / Q2-A）**：SDK 以**所属主体 DID 为身份锚** + 连接器编号作实例标识（编号由 3.6.3 平台侧签发，骨架期为上下文占位）；SDK **不另设独立身份、不自行注入身份头**（网关剥离伪造身份头，权威身份由平台侧认定）。
3. **平台调用统一入口（ADR-005/022）**：SDK 全部平台调用经**单一入口地址**（默认平台网关）+ **Bearer 令牌**（令牌来源可配置：演示期静态令牌，生产令牌体系归 3.9.1）；**不直调平台内部端点**（内部判定端点权限隔离）。
4. **交付腿凭据不变（行为 4）**：经 SDK 发起交付，凭据 = **已生效合约**（未生效 / 已终止 / 已完结合约由平台按合约域状态门槛拒绝，SDK 原样接收拒绝语义）；SDK 为**需求方侧发起端**，幂等键自动携带。
5. **使用控制消费判定 + fail-closed（行为 5 / Q6-A，硬约束）**：SDK"使用控制功能" = **凭合约凭据发起使用请求 + 接受平台判定结果**——放行则续行、拒绝即终止且**不重试**、判定服务不可达**抛异常绝不放行**；**SDK 内不存在任何本地放行路径**；"策略生效放行"与"越界拒绝"**双向必有**（AGENTS §4，单测承接）。
6. **适配器框架就位（行为 11 / 行为 12~14 框架级）**：SDK 定义**适配器 SPI**（四类源：政务共享交换平台 / 数据库 / 对象存储 / API 网关）——源接入登记模型（**凭据引用制，模型无明文凭据字段**）、连通性自检（只读探测，三类失败原因可枚举）、取数接口（先判定后取数契约注记）；**实现类零个**（归 3.6.5 / 3.6.6）。
7. **错误语义零新增（Q9-A）**：平台拒绝时**原码原文透传**（连接器异常携带平台错误码与文案，不二次包装）；SDK 自身错误仅中性三分类（平台不可达 / 调用超时 / 配置缺失），**不占用 1010 段码值**（码值归 3.6.3 落定）。
8. **可编译可测试可审计**：骨架交付 = 模块挂载根 pom + 全量单测（mock 平台响应，不依赖运行态）+ checkstyle 通过；六门面与 SPI 的接口签名即**对外契约**（将来分仓分发时冻结，ADR-002 §3-2）。

**本卡不做（划清）**：适配器四类源实现（3.6.5 / 3.6.6）/ 注册核验与 DID 绑定、升级注销（3.6.3 / 3.6.4 平台侧服务）/ 管理控制台（3.6.7）/ 端到端接入演练（3.6.8）/ 网关路由扩面（登记演进项）/ 轻量化连接器（C-6.4 = P1）与智能连接器（C-6.5 = P2）/ 真实政务平台对接（部署实施期）/ 设备级凭证体系（3.9.1）。

## §2 不做什么（边界划清）

1. **不实现任何业务判定**：主体资格 / DID 状态 / 产品与合约状态 / 策略判定 / 计量存证一律以平台为准（规格 §6-8"资格与状态口径唯一"）；SDK 无任何"跳过判定 / 强制放行"入参；
2. **不建数据存储**：SDK 无库、无迁移、无缓存业务数据（骨架零持久化）；
3. **不改既有服务与网关配置**（零 common 改动、零网关 yml 改动；网关扩路由登记演进项归 3.6.7 / 3.6.8 与部署期）；
4. **不占错误码码值**（1010 段留 3.6.3；平台码透传）；
5. **零加解密面**：凭据采引用制模型（加解密在平台侧 common 国密组件完成）；不自研、不内置任何密码学；
6. **零新第三方依赖**：仅用 Boot BOM 既有构件（spring-web RestClient / jackson）——`docs/dependencies.md` 无新登记项；
7. **不做注册申请门面**（行为 6~10 归 3.6.3 / 3.6.4；连接器编号在本卡为上下文占位）；
8. **不回改规格与剧本**（缺口走变更流程；三份 C-6.x 剧本零改动——S2 演示前提本就登记 3.6.2~3.6.7 交付后执行）；
9. **不夹带**：性能调优（登记制）/ 前端改动 / 部署编排（deploy/ 零触碰）。

### Q1 模块形态与依赖

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | **单 Maven 模块** `connector-sdk`（jar 库，一级目录，挂根 pom `modules` + `dependencyManagement`；parent relativePath `../pom.xml`）；**零新第三方依赖**（spring-web〔RestClient〕+ jackson 均为 Boot BOM 既有构件；测试用 spring-boot-starter-test + MockRestServiceServer）；显式声明 maven-checkstyle-plugin（沿 9 个服务模块惯例，common 未声明不跑——SDK 作为对外契约件从第一天受规范约束）；无 spring-boot-maven-plugin（库不 repackage，沿 common/crypto 先例） | 最小代价落实 ADR-002 规划位；依赖面最小（分仓分发时携带负担最小）；证据面完整（checkstyle 纳管 + 零新依赖 = 无供应链新增） |
| B | 拆 api / impl / spi 三子模块 | 接口与实现物理隔离，但骨架期三模块 pom + 发布坐标×3，体量膨胀近倍；V1.0 无第二实现方，YAGNI |
| C | 挂 services/ 下作服务模块 | SDK 是分发给参与方的库不是平台服务，目录语义错误（ADR-002 明文规划位 = 一级 connector-sdk/） |

### Q2 平台调用面与身份口径

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | **单一入口地址**（可配置，演示期默认 = 网关 8086）+ **Bearer 令牌**（TokenProvider 接口：静态令牌默认实现，可扩展刷新——生产令牌体系归 3.9.1）；SDK **不自行注入 X-Ctds-* 身份头**（网关剥离伪造头、按令牌注入权威身份——ADR-005 §3-7）；ConnectorContext 携 subjectNo / did / connectorNo（占位）作业务元数据随模型传递 | 与"网关唯一入口"架构方向一致（交付 / 使用腿 V1.0 网关即通）；身份零第二口径（Q2-A 不另设独立身份的 SDK 侧落实）；诚实边界：四读腿（身份 / 资源 / 产品 / 合约）端点路径按平台既有路径封装，**网关扩路由为演进项**（登记 ADR-026，归 3.6.7 / 3.6.8 与部署期），端到端受理验证归 3.6.8 |

| C | 本卡即扩网关路由把六域全暴露 | 改网关信任边界与配置（牵动既有剧本走查与全仓回归），超骨架包边界；路由扩面应随 3.6.7 / 3.6.8 统一设计 |

### Q3 六门面方法集（骨架期接口定型）

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 每门面 **2~3 个方法**（接口 + 默认实现），够承载规格框架面、不抢跑下游包：**身份**（查本主体登记详情 / 查 DID 状态）/ **资源**（登记数据集 / 查我的数据集）/ **产品**（发布产品 / 查我的产品）/ **合约**（创建磋商 / 查我的合约 / 查合约详情）/ **交付**（发起交付〔幂等键自动〕/ 查交付详情）/ **使用控制**（执行使用〔凭据 + 消费判定，三态〕/ 查用量汇总）；方法集 = 对外契约（ADR-026 固化），增补走版本演进 | 与 WBS 行 301"六项功能框架"对齐；剧本 C-6.1 S2 六腿动作各有一门面方法承载；避免骨架期过度设计（如全量 CRUD） |
| B | 全量对齐平台各域全部端点 | 体量×3 超预算；大量方法无规格承载面（违反最小实现） |
| C | 只出接口不写默认实现 | 骨架无法单测验证调用语义（fail-closed 三态等行为无承载），"可测试"关闭条件落空 |

### Q4 适配器 SPI 形态

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | SPI = `SourceAdapter`（`type()` / `check()` 只读自检 / `read()` 取数）+ `SourceType` 四枚举（政务共享交换平台 / 数据库 / 对象存储 / API 网关）+ 三个模型：`SourceRegistration`（源接入登记——**凭据引用制字段，模型无明文凭据**，行为 12 规则 2）、`SourceCheckResult`（**三类失败原因可枚举**：网络不可达 / 凭据无效 / 权限不足，行为 13 规则 2）、`SourceReadResult`；`read()` 契约注记"先判定后取数——判定拒绝时不得调用"（行为 14 规则 1）；**实现类零个**（归 3.6.5 / 3.6.6） | 框架边界干净（行为 2 规则 3）；3.6.5 / 3.6.6 有契约锚（ADR-026 固化）；凭据保护从模型层阻断明文路径 |
| B | SPI 连同数据库 / 对象存储等参考实现一起做 | 直接侵入 3.6.5 / 3.6.6 范围（WBS 行 305 / 306 独立预算），骨架包体量失控 |
| C | 不设 SPI，适配器接口归 3.6.5 再定 | 规格行为 11 明文"适配器随连接器分发（SDK 框架，3.6.2）"——SPI 是本卡义务；延后则 3.6.5 无上游契约 |

### Q5 fail-closed 语义（行为 5 硬约束落点）

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 使用控制 / 交付腿统一三态：**① 平台放行（2xx）→ 返回成功结果；② 平台拒绝（403/404/409 等）→ 抛连接器异常〔平台原码原文〕且不重试；③ 平台不可达（连接失败 / 超时）→ 抛连接器异常〔SDK 中性分类〕，绝不返回成功**；SDK 全库无"默认放行 / 忽略错误继续"路径；单测双向用例（放行 + 越界拒绝）+ 不可达用例（AGENTS §4 硬约束） | 规格行为 5 规则 2/3 逐字落实；判定语义唯一权威不破（SDK 消费结果不裁剪） |
| B | 不可达时返回缓存的上次判定 | 打破 fail-closed（缓存无失效语义），违反规格明文 |
| C | 拒绝后自动重试 N 次 | 违反"拒绝即终止"；重试属运维策略不是骨架语义 |

### Q6 错误语义

| 口径 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 平台错误**原码原文透传**（ConnectorException 携 platformCode / platformMessage）；SDK 自身错三分类（`UNREACHABLE` / `TIMEOUT` / `CONFIG`）无码值；**不占 1010 段**（Q9-A：码值与编号前缀随 3.6.3 落定） | 防枚举口径不破（平台同码同文原样到达参与方）；3.6.3 码值落定不受本卡掣肘 |
| B | SDK 统一改写为自有错误码 | 违反透传口径；且提前占用 1010 段与 Q9-A 冲突 |

### Q7 契约沉淀

- **A（建议）**：编码段新建 **`ADR-026 连接器 SDK 契约`**——固化：六门面与端点映射 / 身份锚与令牌口径 / 判定消费与 fail-closed 三态 / SPI 与凭据引用制 / 错误透传 / 诚实边界与演进（网关扩路由、真实联调 3.6.3 后另卡〔CHG-C-1.2-V1.1〕、分仓分发触发、3.6.5/3.6.6 消费面）+ ADR-016 §6 消费方补记评估（沿 3.5.2 Q9-A 新建 ADR-022 先例——下游适配器包与集成包需统一契约锚）。
- **B**：不新建 ADR，仅 hifi 记录（3.6.5 / 3.6.6 / 3.6.8 缺契约锚，将来分仓分发无固化依据）。

### D1 体量与拆分

建议**不拆分**：预估 850~1050 行有效变更（SDK 主代码 ≈450~600 + 单测 ≈300~400 + pom/ADR-026/文档 ≈100），为 WBS 行 301 单卡单目标（新模块骨架原子集，沿 3.4.2 / 3.5.2 先例）；拆则"门面无测试可验、测试无门面可跑"。

## §4 体量与预算

- 预算：WBS 行 301 = **1 会话**（编码交付；评审 / 修复 / 走查沿多会话先例另计）；
- 测试基线：新增 connector-sdk 模块用例**独立计数、只增不减**（沿 3.5.2 口径）；覆盖率按整体 ≥70% 线实测留痕（SDK 非核心六模块名单，不触发 ≥80% 档）；
- 风险预案：RestClient 为 Boot 3.2+ 主流客户端（对齐 Boot 3.5.16，无版本兼容风险）；MockRestServiceServer 绑定测试为主流写法；全仓门禁 GREEN 基线沿 3.5.7 `gate-report-20261025-203400`。

## §5 边界值与异常行为（业务可读）

| 场景 | 期望行为 |
| --- | --- |
| 平台放行的使用 / 交付请求 | 返回成功结果（与平台直接操作同语义） |
| 越界使用（超次数 / 超期 / 用途不符 / 域外 / 再分发） | 抛连接器异常（**平台原码原文**，如 1008C0020→HTTP 403）；**不重试、不触达源** |
| 未生效 / 已终止 / 已完结合约发起交付 | 抛连接器异常（沿合约域状态门槛原码，如 1008C0013→409） |
| 合约不存在 / 非参与方 | 抛连接器异常（原码，同码同文防枚举） |
| 平台不可达 / 调用超时 | **fail-closed**：抛连接器异常（SDK 中性分类 UNREACHABLE / TIMEOUT）——**绝不返回成功** |
| 入口地址 / 令牌未配置 | 启动即抛 CONFIG 异常（fail-fast，不静默降级） |
| 连接器编号未注入（3.6.3 未上线期） | 上下文容忍占位（null）+ Javadoc 注明；编号签发后注入即可用 |
| 适配器实现尝试携带明文凭据 | **模型层无明文途经**（SourceRegistration 仅凭据引用字段）——编译期阻断 |
| 未登记源发起读取（SPI 实现方义务） | 契约注记 + ADR-026 固化"默认拒绝"（登记制，行为 11 规则 2） |
| 绕过 SDK 直调平台 | 与经 SDK **同一判定面**（服务端强制不变——SDK 不是也不成为旁路） |
