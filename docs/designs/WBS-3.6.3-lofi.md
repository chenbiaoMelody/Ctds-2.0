## §1 做什么（业务可读行为清单，9 条）

1. **提交注册申请**：参与方以本人身份提交连接器名称 / 类型 / 版本 → 平台登记为「**待核验**」，返回**申请单号**（`CA` + 6 位）与当前状态；申请者身份由服务端从登录上下文取，**请求体不含主体编号**（防越权自报）。
2. **接入前提把关**：未入驻 / 非 ADMITTED 主体提交申请 → **拒绝**（业务可读理由 + 留痕，防枚举同文）。
3. **防重**：同一主体**同名**（忽略大小写与首尾空白）连接器只能有一条**活跃**档案；重复申请 → 提示重复，**不新建档**。
4. **待核验队列**：平台运营方可查看待核验申请列表（分页，申请时间升序），并逐条发起核验。
5. **核验三查**：① **主体资格**（所属主体 ADMITTED，读主体域内部面）；② **DID 有效**（所属主体当前 DID 存在且状态 ACTIVE，读 DID 域内部面）；③ **信息完整**（要素齐备、格式合规）。三查全过 → 状态转「**已注册**」+ **签发连接器编号**（`CN` + 6 位，全局唯一、终身不复用）+ **建立「连接器 ↔ 所属主体 DID」绑定**；全程留痕（谁核 / 何时 / 对象 / 结论）。
6. **核验拒绝**：任一查不通过 → 核验结论 = **拒绝**（可读理由标明哪一查 + 留痕），档案**保持待核验**；申请人**补正要素**后可再次提交核验，留痕链完整。
7. **绑定与 DID 状态联动（fail-closed）**：绑定查验返回「连接器 ↔ DID ↔ 建立时间」+ **实时** DID 状态；DID 已吊销 / 非 ACTIVE → 查验结论 = **不通过**（如实反映，不缓存、不冒充有效）；DID 服务不可达 → **503，绝不放行**。
8. **最小健康度**：已注册连接器可**上报心跳**；平台按「最近心跳是否超时」**读时派生**在线 / 离线（阈值可配，默认 5 分钟）——只做上报与派生，不做调度与告警（展示归 3.6.7、监控归 3.9.4）。
9. **内部消费面**：其他平台服务可凭连接器编号读取「连接器 + 绑定 + 实时 DID 状态」，供 3.6.4（生命周期）/ 3.6.7（控制台）/ 3.6.8（集成演练）与 SDK 编号校验消费——单一事实源在本服务，**不复制到消费方库**。

## §2 不做什么（边界划清，9 条）

1. **不做升级 / 版本兼容 / 注销**（规格行为 9~10 归 **3.6.4**）——状态机的「已注销（CANCELLED）」取值在 V1 建表时**预留**（列注释全量定义、字段与索引按注销后同名重注册口径设计），**代码不实现该流转**。
2. **不做适配器**（行为 11~14 归 3.6.5 / 3.6.6）；**不做管理界面**（归 3.6.7，本卡只交接口）；**不做端到端接入演练**（归 3.6.8）。
3. **不设连接器独立身份**（Q2-A）：不签发连接器 DID、不引 API Key / 证书体系；身份锚 = 所属主体 DID，实例标识 = 连接器编号。
4. **不回改 C-1.1 入驻流程**（Q3-A）：连接器注册是入驻后的**独立业务动作**，只读消费主体入驻状态。
5. **不自研密码学、不落任何凭据明文**：本卡业务面**无凭据字段**（源凭据归 3.6.3 之外的 3.6.6）；连接器编号与 DID 均非秘密材料。
6. **不改既有服务业务语义**：全卡只允许**两处装配接触**（详见 hifi §8）——① 主体服务 `application.yml` **加 1 行**角色映射（`connector-internal: subject.internal.read`）；② DID 服务**新增 1 个内部只读端点**（`did.internal.read`）+ `application.yml` **加 1 行**角色映射 + ADR-017 补记。两处都**零业务判定改动**、零既有端点语义改动。
7. **不动网关与路由**：本卡端点一律**服务直连**（演示期回环边界，ADR-016 §2.7）；网关路由扩面仍登记为演进项（ADR-026 §4-1 沿承），不在本卡做。
8. **不做点对点直传、不做策略本地执行、不做计量 / 存证**（规格 §4 非目标 5/6/10 沿承）。
9. **不碰演示库**（DB-64 沿承）：本服务新库 `ctds_connector` 由 Flyway 自建；造数 / 清理脚本严禁对演示库执行。

## §5 边界值与异常行为（业务可读）

| 要素 | 规则 / 边界 | 违反时 |
| --- | --- | --- |
| 连接器名称 | 去首尾空白后 2~64 字符；同主体同名（忽略大小写）活跃档案唯一 | 400 `1010C0001`；重复 → 400 `1010C0002` |
| 连接器类型 | V1.0 仅 `STANDARD`（轻量化 C-6.4 属 P1，非本卡） | 400 `1010C0001` |
| 版本号 | `主.次.修订`，每段 1~3 位数字（如 `1.0.0`） | 400 `1010C0001` |
| 申请单号 / 连接器编号 | `CA` / `CN` + 6 位；单调递增；终身不复用 | —— |
| 申请查询 / 补正 | 仅属主；非本人或不存在 → **同码同文** `1010C0003`（防枚举） | 400 `1010C0003` |
| 补正 | 仅 `PENDING_REVIEW` 态可补正名称 / 类型 / 版本；已注册态 → 状态门槛拒绝 | 400 `1010C0004` |
| 核验动作 | 仅 `PENDING_REVIEW` 态可核验；重复核验已注册档案 → 状态门槛拒绝 | 400 `1010C0004` |
| 核验三查顺序 | 主体资格 → DID → 信息完整；任一不过即拒绝（理由取首个不通过项） | 结论 = 拒绝（200 + `verified=false` + `reason`） |
| 主体未入驻 | 申请时前置检查 + 核验时第一查 | 申请 → 400 `1010C0006`（防枚举同文）；核验 → 结论拒绝 |
| DID 状态 | `ACTIVE` 才通过；`REVOKED` / `PENDING_ISSUE` / `NONE` 一律不通过 | 核验 → 结论拒绝（`1010C0007` 理由码）；绑定查验 → `verified=false` |
| 跨域不可达 | 主体服务 / DID 服务不可达、超时、非 200、响应不可解析 | 503 `1010S0001`（主体）/ `1010S0002`（DID）——**fail-closed，不冒充结论** |
| 心跳 | 仅 REGISTERED + 属主；阈值 1~1440 分钟（默认 5） | 400 `1010C0004`（非注册态）/ `1010C0003`（非属主，同码同文）/ 400 `1010C0001`（阈值配置越界时启动 fail-fast） |
| 分页 | `pageNum` 1~10000 / `pageSize` 1~100 | 400 `1000C0001`（common-pagination 既有口径） |
| 留痕 | 申请 / 补正 / 核验（含拒绝理由）/ 绑定建立 / 绑定查验 / 心跳；**不含**任何秘密材料 | —— |
