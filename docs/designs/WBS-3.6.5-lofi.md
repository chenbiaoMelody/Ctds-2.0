## §1 做什么（业务可读行为清单，9 条）

1. **源接入登记（四类源全受理）**：连接器属主为**已注册**连接器登记源——填写**源类型**（政务共享交换平台 / 数据库 / 对象存储 / API 网关）、**源地址**、**访问凭据**、**所属连接器**；登记成功签发源编号 `SR` + 6 位，全程留痕。四类源**均可登记受理**（行为 11 验收 1）。
2. **凭据国密保护（硬约束）**：访问凭据经 `common` 国密组件**加密存储**；对外只回显**掩码**（如 `****abcd`）与**不透明凭据引用**；任何接口响应、留痕、日志**无明文**。
3. **配置变更留痕**：可变更源地址与凭据（可选）——留痕记录**旧 / 新要素**，凭据仍以掩码呈现；变更后可重新自检。
4. **归属与防枚举**：源只对**所述连接器的属主**（或运营方读面）可见；非本归属 / 不存在的源一律**同码同文拒绝**（`1010C0003`），不泄露该源是否存在。
5. **连通性自检（政务源）**：对政务共享交换平台源发起**只读探测**（连通 / 凭据 / 权限三查）——**通过 = 业务结论成功**（状态码 200），**失败 = 三类可读原因**（网络不可达 / 凭据无效 / 权限不足）+ 失败留痕；自检**不产生源端数据变更**，自检通过**不构成业务授权**（行为 13-3）。
6. **政务标准报文模拟源（诚实承载）**：V1.0 政务共享交换平台以**标准报文模拟源**承载——适配器按标准请求 / 响应报文与源交互；模拟源为**演示期专用**、界面与文档**如实标注"模拟"**，不虚称已对接真实政务平台（行为 11-3 / 规格 §6-3）。
7. **未开放源类型的诚实拒绝**：数据库 / 对象存储 / API 网关三类在 3.6.6 前**可登记、不可自检 / 不可读取**，拒绝时明确提示"该源类型的适配承载尚未开放"，**不假装支持、不虚报通过**。
8. **读取能力就位（先判定后取数）**：提供**内部读取端点**供交付链在**使用控制判定放行后**调用；适配器读取返回**摘要**（不含数据本体与原文）；读取留痕**五要素**（谁 / 何时 / 哪个源 / 哪份合约 / 结果）。**判定次序与触达控制在交付链（3.6.8）**——本卡不建第二判定语义。
9. **注销后的源口径**：连接器注销后其源**不可读取**（读面校验连接器已注册），但源档案与留痕**保留可查**（历史可追溯）；注销**不级联删除源**。

## §2 不做什么（边界划清，10 条）

1. **不做三类通用源适配器**（数据库 / 对象存储 / API 网关，归 **3.6.6**）；本卡只实现 `SourceType.GOV_EXCHANGE` 一个适配器。
2. **不做管理界面**（连接器列表 / 健康度 / 版本管理页，归 **3.6.7**）；本卡只交接口。
3. **不做端到端接入演练与交付链改造**（网关路由扩面、交付链取数次序、SDK 端到端受理，归 **3.6.8**）；本卡**不改网关任何配置、不改交付域**。
4. **不做真实政务共享交换平台生产对接**（规格 §6-3 / §7 Q7-A：属部署实施期事项，不在 V1.0 承诺范围）。
5. **不自建策略判定、不复制判定语义**（ADR-019 / ADR-020 单点权威）：本卡读取端点不自校验合约态、不调合约域判定端点。
6. **不做源停用 / 启用 / 注销状态机**（规格未定义源生命周期动作）；源只有"已登记"一态，仅支持变更。
7. **不回改 3.6.3 / 3.6.4 既有 21 端点语义**（只做加性：新表、新端点、新错误码、新权限点、新审计动作常量，`application.yml` 与 pom 加行）。
8. **不把政务适配器落进 `std-adapter`**：`StdDomain` 四值固定、新增域须 ADR-008 变更（本卡 1 会话内不做架构变更）；政务共享交换对接属"业务源适配"，与信通院互联互通标准层解耦（Q1 决策，见 §3）。
9. **不改网关与路由、零新第三方依赖、零门禁配置改动**：仅新增 2 个**模块依赖**（`connector-sdk` 与 `common-crypto`，均为既有构件，非第三方坐标）。
10. **不碰演示库**（DB-64 沿承）：`ctds_connector` 结构变更走 Flyway；造数 / 清理脚本严禁对演示库执行。

## §3 决策点与确认留痕（Q1~Q8 + D1，✅ 2026-10-27 一次确认）

### Q1 适配器实现落位（**本卡关键裁决**）

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 适配器实现放 **`connector-sdk` 内新增 `adapter/gov` 包**（`GovExchangeSourceAdapter implements SourceAdapter`，随 SDK / 连接器分发，兑现行为 11-1"适配器随连接器分发"）；平台侧 `connector-service` 新增对 `connector-sdk` 的**模块依赖 1 行**，服务内以 `SourceAdapterRegistry` 按源类型装配并编排自检 / 读取 | 与规格"随连接器分发（SDK 框架）"逐字一致；**零新模块、零根 pom 改动、零门禁配置改动**；3.6.6 沿用同包结构（`adapter/jdbc` / `adapter/oss` / `adapter/http`）即可；平台服务与连接器共用同一份适配器代码，行为一致、无双实现 |
| B | 新建一级模块 `connector-adapters/`（每类源一个子模块） | 分仓分发形态更纯粹，但需新模块骨架 + 根 pom + 打包/门禁扫描面 + 3.6.6 再复制一层；1 会话预算内风险高，收益在 V1.0 演示期体现不出 |

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |

### D1 体量与是否拆分

**建议不拆分**：预估 **1100~1500 行**（迁移 2 表 ~70 / SDK 适配器 ~250 / 服务侧 ~450 / 测试 ~400 / ADR-029 ~100）。理由：源登记 → 凭据保护 → 自检 → 读取是**同一条能力链**，拆开会出现"能登记不能自检"或"能自检不能取数"的不可验收中间态；且 3.6.6 依赖本卡的登记面与适配器注册机制，拆分会让 3.6.6 二次返工。沿 3.4.2 / 3.5.4 / 3.6.2 / 3.6.3 / 3.6.4 同款先例；**超 400 行指引说明**随任务卡 §五登记。

## §5 边界值与异常行为（业务可读）

| 要素 | 规则 / 边界 | 违反时 |
| --- | --- | --- |
| 源类型 | 四值：`GOV_EXCHANGE` / `DATABASE` / `OBJECT_STORAGE` / `API_GATEWAY` | 非法值 → 400 `1010C0001` |
| 源地址 | 必填，1~512 字符；`mock://` 仅政务源可用（演示期模拟源）；`http://` / `https://` 为真实源形态 | 空 / 超长 → 400 `1010C0001`；非政务源用 `mock://` → 400 `1010C0001` |
| 访问凭据 | 必填，1~256 字符（明文仅在请求体内，**不落日志、不回显**） | 空 / 超长 → 400 `1010C0001` |
| 登记前置 | 连接器存在 + **属主本人** + 状态 `REGISTERED` | 非属主 / 不存在 → 400 `1010C0003`（同码同文）；非注册态 → 400 `1010C0004` |
| 重复登记 | 同连接器 + 同源类型 + 同源地址 | 400 `1010C0001`（提示改用变更） |
| 凭据保护可用性 | 密钥不可用（未配密钥文件 / KMS 不可达） | 503 `1010S0004`（**fail-closed，禁止明文降级**） |
| 源归属 | 源必须属于路径中的连接器；读面仅属主或运营方 | 否则 400 `1010C0003`（不泄露源是否存在；跨归属同一文案） |
| 自检前置 | 连接器 `REGISTERED`；源类型有适配器承载 | 非注册态 → 400 `1010C0004`；类型未开放 → 400 `1010C0011` |
| 自检结论 | 200 业务结论：`passed=true` 或 `passed=false` + 三类失败原因（`NETWORK_UNREACHABLE` / `INVALID_CREDENTIAL` / `INSUFFICIENT_PERMISSION`）+ 可读文案 | 非预期异常 → 502 中性文案（不暴露内部），留痕 `FAILURE` |
| 读取前置 | 内部服务身份；连接器 `REGISTERED`；源归属；类型有适配器 | 非注册态 → 400 `1010C0004`；源不存在 / 跨归属 → 400 `1010C0003`；类型未开放 → 400 `1010C0011` |
| 读取结果 | `success` + 摘要（**不含数据本体与原文**）；留痕五要素 | —— |
| 变更留痕 | 旧 / 新源地址入留痕；凭据只记"已变更 + 掩码" | —— |
| 读取合约号 | `contractNo` 必填，1~64 字符，字符集 `[A-Za-z0-9._-]`（与网关凭据头口径一致）；`purpose` 可空 ≤128 | 400 `1010C0001` |
| 分页 | `pageNum` 1~10000 / `pageSize` 1~100（清单按需） | 400 `1000C0001`（common-pagination 既有口径） |
| 留痕 | 登记 / 变更 / 自检（成功与失败）/ 读取 / 拒绝访问；**不含任何秘密材料** | —— |
