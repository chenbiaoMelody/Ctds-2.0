## §1 做什么（业务可读行为清单，8 条）

1. **数据库源可自检、可读取**：连接器属主为已注册连接器登记**数据库源**（`jdbc:mysql://主机:端口/库`）——自检做**只读探测**（连通 / 凭据 / 权限三查），读取返回 **schema 级摘要**（库名、表数量量级，**不含任何行数据与原文**）；全程不执行用户提交的 SQL。
2. **对象存储源可自检、可读取**：登记**对象存储源**——源地址填对象定位（对象 URL 或 `s3://` / `oss://` 定位），访问凭据填提供方生成的**预签名 URL**；自检发只读 `GET`/`HEAD`，读取返回**对象元数据摘要**（字节数、内容类型），**不含对象内容**。
3. **API 网关源可自检、可读取**：登记 **API 网关源**（`https://` 地址），访问凭据填完整 `Authorization` 头值（如 `Bearer …`）；自检发只读 `GET`，读取返回**响应元数据摘要**（状态、字节数、内容类型），**不含响应体**。
4. **统一的失败原因口径**：三类源自检失败均给出可读原因——**网络不可达 / 凭据无效 / 权限不足**；无法归类的系统异常走 502 中性文案，**不猜测、不虚报**。
5. **调用边界的主机防护（DB-91）**：自检与读取在真正触达源之前，对主机做**域名解析后判定**——解析到回环 / 内网 / 链路本地一律拒绝且**零触达**；对象存储的预签名 URL 主机同样纳入判定；登记与变更受理期不联网（避免校验期联网与 DNS 漂移）。
6. **凭据保护口径不变**：三类源的凭据仍经 `common-crypto` **SM4 加密存储**、对外仅显**掩码**、任何响应 / 留痕 / 日志**无明文**；密钥不可用 → 503 fail-closed，禁止明文降级。
7. **访问形态的诚实声明**：对象存储 V1.0 **只支持预签名 URL 形态**（不支持 AK/SK 现场签名，避免自行实现密码学）；数据库 V1.0 **只支持 MySQL 协议**（JDBC 驱动由运行宿主提供）；API 网关 V1.0 支持 **Bearer / 自定义 Authorization 头**。三类均不支持写入与任意查询。
8. **自检结论读法收口（DB-90）**：源详情里的"最近一次自检结论"改由**统一留痕读面**获取（按动作 + 源编号前缀取最近一条），不再由源仓储自造一套直读 SQL；对外表现与响应字段**零变化**。

## §2 不做什么（边界划清，10 条）

1. **不做政务源改造**（3.6.5 已交付，模拟源口径不变）。
2. **不做管理界面**（连接器列表 / 健康度 / 版本管理页，归 **3.6.7**）。
3. **不做端到端交付链改造**（网关路由扩面、交付链路取数次序、"判定拒绝不触达源"的完整证明，归 **3.6.8**）。
4. **不做源停用 / 注销状态机**（规格未定义源生命周期动作）。
5. **不实施 DB-88（运营方读面口径）**：规格行为 12 验收 3 与既有运营方读面冲突，**须先走规格变更流程**；本卡只提示，不改权限与可见性。
6. **不做 AK/SK 现场签名**（对象存储 SigV4 / OSS 签名属密码学实现，违反 AGENTS 原则 7）；如业务必须，走新依赖审批 + 变更流程。
7. **不执行用户 SQL、不做数据抽取**（数据库只跑固定只读探针与元数据查询）；不做对象内容 / 响应体回传（`read()` 只回摘要）。
8. **不新增端点、迁移、权限点**：复用 3.6.5 的 6 端点与 `connector_source` 表；**零回改** 3.6.3 / 3.6.4 / 3.6.5 端点语义（凭据长度上限放宽属加性校验调整，见 §5）。
9. **不默认放开内网**：`allow-private-endpoint` 默认 false 不变；演示 / 测试显式放开，且放开决定留痕在配置与文档。
10. **不改网关与路由、零新第三方依赖、零门禁配置改动、不碰演示库**（DB-64 沿承）；造数 / 清理脚本严禁对演示库执行。

## §3 决策点（Q1~Q9 + D1，提请一次确认）

### Q1 三类适配器的依赖策略（**本卡关键裁决**）

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | **零新增第三方依赖**：三类适配器只用 JDK 标准 API（`java.sql` / `java.net.http` / `java.net.URI`）+ 既有 `spring-web`；数据库驱动由**运行宿主**提供（`connector-service` 已有 `mysql-connector-j`，SDK pom 零改动） | 供应链零新增（无新坐标、无新 CVE 面、无 `dependencies.md` 变更）；SDK 保持"轻量分发"；诚实边界 = 连接器部署方需自带 JDBC 驱动（文档明示）；牺牲 AK/SK 现场签名能力（见 Q2） |
| B | 引入 MinIO 官方 SDK（`io.minio:minio`）支持 AK/SK 直连 | 能力更接近生产（临时凭证 / 分片 / 预签名生成）；但需**新依赖审批 + 注册表核验 + 供应链扫描 + 锁定文件登记**，SDK 传递依赖与体积增加，1 会话预算与门禁风险上升 |
| C | 三类源只做进程内模拟源（不连真实源） | 直接虚报能力（行为 11 / 13 失真），不可选 |

### Q2 对象存储访问形态

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | **预签名 URL 形态**：源地址登记对象定位（`https://…/bucket/key` 或 `s3://bucket/key`），访问凭据 = 提供方生成的**预签名 URL**（含签名参数）；适配器只发 `GET`/`HEAD`，并对**凭据 URL 的主机**做解析级校验 | 零签名实现、零新依赖、符合"禁止自行实现密码学"；提供方侧一次性生成 URL，演示与验收可操作；诚实边界 = 预签名 URL 有有效期，过期后需变更凭据（登记为操作说明） |
| B | AK/SK + SDK 签名 | 支持长期凭证与自动续签，但依赖 Q1-B（新依赖审批），且签名链属密码学实现面 |
| C | 仅支持公开读对象（无凭据） | 与行为 12"访问凭据必填 + 国密保护"硬约束冲突，不可选 |

### Q3 数据库适配的安全与只读口径

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 自检 = `SELECT 1`（连通 + 凭据）+ 连接 `setReadOnly(true)`；读取 = 查询 `information_schema` 取 schema 级摘要；**JDBC URL 安全参数白名单**（允许 `sslMode` / `useSSL` / `requireSSL` / `characterEncoding` / `serverTimezone` / `connectTimeout` / `socketTimeout` / `allowPublicKeyRetrieval`；**显式拒绝** `allowLoadLocalInfile` / `allowUrlInLocalInfile` / `autoDeserialize` / `allowMultiQueries` / `allowMultiQueries` 等危险参数） | 阻断 MySQL JDBC 已知的本地文件读取与反序列化攻击面；只读探针不产生源端变更；摘要不含业务数据；参数白名单可能拒绝个别合法参数，按变更流程扩充 |
| B | 只连接不查询 | 权限维度不可验证（行为 13 三查缺一），剧本 S1-6 无法对应 |
| C | 放开全部 JDBC 参数 | `allowLoadLocalInfile` / `autoDeserialize` 等可直接导致源端文件读取或反序列化，不可选 |

### Q4 三类失败原因的映射口径

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 按协议特征映射：连接失败 / 超时 / 解析失败 → `NETWORK_UNREACHABLE`；HTTP 401 / SQLState `28xxx` / MySQL 1045 / 签名类 403（`SignatureDoesNotMatch` / `InvalidAccessKeyId` / 过期）→ `INVALID_CREDENTIAL`；HTTP 403 其它 / MySQL 1142·1044·1227 → `INSUFFICIENT_PERMISSION`；无法归类 → 非预期异常 502 中性 | 三类原因可机读、可对应剧本 S1 步骤 4~6；不把"系统故障"伪装成业务结论；映射依赖协议特征，真实源行为差异登记为观察项 |
| B | 失败一律记"网络不可达" | 原因不可读（违行为 13-2），剧本 S1 步骤 4~6 无法区分 |
| C | 403 一律记权限不足 | 对象存储签名过期会被误判为权限不足（误导排障） |

### Q5 DB-91 解析级校验的落点

| 选项 | 内容 | 业务影响 |
| --- | --- | --- |
| **A（建议）** | 新增 `SourceHostGuard` 端口 + 生产实现（`InetAddress.getAllByName`）：在**自检 / 读取调用适配器前**解析主机并判定回环 / 内网 / 链路本地 / 无法解析，命中即拒绝且**零触达**；对象存储**凭据 URL 的主机**、数据库 **JDBC 主机**一并纳入；登记 / 变更受理期不联网（保持 3.6.5 口径） | DB-91 闭环；每次调用前解析，避免"登记时安全、运行期内网"的漂移；解析失败按网络不可达（自检）/ 400 `1010C0010`（读取）；测试可注入解析器端口，结果确定 |

### D1 体量与是否拆分

**建议不拆分**：预估 **900~1200 行**（SDK 三类适配器 ≈ 450 / 服务侧加固与读面 ≈ 220 / 测试 ≈ 420 / ADR-030 ≈ 90）。理由：三类适配器与"解析级防护 + 失败映射"是**同一条可证伪能力链**（能登记 → 能自检 → 能读取 → 拒绝不触达），拆开会产生"部分源已适配"的不可验收中间态；沿 3.6.5 / 3.6.4 同款先例；**超 400 行指引说明**随任务卡 §六登记。

## §5 边界值与异常行为（业务可读）

| 要素 | 规则 / 边界 | 违反时 |

| 源类型 | 三类新增适配器：`DATABASE` / `OBJECT_STORAGE` / `API_GATEWAY`；`GOV_EXCHANGE` 不变 | 非法值 → 400 `1010C0001` |

| 访问凭据长度 | **上限由 256 放宽至 1024**（预签名 URL 可能超过 256）；密文列 `VARCHAR(2048)` 不变（1024 明文加密后约 1.4KB） | 超长 → 400 `1010C0001`；既有 256 边界用例同步改写 |
| 数据库凭据格式 | `用户名:密码`（按**第一个冒号**切分，密码可含冒号）；不含冒号 → 凭据无效 | 自检 200 + `INVALID_CREDENTIAL` |
| 数据库 URL 参数 | 白名单（见 Q3）；命中危险参数 → 400 `1010C0001` | 拒绝登记 / 变更 |
| 对象存储凭据格式 | 完整预签名 URL（`http(s)://`）；非 URL 形态 → 凭据无效 | 自检 200 + `INVALID_CREDENTIAL` |
| API 网关凭据格式 | 完整 `Authorization` 头值（如 `Bearer …`），原样出站 | 空 / 超长 → 400 `1010C0001` |
| 主机解析（DB-91） | 自检 / 读取前解析；命中回环 / 内网 / 链路本地 / 解析失败 → 拒绝且零触达 | 自检 200 + `NETWORK_UNREACHABLE`；读取 400 `1010C0010` |
| `allow-private-endpoint` | 默认 **false**；仅测试与演示显式放开（演示留痕） | 默认配置下内网源不可用（预期行为） |
| 自检结论 | 200 业务结论：`passed=true` / `passed=false` + 三类原因 + 可读文案 | 不可归类异常 → 502 中性文案 + 留痕 `FAILURE` |
| 读取结果 | `success` + 摘要（数据库：库名 + 表数量级；对象存储：字节数 + 内容类型；API：状态 + 字节数 + 内容类型），**不含数据本体 / 对象内容 / 响应体** | —— |
| 连接超时 | 连接 3s / 读取 5s（可由已有 HTTP 客户端范式沿用；数据库由 JDBC `connectTimeout` / `socketTimeout` 参数控制） | 超时按网络不可达 |
| 凭据保护 | 密钥不可用 → 503 `1010S0004`（既有） | fail-closed，禁止明文降级 |
| 重复登记 / 变更 | 沿用 `uk_connector_type_endpoint` 与 `1010C0001` | —— |
