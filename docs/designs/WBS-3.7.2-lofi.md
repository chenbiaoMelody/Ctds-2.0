## 1. 做什么 / 不做什么

### 做什么（W1~W8）

- **W1 「数据产品门户」首页**（`/portal`，menuOrder 22，**登录可见、无权限点**——门槛在服务端）：
  - 顶部检索区：关键词输入（名称 / 简介）+「查询」/「重置」；
  - 左侧类目树（R5 全量两级，点击过滤；「全部」清除过滤）；
  - 右侧「网购式」产品卡片网格（每卡：产品名称 / 定价档标签 / 简介两行 / 形态 / 类目 / 提供方主体编号 / 上架时间 /「查看详情」）；**无图片素材**（目录契约无图片字段，卡片以文案 + 标签构成，不伪造商品图）；
  - 分页（`pageSize=12`，上架时间倒序由服务端决定）；空态「没有找到符合条件的产品」；加载 / 错误态（错误文案原样）。
- **W2 门户产品详情页**（`/portal/products/:productId`，深链不占菜单）：
  - 页头：返回链接「← 返回数据产品门户」+ 产品名称 + 状态 tag（已上架）；
  - 元数据区：简介（全文）/ 形态 / **定价**（免费显式"免费"；付费档"按次（3.00）"式展示，数值来自 R7 加性 `priceAmount`）/ 类目 / 提供方主体编号 / 上架时间；
  - 动作条（**仅普通档**）：收藏 / 取消收藏、订阅 / 退订（W4~W7；状态以 R9/R10 初查 + 写后重拉为准）；
  - **订购入口（Q3-A）**：「发起订购」**禁用态** + 提示「订购与订单流程将在后续版本开放（WBS-3.7.3）」；零请求、零订单；
  - 不可达分支（非在架 / 不存在 / 无 ADMITTED 资格）：同一条提示常量 `PRODUCT_NOT_ACCESSIBLE_TIP`，不区分原因（防枚举）。
- **W3 未登录引导**：沿用既有路由守卫（`/portal` 属业务路由，未登录 → `/login`，不返回任何产品数据）；门户不新增匿名浏览面。
- **W4 前端模块**：`api/catalog.ts` 类型扩展（`CatalogProductDetail.priceAmount`）；`constants/catalog.ts` 新增 `formatPortalPricing()` 展示助手（免费 / 付费档统一口径，单一常量源）；`views/portal/` 两视图 + 两 spec + `PortalSourceGuard.spec.ts`；`router/index.ts` 一菜单 + 一深链；`vite.config.ts` 零改动（8084 转发键已存在）。
- **W5 菜单与测试基线联动**：普通用户菜单 **8 → 9**、admin **21 → 22**；`router.spec.ts` 两处 `menuOrder` 最大值 **21 → 22**；`MainLayout.spec.ts` 计数与文案断言；e2e 登录冒烟补「数据产品门户」菜单可见断言（不计数）。
- **W6 后端加性读面（Q2-A 生效时）**：`PRODUCT_COLUMNS` 增列 `p.price_amount`、`CatalogProductRow` 增字段、`CatalogProductDetail` 增 `priceAmount`（`String`，null = 免费 / 未登记）；**R6 / R9 / R10 出参不变**；零新表 / 零迁移 / 零新错误码 / 零新权限点；补 2~4 例 DTO / 集成测试。
- **W7 剧本核对修订（Q6-A 同批）**：C-7.1 剧本「界面入口」行 + 演示前提⑤（占位句 → 实际页面路径）+ 维护说明路径说明；**业务判定一字不改**，提示 PO 批准留痕。
- **W8 交付说明与证据**：复用声明 / 规格外实现声明 / 本地门禁命令与结果 / 演示走查指引 / 业务可读交付说明 / 台账与日志。

### 不做什么（N1~N8）

- **N1 不做订购 / 订单 / 合约发起 / 评价**：B3~B5 归 3.7.3 / 3.7.4；详情页订购按钮为禁用占位，不发起请求、不伪造订单，不出现订单列表 / 评价区。
- **N2 不做计费 / 账单 / 计量**：归 3.7.5~3.7.8；门户不展示账单、用量、费用预估（无数据源）。
- **N3 不改既有「数据目录」页**：3.3.6 交付的 PortalView（4 页签）/ ProductDetailView / 三个管理页零改动；C-3.2 三剧本与既有 650 例零回归。
- **N4 不新增检索语义**：不新增排序（价格 / 销量 / 热度）、不新增筛选（形态 / 提供方 / 价格区间）、不做前端本地过滤、不做语义检索（归 3.10.2）。
- **N5 不做推送 / 消息 / 轮询**：B6 评估结论 = 留痕可查 + 主动查询；门户无站内信、消息角标、轮询刷新。
- **N6 不做前端业务判定**：仅「演示主体编号为空」前置拦截（`makeDomainJson`，零请求，沿 DB-41 口径）；可见性 / 状态 / 资格 / 归属一律以服务端响应为准；拒绝文案原样展示（不吞、不改写）。
- **N7 不做匿名浏览、不做真实登录 / 令牌 / 网关调用链**：全站登录制（§4-8 非目标）；真实身份与令牌归 3.9.1；演示期信任客户端身份头（ADR-016 §2.7）。
- **N8 不夹带**：DB-88（连接器读面规格冲突）/ DB-96 / DB-97（测试硬化）/ 3.7.3 起的订购流程 / 3.7.5 起的计量计费 / 3.10.2 语义检索均按各自归属，不在本卡处理。

## 3. 主要流程（用户旅程概述）

1. **需方浏览**：登录 → 侧边栏「数据产品门户」→ 首页卡片列表显示全部已上架产品（P0~P3）→ 可按类目点击或关键词检索 → 打开 P1 详情 → 看到"按次（3.00）"定价与元数据 → 收藏 / 订阅（可选）→ 返回列表（浏览前后目录数据不变）。
2. **免费档展示**：打开 P0 详情 → 定价区显式"免费"（不得空缺）；卡片定价标签"免费"。
3. **负向可见性**：P4（已下架）/ P5（待上架）不出现在列表与检索；直接访问其详情 URL → 同一条不可达提示（不区分不存在 / 未上架 / 已下架）。
4. **未登录**：退出登录后访问 `/portal` 或详情深链 → 被引导至登录页，不返回任何产品数据。
5. **运营档**：admin 登录后可浏览门户（catalog.read），但详情页不显示收藏 / 订阅动作条（体验层；服务端仍为判定源）。
6. **订购占位**：详情页「发起订购」为禁用态，提示"订购与订单流程将在后续版本开放（WBS-3.7.3）"；点击无请求、无状态变化。
