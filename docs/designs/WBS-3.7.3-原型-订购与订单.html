低保真方向稿：4 个画面覆盖「订购弹窗 → 订单详情 → 我的订单 → 负向 / 空态」。所有数据为线框示意，不代表演示数据；业务判定以服务端为准。 订单 = 合约发起的业务外壳：提交订购即生成订单并同步发起合约草案；订单状态只映射「合约生效 → 已完成」「生效前终止 → 已关闭」。
