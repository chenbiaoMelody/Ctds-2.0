## 3. 主要流程（业务语言）

### 3.1 手动即时出账（剧本 C-7.2 S2-1~S2-4）

运营方对指定合约 + 周期触发出账 → 计费引擎只读该合约快照（双方 / 产品 / 定价档 / 数值 / 生效与终止时点）→ 按定价档计算：
- **按次**：本自然月 `metering_flow` 事件数 N × 次单价 → 金额；账单明细逐条映射计量流水（可逐笔回溯）；
- **包月**：合约快照 `price_amount`（元/月）→ 金额，与调用次数无关；
- **交易额分成**：出账时登记的本周期约定交易额 × 合约快照费率（0~100 百分比）→ 金额（本金与费率双快照落账单）；
- **免费档**：拒绝出账（免费档不产生计费流水/账单——B8-2）。

落账：取账单号（全局唯一、终身不复用）→ 账单主表 + 明细 + 动作留痕（CREATE）+ 状态 `ISSUED` 单事务提交。同合约同周期重复出账：唯一键兜底 → 409 业务可读拒绝（幂等负向）。

### 3.2 自然月自动出账（B10-1 周期腿，剧本 S2-11 归口）

每月 1 日 00:10（cron 可配）→ 对**上月**自然月扫描合约：按次合约仅当上月有计量事件才出账；包月合约在周期内处于生效状态即出整月费；免费档跳过；交易额分成未登记约定交易额则跳过并告警（人工补出账）。逐合约独立事务、唯一键防重、单实例演示（多实例前唯一键仍保证不重复计费；调度面演进登记 3.7.8/部署期）。

### 3.3 对账与差异处置（账单核对剧本 S1 / S2）

运营方对「合约 × 周期」发起对账 → 读取账单（必须已出账）→ 计算四组数值：
1. 合约计数表余额口径（全量 `used_count`）；
2. 合约执行流水（本期 + 全量 ALLOWED 计数）；
3. 计量流水聚合（本期 + 全量计数）；
4. 账单合计（金额 + 按次数量 + 按账单快照独立复算金额）。
判定：余额腿 / 本期流水计量腿 / 账单数量腿 / 金额复算腿全部一致 → **通过**；任一不一致 → **差异**（差异明细可定位：缺失/多出/数量不符/金额不符；不允许静默通过）。差异 → 该合约该周期相关账单全部**冻结**（确认与后续动作被拒）；复核与澄清后重新对账通过 → **解冻**恢复原状态。对账全程留痕（时点 / 四方数值 / 结论 / 执行人 / 差异明细）；**系统不自动修改任何账务数据**。

### 3.4 读面、确认与更正（B10 / B12）

需方/供方按合约 / 周期 / 产品过滤查本方账单与本方合约对账结论（非本方 404 同码同文防枚举）；运营方查全量、手动出账与对账。运营方确认账单（`ISSUED → CONFIRMED`）；更正 = 对原账单另出更正单（金额可为负=红字冲正/正=补差，原因必填），原账单金额与明细逐字不变，更正单与原单双向可溯；冻结账单与更正单不可再更正（状态拒绝）。
