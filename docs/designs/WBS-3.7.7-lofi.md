## 3. 主要流程（业务视角）

1. **出账**：运营在 Tab1「手动出账」填合约号 + 账期（分成档加填约定交易额）→ 成功后弹出新账单详情 → 回列表可见状态 `已开具`。
2. **确认**：运营在详情点「确认」→ 状态 `已确认`；若账单因对账差异被冻结 → 被拒并提示"账单已冻结"（fail-closed）。
3. **对账**：运营在 Tab2 填合约 + 账期 → 执行 → 结论卡（`通过` / `差异`）+ 四方数值表 + 金额复算；差异时列出每条差异腿，并提示"该期账单已冻结，需澄清后重新对账"。
4. **差异处置（负向演示）**：差异存在期间尝试确认 → 被拒（与规格 B11-3 一致）；差异澄清（演示口径 = 对账剧本附录 A 还原动作）后重新对账 → 通过 → 账单解冻 → 可确认。
5. **更正**：运营在详情点「更正」→ 填金额（负 = 红字冲正 / 正 = 补差）+ 原因（必填）→ 生成更正单并跳转新单；原单金额与明细逐字不变、更正链双向可见。
6. **需方 / 供方查看**：需方在「我的账单」看到本方账单（角色列标注"需方"）→ 点开看明细与快照、前端展示明细合计与账单金额对照（只作核对展示）。
7. **运营核查流水**：Tab3 按合约 / 主体 / 源类型 / 时间范围查逐条流水，核对某笔账单明细里 `meteringFlowId` 对应的原始事件。
