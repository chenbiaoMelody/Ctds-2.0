## 3. 主要流程（业务语言）

**链 A｜计量采集与不双计**（剧本 C-7.2 计量 S1 关键步）
运营触发采集 → 需方查本方流水（条数 = 放行次数 N）→ 越界调用被拒（流水仍 N、拒绝留痕独立）→ 三方/四方勾稽（交付记录 / 策略计数 / 计量流水各 1 条）→ 沙箱作业与导出各 1 条不叠加 → 免费档无账单 → 主体 C 查他人流水 404 同码同文。

**链 B｜出账与对账双向**（剧本 C-7.2 计量 S2 + 账单核对 S1/S2）
三模式各出一份账单（金额可复算）→ 同周期重复出账被拒 → 改价后已出账单不变 → 更正单生成且原单逐字不变 → 对账通过（四方一致）→ 构造差异后必报（七类可定位）→ 冻结态确认被拒（fail-closed）→ 还原后对账通过并解冻；全程除状态流转与留痕外零数据修改。

**链 C｜读面权限与防枚举**（B12 归属 + R-M4 运营读面）
需方 / 供方各查本方（仅本方数据、角色列正确）→ 主体 C 查他人账单 404（`1011C0009` 同码同文）→ 运营查全量账单与逐条流水（R-M4，权限 `billing.governance` / `metering.governance`）→ 普通档访问运营读面被拒（403 / 路由拦截）→ R-M4 非法参数一律 `1000C0001`。
