## 2. 结构组成

- **S1 路由与菜单**：`router/index.ts` 平铺追加 2 条（`evidence` / `evidence/verify`），meta `{title, menu, menuOrder: 26|27, icon, permission: 'evidence.governance'}`；深链不占菜单；
- **S2 api 层**：`api/evidence.ts`——查询函数走 `makeDomainJson(evidenceRolesHeader())` + `pageQuery` 复用；`downloadAuditReport` 走原生 fetch（豁免登记）；共享类型单点 `PageData<T>`；
- **S3 常量层**：`constants/evidence.ts`——`STAGE_LABELS/TAG`（AUTHORIZATION/CONTRACT/DELIVERY/USAGE）、`STATUS_LABELS/TAG`（PENDING/ON_CHAIN/FAILED）、`CONCLUSION_LABELS/TAG`（PASS/MISMATCH/NOT_ON_CHAIN）、`ANOMALY_LABELS/TAG`、`ACTION_LABELS`；`labelOf()` 未知值原样；
- **S4 身份层**：`stores/demoIdentity.ts` 增 `evidenceRolesHeader()`（沿 billingRolesHeader 同构）；
- **S5 视图层**：`views/evidence/EvidenceAuditView.vue`（el-tabs 5 面）+ `components/EvidenceRecordDrawer.vue`（el-drawer + el-descriptions + 留痕 el-table）+ `views/evidence/EvidenceVerifyView.vue`（单页）；
- **S6 代理层**：`vite.config.ts` server.proxy 在通用 `/api` 键之前插入 `/api/v1/evidence`（→ `http://localhost:8090`，changeOrigin，注释沿交付域同款）；
- **S7 测试层**：`EvidenceAuditView.spec.ts` / `EvidenceVerifyView.spec.ts` / `EvidenceRecordDrawer.spec.ts` / `api/evidence.spec.ts` / `EvidenceSourceGuard.spec.ts` + 菜单计数断言同步（`MainLayout.spec.ts` / `router.spec.ts`）。

## 5. 决策点（待编排师确认，Q1~Q7 + D1）

> 摘要表见任务卡 §二；此处补业务影响说明。

- **Q1 两菜单 vs 单菜单**：A 的代价 = 菜单 +1（计数断言三处同步，机械工作）；收益 = WBS 行 330 两交付项可分别演示、核验工具有独立入口（验收可判定性）。B/C 的风险 = 核验工具埋在标签堆或抽屉里，C-8.1 S2 演示动线长且"核验工具"作为交付项不可见。
- **Q2 单卡流 vs 行内按钮**：A 把核验定位为"工具"（主动输入编号），与 B3"按存证编号定位"语义一致；B（清单逐行核验）会诱导批量点击（每次核验都写一条留痕行），C 无法承载 S2 幕。
- **Q3 口径**：A = 零新增逻辑、两端点族各自已验收口径直出；B/C 均要求前端加工敏感字段，制造平台第二事实源，违反"调阅不复制、不改写"边界。
- **Q4 下载通道**：A 是唯一可行范式（身份头 + 文件名 + Blob）；豁免登记把"裸 fetch"纪律风险显式化（仅此两处、逐字注释锚、SourceGuard 断言兜底）。
- **Q5 参与方读面**：A 关闭跟踪项（评估留痕完整闭环）；B 开放则须新增后端归属过滤读面 + 脱敏子集口径 = 一个独立后端包的体量，超出本卡预算与 WBS 行 330 范围。
- **Q6 校验归属**：A = 业务规则唯一裁决在后端（现网关与服务的既有硬约束），前端只做"体验引导"（日期控件物理上选不出 >90 天区间），不构成第二裁决；B 会在前端复制规则副本（DB-105 同类漂移风险的放大）。
- **Q7 剧本修订**：A = 三处占位行落定 + 两处"界面路径核对方式"修订，业务判定零改动，满足"3.8.5 交付后仅修订本表首行与 S1-8 / S2-7 的界面路径核对方式"的既定承诺；B = 剧本永远以接口承载，界面交付与剧本脱节。
- **D1 体量与拆分**：预估 2300~2900 行（主源 1400~1700 + 测试 900~1200）；两页面共享底座拆分会产生"有审计无核验"中间态不可验收；超 400 行登记制豁免沿 3.8.3 / 3.8.4 先例。

## 7. 诚实边界与验收观察点（沿承规格 B8）

1. **留存边界**：存证 / 留痕 / 报告留存期限承诺（≥6 个月）标"待生效"（集中留存机制未建，G-07）——交付说明与剧本 S2-8 沿承，界面不展示虚构的留存期限承诺；
2. **链口径**：界面与交付说明不出现"已对接真实区块链 / 可对外出证"表述（DB-115；B8-4 自建链不承诺对外公信力）；
