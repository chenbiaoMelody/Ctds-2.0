- **关键决策**：
  1. **RED 用 stub 骨架而非空文件**——让测试可编译、以运行期断言失败为 RED 证据（含 5 个"自然通过"用例如实报告，不粉饰）；

  5. **example-service 集成测试用 @SpringBootTest + @DynamicPropertySource 指向临时审计目录**——不污染工作目录，且断言全部字符串化（不 import 组件类），RED 阶段无新依赖也能编译。
