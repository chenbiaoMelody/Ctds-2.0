- **关键决策**：
  1. redisson-spring-boot-starter 以 **optional** 引入（沿 2.4.5 先例）：防 Redisson 自动配置在无 Redis 环境牵连应用启动；example-service 演示走内存模式（零中间件依赖、剧本可执行），Redis 模式由引入方显式加依赖触发；
  2. 模式默认值 = `redis`（安全默认）：mode=redis 但无 redisson 依赖 → 安全失败（显式报错），**不静默降级内存**（防多实例部署误用单机语义）；
  3. 存储/锁不可用时 **fail-closed**（宁可拒绝不执行/不放行）：幂等防重复执行、锁防无锁放行（防超卖）——安全默认沿红线 7 精神；
  4. 切面顺序：幂等外层、锁内层（先判重再互斥）；幂等"执行中标记 TTL"与"结果 TTL"分离（processing-ttl-seconds vs expireSeconds），超长业务重复执行风险列为使用方责任（V1.0 不做看门狗式续期，防过度设计）。
