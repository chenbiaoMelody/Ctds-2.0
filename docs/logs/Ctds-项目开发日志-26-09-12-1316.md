### 业务可读交付说明

- **完成了什么功能**：给平台的网页端装上"真实浏览器自动验收"能力——以前页面在浏览器里能不能走通只能人工点开看，现在一条命令自动打开真实浏览器、把"登录 → 进入工作台 → 无权限访问被拦 → 退出"整条链路完整走一遍并逐项核对，测完自动关闭。配套交付了一个骨架期演示登录页（页面明确标注"演示占位，真实登录待后续规格澄清"，任意非空账号口令可进入），打开应用先见登录页是本次唯一的业务可见变化。写法规范固化为 ADR-011。另按 2.4.9 时的预告，把前端代码检查与前端单测纳入了质量门禁（每项 3 分钟内），浏览器自动验收暂登记待 CI 环境评估后启用。
- **如何演示**：① 自动验收：`cd frontend && npm run e2e` → 输出 `5 passed`（自动起停 dev server 与浏览器，约 9 秒）；② 手工体验：`cd frontend && npm run dev` → 浏览器开 http://localhost:5173 → 见登录页（含演示口径提示）→ 任意非空账号口令登录 → 工作台 → 顶栏切"管理员"出现"仅管理员可见"菜单 → 点"退出"回登录页；刷新页面登录态保持。
- **注意事项**：① E2E 需本机一次性 Chromium（已装好，换机器时 `npx playwright install chromium` 下载约 115 MB）；② 5173 端口被占用时 `npm run e2e` 会报超时——先关掉占用端口的程序再跑；③ 演示登录页不连后端、localStorage 可被篡改属演示占位预期，安全边界在后端鉴权（待 3.9.1，2.4.9 已留痕）；④ 验收剧本建议：增补"前端演示登录"节点（hifi §5 有业务语言文案），既有节点无需改。
