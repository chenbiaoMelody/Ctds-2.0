### 问题与教训

1. **`2>/dev/null` 吞 SQL 错误造成"假空表"**：查询用错列名（沿用 SR 印象而非 `DESC` 事实），错误被重定向吞掉，一度误判"KMS 未落库"。**教训：核验数据前先 `DESC` 确认列名；诊断期不吞 stderr。**
2. **Git Bash 内联中文 JSON 必坏**：`curl -d '{"reason":"中文"}'` → 服务端 1000C0001；改 UTF-8 文件 `--data-binary @file` 即通。**教训：演示命令统一文件传参，写成可复制口径。**
3. **环境依赖链要"先外后内"检查**：Docker 引擎 → 容器 → 数据库 → 服务，逐层确认可避免把"引擎掉线"误判为"服务缺陷"（首轮三服务同报 `Connection refused` 时即按此定位）。
