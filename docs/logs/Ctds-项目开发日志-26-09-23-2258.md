### 问题与教训（本会话沉淀）

1. **跨服务复用的两层门槛**（功能级权限 + 对象级归属）——只配权限点不够，必须实测 200 路径；处置 = 最小暴露新端点而非放宽既有安全口径。

3. **测试类合并作为时长合规手段**——需在类注释/自检单/台账三处留痕理由，供评审核查。
4. **注释断言 ≠ 代码强制**（3.1.8 评审①P1 教训的再次确认）——安全承诺必须落代码门槛 + 删实现必变红的回归锚点。
5. **环境脆弱性**：Docker Desktop 两次掉线（编码期）——演示环境须保持引擎运行；掉线后服务进程退出、重启即恢复。
