### 问题与教训

1. **分级判定必须给论证，不能只写结论**：把"B 级"写成结论很容易被认为在自行降级规避评审。**处置**：变更单专设 §6，按章程 §7.1 三条判据逐条比对（A 级不成立 / B 级成立 / C 级过轻），并写明"若编排师认为应升 A 级则补会议留痕、且不影响 3.1.12 已确认设计"。**教训**：流程类判定要留"可复核的推理链"。
2. **"同步剧本"不等于"改剧本"**：章程要求"剧本不变 = 变更没完成"，但若剧本确实不受影响，正确做法是**留痕说明"检索 0 命中、判定标准未变"**，而不是为凑动作去改剧本。**教训**：流程动作要为内容服务，不为形式服务。
3. **规格文档没有独立修订节**：本仓规格的修订历史**内联在头部"版本"字段**（C-1.1/C-1.2 均如此），照抄该形态即合规；WBS 则用"版号 + 修订记录表"。**教训**：变更留痕要按**各文档既有的留痕形态**办，不新造格式。
4. **变更落点分支要与来源任务卡一致**：本次变更源于 3.1.12 的 Q1=A，故随该卡分支提交，并在台账/日志明示"规格 V1.1 随本分支合并入 main"，避免"规格在分支上干了但主线不知道"。
