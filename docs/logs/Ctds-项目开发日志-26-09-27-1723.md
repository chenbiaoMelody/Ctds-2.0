### 问题与教训

1. **共享库全局状态跨用例污染**（新增教训）：空间域库按测试类共享（沿 ADR-010 形态），**平台级表行是全局状态**——一个用例改平台基线会污染其他用例（本轮 T5 的平台收紧使 T1/T13 失效，T13 的同值覆盖撞幂等变无操作）。处置：@BeforeEach 平台基线复位；后续包若涉及平台级全局数据，测试设计须先声明复位策略；
2. **留痕 target_id 建前未知**：创建类留痕的 target 指向新实体时，须"先插拿主键、再写留痕"（同一事务内），不能沿用"调用方预构造留痕"模式想当然；
3. 既有教训复用：wasNull 判空紧跟 getLong（mapPolicy 预落实）、JDK 17 API 面（List.getFirst 不可用）。
