### 问题与教训

1. **"绿"必须在正确的时点判定：测试绿 ≠ 交付绿**：首跑测试全过却 `BUILD FAILURE`——若只看 `Tests run: 141` 就宣称完成，交付的其实是**不存在可运行构件**的假绿；"声称完成 = 附验证命令与结果"，必须看到 `BUILD SUCCESS` + 产物核验；
2. **Windows 上的"文件锁"类失败要查进程与端口，别查代码**：`repackage` 的重命名失败在 Windows 几乎总由"有进程正持有该 jar"引起；定位手法 = 进程命令行 + 端口占用 + target 目录，30 秒内可定因，避免误改代码或误改构建配置；
