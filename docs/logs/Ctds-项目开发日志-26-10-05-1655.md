**"合约模板库服务"这张卡已立好**：这是合约域的第一个开发包，相当于给后续所有合约功能盖"房子地基"。您需要确认的是 8 个设计问题 + 1 个体量判断（**全部都有建议答案，回复"都按建议"即可**），其中最重要的三个：

1. **模板里放哪些条款**——建议每类模板 = 7 条公共必填条款（标的 / 范围 / 期限 / 用途限制含禁止再分发 / 保密 / 违约 / 争议）+ 各自特色条款（如 API 类必填"调用频次上限"、隐私计算类必填"原始数据不出域承诺"），完整清单见 lofi §三（业务语言，可直接读）；
2. **停用的模板浏览者还能不能看到**——建议"看不到也不能用"（最严格、最不容易出歧义的口径）；
