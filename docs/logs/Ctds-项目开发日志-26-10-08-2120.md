- **关键决策**（本段生效）：
  1. **本卡形态 = contract-service 同宿主三组端点**（模拟试算 / 测试台 / 受控执行）——与 3.4.5"不建 HTTP 端点"不矛盾：3.4.5 的理由是"无真实消费方，提前暴露未经验证的契约"，而 3.4.6 正是该消费方（模拟器 / 测试台 / 剧本演示入口）；
  2. **双通道语义是本卡的核心概念**：模拟（假想上下文 + 零副作用 + 拒绝以**数据**返回）与执行（真实计数留痕 + 拒绝以**异常**返回）——理由 = 测试台报告必须能区分"如期被拒（PASS）"与"系统报错"，否则双向用例无法表达；
  3. **假想上下文（假想已用次数 + 假想日期）为必要设计**：规格规则 4 的"期限届满 / 次数耗尽"越界腿若无可假设口径，只能真改合约期限或真烧 100 次配额（污染业务数据与计数）；
  4. **配额纯判定补齐 3.4.5 遗留缺口**：`PolicyJudge` **新增** `judgeQuota`（与四要素判定同址，判定不散落）+ ADR-021 登记两腿同源（同一限值来源 + 同一耗尽判据）+ **对照一致性锚**（模拟结论 ≡ 真实执行结论，含 100/101 边界）——以"可执行证据"替代口头同源声明；
  5. **受控执行端点 = S2/S3 演示入口的正式承载**（替代 3.4.5 走查期的临时 harness），但**明确为演示期形态**：C-5.x 交付链接入后由 3.4.8 复核"端点 ≡ 交付链判定面"并评估退役（接管 ADR-020 §2.8 集成面不变）；
  6. **可见性守卫抽取（跟踪-17 兑现）范围收敛**：以 `UsageQueryService`（R12）形态为基准抽取共享守卫供 R12 与新端点共用；`ContractQueryService` 既有实现本卡不动（统一收敛沿跟踪-17 续办）——控制对已验收面的改动面；
  7. **零新增面纪律**：零新表零迁移（V3 两表复用）/ 零新依赖 / 零新码位 / 零门禁配置改动 / 零加解密改动 / 零跨服务 / `PolicyJudge` 只增不改 / 既有 7 控制器 diff 为空；模拟与测试台**零落库**（自检报告不是业务事件）；
