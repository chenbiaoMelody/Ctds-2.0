### 二、业务可读总结（给项目主导者）

**「政务数据源怎么接进来」这块功能已立卡，等您点头开工。** 这一包要办的是：让平台把**政务共享交换平台**当成一个可以登记、可以"试连一下"、可以被交付链取数的数据来源。要点四条：

1. **先登记后使用**：连接器属主为自家连接器登记数据源（类型 / 地址 / 凭据 / 归属），平台发一个源编号；没登记的源一律读不到。
2. **凭据看得见但不外泄**：凭据一律加密存储，界面和记录里只显示"****"，任何日志里也看不到原文；加密组件万一不可用，平台**宁可拒绝也不明文凑合**。
3. **试连三查**：可以点"自检"，平台只读探测（连得上 / 凭据对不对 / 有没有权限），失败会明确告诉是哪一类原因，并留痕。
4. **政务源是"模拟"的，不吹牛**：V1.0 的政务共享交换平台用**标准报文模拟源**承载（正式功能里的模拟件，不是测试后门），界面和文档都会写明"模拟"；真实政务平台对接留到部署实施阶段。

**同时明确划了三道界**：数据库 / 对象存储 / API 网关三类源的自检与取数归**下一包（3.6.6）**；连接器管理界面归 3.6.7；"判定通过才取数"的完整端到端证明归 3.6.8（本包只把读取口子和"拒绝时不碰源"证明好，不假装已经端到端跑通）。
