### 二、业务可读总结（给项目主导者）

连接器现在**四类数据源都能用**了：原来只支持政务共享交换平台，这次补上**数据库、对象存储、API 网关**三类——都能登记、自检、读取摘要。数据库只做"能不能连、账号对不对、有没有权限"三查和"有多少张表"的目录摘要，**不读任何业务数据**；对象存储使用提供方给的**临时授权链接**，只发一次只读请求、只看内容类型和大小；API 网关只发一次 GET、只统计返回字节数，**不保存任何返回内容**。三类失败原因（网络不可达 / 凭据无效 / 权限不足）都是中文可读，无法归类的异常统一提示稍后重试、不暴露内部细节。

额外加了一道"访问前再校验地址"的保险：真正请求之前会把地址解析成真实 IP 再看一遍，解析到内网 / 本机 / 无法解析的一律拒绝，**拒绝时根本不会发出请求**（可演示、可证伪）。内网地址默认仍不允许，只有演示环境显式打开开关才可用。

**如何演示（接口级，约 5 分钟）**：① 登记一个数据库源（演示库）→ 点自检 → 显示"自检通过"；② 登记对象存储源（临时链接）与 API 网关源（本地桩）→ 自检均通过；③ 把数据库密码改错 → 自检显示"凭据无效"；把地址换成不存在的主机 → 自检显示"网络不可达"，此时调用读取会被拒并提示"源地址不被允许"；④ 对三类源各调一次读取 → 只返回摘要（表数量 / 内容类型与大小 / 状态码与字节数），**看不到任何数据本体**。

**注意事项**：对象存储的临时链接有有效期，过期要更新凭据；界面操作归 3.6.7、端到端取数归 3.6.8，本卡验收以接口级为准；三份验收剧本**不需要修改**（可选在维护说明补一行"3.6.6 已交付，四类源自检均可用"）。
