### 二、业务可读总结（给项目主导者）

**「连接器管理界面」已经做出来了，本地所有自动检查全绿。**界面上现在能做三件事：①「连接器管理」——参与方提交接入申请、补正 / 撤回、看自己的连接器和在线状态 / 最近心跳，还能一键上报心跳；②「连接器详情」——看健康度、查验 DID 绑定、登记版本升级、登记 / 变更 / 自检数据源（凭据只显示掩码，政务源如实标注"模拟源"）、看动作留痕、注销；③「连接器治理」——运营方看全平台连接器与在线概览、做注册核验、确认不兼容升级。为了让运营方能真正"看到全平台"，补了一个只读的运营方列表能力（不新增表、不新增权限点）。

**还没做的两件事**：一是"真人点界面走一遍"（需要先把 subject / did / connector 和前端四个服务拉起来，口令和密钥由人侧提供，AI 不接触）；二是三份验收剧本的界面入口改动**需要您批准**（只改入口说明，业务判定一字未改）。这两步完成后才进入验收和建 PR；"建 PR / 合并"仍会单独请示。
