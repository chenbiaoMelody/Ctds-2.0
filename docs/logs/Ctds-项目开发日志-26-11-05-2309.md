- **关键决策**（本段生效）：
  1. **P1-1 在 handler 层映射而非在 verify 服务内 try/catch**：`EvidenceChainUnavailableException` 是适配器契约异常，集中映射可保证"任何取链失败路径"同码同文，且核验失败自然不追加 VERIFIED 留痕（异常在 appendAction 之前抛出）；验证用例用"受控 SQL 置 ON_CHAIN + 关链"构造，符合 Q7-A 无运行期后门。
  2. **P2-3 采"状态写失败直接 1012S0002、不写 FAILED"**：若在失败回调里再写 FAILED，DB 不可用时二次写同样失败且语义错误（链已成功）；记录停在旧状态可由重试命中 `uk_chain_payload` 复用回执恢复，与 hifi §4 崩溃窗口口径一致。
  3. **P2-2 采确定性替身而非真实双线程**：双线程唯一键冲突时序受 JVM / 连接池影响易 flaky；替身精确复现"预检漏过 → insert 冲突 → 回查"分支语义，断言零新增与 `duplicate=true`，符合评审卡建议的兜底方案。
