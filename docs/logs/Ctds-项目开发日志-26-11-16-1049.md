## 一、立卡段实录（业务可读）

1. **为什么立这张卡**：上一个大包（WBS-3.9.6 系统管理测试与集成）验收时发现，资源域详情页对"不是你的资源 / 别的空间的资源 / 不存在的资源"三种情况，返回的提示都是"404 + 1007C0005 + 资源不存在或无权访问"。防"试探别人资源是否存在"的目的是达到了（三种情况一模一样），但平台规格要求的是"400 + 1000C0003 + 与对象不存在同一句话"。PM/PO 已裁决按规格改（A 案），但不在上一个包里顺手改，另立本卡。
2. **本卡要做什么**：只改资源域"我的资源详情"和"资源操作留痕"两个读接口的拒绝提示，改成规格要求的状态码/错误码/同一句文案；"谁试探谁留痕"的内部审计记录保留；写操作、治理面、产品面、其他域一律不动。
3. **为什么现在只立卡**：规矩是设计先行——先出"业务可读行为清单 + 接口契约表"两级设计，经编排师一次确认后才写代码。本批次只做立卡与台账转态，零代码。
4. **立卡时发现的一个边界**：验收剧本 S2-5 还写了"访问别的空间的合约/交付记录也要同样被拒"，但初查合约/交付两个服务里没有"空间归属"这个字段；本卡只改资源域，这条腿按实测如实登记，不擅自扩大改造范围（已列为 Q6 请编排师裁定）。

**没有做什么**：没有改规格、没有改剧本正文、没有写代码、没有改测试、没有改门禁配置、没有提交/推送、没有动 main。
