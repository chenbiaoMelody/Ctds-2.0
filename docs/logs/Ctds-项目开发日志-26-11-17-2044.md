## 一、业务可读交付说明（编码段实录）

**做了什么**：实现了"按意思找数据"的目录语义检索——平台用本地算法把产品名称、简介和语义标签转成向量（不调用外部模型、不花钱），存入现有 MySQL 的新缓存表；新增一个只读接口，按相似度给已上架产品排序返回；产品下架/注销后立即不出现在结果里；简介或标签修改后自动重算。公共向量化/排序组件独立成 `common/vector-store`，未来换 pgvector/Milvus 只需新增适配器。测试先行（1 个模块测试组 + 3 个集成/基准测试类），全部通过。

**如何演示**：测试驱动——按 `docs/manuals/C-11.2-语义检索-验收剧本.md` V0.9 的 S1~S5 运行命令即可核对绿灯；无需启动服务、无需模型密钥。基准结果：1k 产品 P95 24ms、10k 产品 P95 106ms（容器内单机口径）。

**剧本是否需更新**：已新建 C-11.2 剧本 V0.9（待 PO 批准；门禁单发待补）；既有剧本无需更新。

**注意事项**：① "语义"能力有限（本地算法，不是真实语义模型），不能宣称达到 PRD 的 Top5 ≥90% 指标；② MySQL 方案只面向演示规模，不是生产级向量数据库；③ 首次查询需建缓存（1k ≈1.6s / 10k ≈8.8s），稳态毫秒级；④ 代码/测试均在本地分支，未推送；门禁、评审、验收尚未开始。
