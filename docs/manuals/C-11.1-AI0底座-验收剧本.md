## 步骤

### S1 契约往返（B1：接口长得和 OpenAI 一样）

- **做什么**：运行契约测试，验证平台定义的模型调用请求/响应结构与 OpenAI 兼容格式逐字一致（`max_tokens` / `finish_reason` / `prompt_tokens` 等字段名；多轮对话消息原样往返；不填的可选字段不出现；对方多给的未知字段不报错）。
- **命令**：`mvn -B -ntp -pl common/model-gateway test -Dtest=ContractJsonTest`
- **预期**：`Tests run: 6, Failures: 0, Errors: 0`，BUILD SUCCESS。
- **业务含义**：未来任何 AI 功能对接模型时，用的就是业界标准格式，不被单一模型厂商绑定。

### S2 换模型只改配置（B2：插座核心价值）

- **做什么**：运行路由测试，验证①缺省走智谱 GLM；②把默认供应商配置改成 deepseek/qwen/kimi，路由立即跟着变，**代码零改动**；③点名指定供应商优先于默认；④点名一个没注册的供应商 → 明确拒绝"供应商未注册"，**绝不悄悄换成别家**。
- **命令**：`mvn -B -ntp -pl common/model-gateway test -Dtest=ProviderRouterTest`
- **预期**：`Tests run: 8, Failures: 0, Errors: 0`，BUILD SUCCESS。
- **业务含义**：换模型 = 改一行配置；防止"以为换了模型其实没换"。

### S3 开关演示（B3：缺省关闭，零消耗安全默认）

- **做什么**：运行控制位测试之开关族，验证网关开关**缺省是关的**——关着时无论用量多少一律拒绝（原因="网关未启用"）；打开且未设预算 → 放行。
- **命令**：`mvn -B -ntp -pl common/model-gateway test -Dtest=GatewayControlTest`
- **预期**：`Tests run: 6, Failures: 0, Errors: 0`（含 S4 预算族），BUILD SUCCESS。
- **业务含义**：V1.0 交付后平台不会偷偷产生任何模型调用费用。

### S4 预算演示（B3：上限语义，保守口径）

- **做什么**：同 S3 命令中的预算族用例，验证预算上限 100 时：已用 99 → 放行；已用 100 → **拒绝**（达到上限即拒，含等号）；已用 101 → 拒绝；预算 0 或负 = 未设限；开关关闭优先于预算（用量为 0 也拒）。
- **预期**：同 S3 绿灯。
- **业务含义**：将来接上真实用量后，"到顶即停"有明确且保守的判定规则可依赖。

### S5 零消耗实证（B4 + 密钥红线）

- **做什么**：核对四项证据——
  1. **E1 零外呼**：模块依赖仅 jackson-databind（JSON 序列化，仓内既有）+ 测试组件；主源 import 零网络类；全部测试离线可跑（S1~S4 本身即断网可复跑）；
  2. **E2 零真实密钥**：仓库/测试中密钥值仅占位符 `placeholder-not-a-real-key`；门禁 secretsScan GREEN；
  3. **E3 既有面零改动**：`git diff --stat` 锚定——除新模块目录 `common/model-gateway/` 与根 pom 登记（+8 行）外零既有文件改动；既有模块测试全绿；
  4. **E4 门禁 GREEN**：全仓门禁单发 GREEN 报告，ConfigSha256 与基线逐字一致（`adc3f98b153c0578b303e52429974fab055266493ea98d5fadd75035345c5cfb`），coverage overall ≥ 基线 92.34%。
- **业务含义**：本次交付不通电、不花钱、不动既有功能；插座之外的电线（真实调用/计费/审计/页面）归后续包。

## 通过判定

S1~S4 全绿 + S5 四项证据齐备 = 验收通过。**诚实边界**（lofi §6）：本剧本证明的是"插座合格"，不证明"已接通模型"——路由以测试桩证明、预算判定无真实用量来源、OpenAI 兼容 = 字段命名与结构兼容（最小常用集）。
