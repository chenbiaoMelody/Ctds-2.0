## 步骤

### S1 护栏语义（B1：输入拒绝不调用下游、输出拒绝不交结果、顺序与短路、fail-closed、空链直通）

- **做什么**：运行 `common/guardrail` 模块测试，核对——
  1. **空链直通**：未注册任何护栏时输入/输出均放行（T1）；
  2. **输入拒绝**：包装后的调用**不调用下游模型**、抛出拒绝异常且原因码原样可读（T2）；
  3. **输出拒绝**：下游已调用但**响应不交给调用方**，拒绝阶段为输出（T4）；
  4. **顺序与短路**：首个拒绝后后续护栏不再执行（T2：链层输入/输出短路 + 装饰器输入拒绝；护栏收到同一 request/context）；
  5. **fail-closed**：护栏抛运行时异常 / 返回 null / 判定为 null 一律按拒绝处理，原因码 `GUARDRAIL_ERROR`（T3）；
  6. **下游异常原样传播**：下游抛出的异常保持同一实例原样抛出（T6）；`Error` 不捕获、不审计、直接传播（§6）。
- **命令**：`mvn -B -ntp -pl common/guardrail test checkstyle:check`
- **预期**：`Tests run: 24, Failures: 0, Errors: 0, Skipped: 0`（模块 T1~T11 + §6 边界共 24 例），checkstyle 0 违规，BUILD SUCCESS。
- **业务含义**：AI 调用前有"安检门"、调用后有"复核关"；拒绝时不合规内容既不进入模型、也不返回业务；护栏自身故障时宁可拒绝（安全优先），不会"护栏坏了就当没护栏"。

### S2 AI 审计记录契约（B2：每次尝试一条记录、仅元数据、绝不抛错/阻塞、默认 No-op）

- **做什么**：在同一模块测试中核对——
  1. **结果三分**：成功 → `SUCCESS`（T5）、被拒绝 → `DENIED`（T2 输入拒绝 / T4 输出拒绝）、下游失败 → `FAILURE`（T6）；
  2. **恰好一次**：每次调用尝试恰好产生一条记录尝试（T5 断言下游恰一次、记录恰一条）；
  3. **仅元数据**：记录组件恰为契约 12 项，**零 prompt / 响应原文 / 密钥 / 个人信息字段**（T9）；调用时间由落库层 `created_at` 承载（hifi §9 E-02；V1.0 不落库）；
  4. **绝不抛错**：记录器自身抛异常时，成功仍成功、拒绝仍拒绝、下游异常仍原样抛出（T7）；
  5. **默认 No-op**：未提供记录器时不抛错、零数据库写入（T8；V1.0 无任何落库实现）。
- **命令**：`mvn -B -ntp -pl common/guardrail -Dtest=GuardedModelGatewayTest,AiCallLogContractTest test`
- **预期**：`Tests run: 13, Failures: 0, Errors: 0`（GuardedModelGatewayTest 9 = T2/T4/T5/T6/T7/T8 + §6 边界 + 构造器守卫；AiCallLogContractTest 4 = T9 及归一/NOOP；与 S1 同模块，可一并通过整模块命令复核），BUILD SUCCESS。
- **业务含义**：每次 AI 尝试都有一条"只记谁、为什么、哪个模型、多少 token、多久、结果、护栏判定"的留痕，**不记对话原文**；留痕失败不影响业务。

### S3 AI 调用日志表结构预留边界（B3：结构定稿、零内容列、V1.0 零建表/零写入/零迁移）

- **做什么**：核对预留 DDL 工件与全仓迁移面——

- **预期**：`Tests run: 2, Failures: 0, Errors: 0`；DDL 结构/声明/零迁移断言全过。
- **业务含义**：V1.5 的"AI 行为审计"已有一张**定稿但未启用**的表结构；本版本不建表、不写库，避免提前固化归属服务。

## 诚实边界（规格 §5 / lofi §6 / hifi §8/§9）

1. **框架 ≠ 护栏中心 C-11.5 全量**：本卡不含任何真实护栏算法（prompt 注入检测、敏感信息识别、内容合规、幻觉/越权检测、引用溯源均归 V1.5）；
2. **装饰器为休眠态**：3.10.1 无真实 `ModelGateway` 实现，装饰器仅供未来实现包装与测试；不得宣称已产生任何 AI 调用/审计数据；
3. **预留 ≠ 已建表**：V1.0 零建表、零写入、零迁移；不得表述为"AI 审计已落库"；
4. **AI 审计预留 ≠ C-8.4 上链**：C-8.4 AI 行为审计（含上链存证）为 P1，不属本卡；
5. **隐私口径**：审计仅元数据（CAT-01 / L2），零 prompt / 响应原文 / 密钥 / 个人信息；
6. **零外呼 / 零费用**：全过程离线可跑，无任何真实模型调用或密钥。
