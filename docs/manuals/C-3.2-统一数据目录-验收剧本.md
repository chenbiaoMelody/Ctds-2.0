## 剧本 S1：检索与分类（呈现范围、资格、分类过滤、分页）

**验证规格行为**：行为 5（呈现范围 / 检索者资格 / 检索能力 / 检索 ≠ 可访问）

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**A 主体**，已入驻） | 在目录页按关键词检索已上架产品（C-3.3 剧本预置，如"普惠金融数据服务"） | 该产品**出现在结果中**，且结果**仅为目录元数据**（名称 / 简介 / 形态 / 定价模型——不含资源数据本体与敏感原文） |
| 2 | 需求方（A 主体） | 检索提供方**未上架**的产品（C-3.3 剧本 S1 产出） | 结果**不含**该产品（目录仅呈现已上架产品） |
| 3 | 需求方（A 主体） | 按分类类目过滤 + 关键词组合检索，并翻页查看 | 分类过滤生效；分页字段齐备（总数与页码可见，翻页结果一致） |
| 4 | 申请人（**C 主体**，待审核） | 以 C 主体身份尝试检索目录 | **被拒绝**，提示为统一业务文案（防枚举） |
| 5 | 需求方（A 主体） | 打开任一已上架产品详情页核对内容 | 详情**仅为目录元数据**，无数据本体内容段落（检索 ≠ 可访问） |

## 剧本 S2：订阅收藏（收藏幂等、订阅登记、越权拒绝、下架联动）

**验证规格行为**：行为 6（收藏 / 订阅 / 仅可操作本人条目 / 状态联动）

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（A 主体） | 收藏一个已上架产品；随后**再次**收藏同一产品 | 收藏成功；重复收藏后收藏数**不变**（幂等，不新增条目） |
| 2 | 需求方（A 主体） | 订阅同一产品，并查看订阅记录 | 订阅关系**登记成功**，订阅留痕可查（谁 / 何时 / 对哪个产品） |
| 3 | 需求方（**B 主体**） | 以 B 主体身份尝试取消 A 主体的收藏 / 订阅 | **被拒绝**（仅可操作本人条目）且记录拒绝留痕 |
| 4 | 提供方（A 主体）+ 需求方（A 主体） | 提供方将一个已被收藏 / 订阅的产品**下架**（沿 C-3.3 剧本 S3 操作），随后需求方查看收藏 / 订阅列表 | 条目**保留**且标记产品当前状态"已下架"（历史不删除）；**新发起**对该产品的收藏 / 订阅**被拒绝** |

## 剧本 S3：访问边界与治理例外（防枚举、越权探测、治理查看留痕）

**验证规格行为**：行为 7（默认拒绝与服务端强制 / 未上架对象读取边界 / 治理例外唯一 / 越权探测可取证 / 数据本体零接触）

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 以 B 主体身份按标识**直接读取**提供方未上架产品的详情（绕过目录列表，如粘贴链接 / 接口调用） | **被拒绝**，且提示与"对象不存在"**同形**（防枚举——不暴露"未上架"差异） |
| 2 | 需求方（B 主体） | 以 B 主体身份直接调用接口尝试**变更** A 主体的资源或产品（绕过界面） | 服务端**拒绝**且产生拒绝留痕（界面隐藏不构成权限——服务端强制） |
| 3 | 平台运营管理员 | 以平台运营方身份查看全部产品与资源的治理信息（含未上架对象） | **允许**（治理例外唯一）且产生**查看留痕**（谁 / 何时 / 看了什么） |
| 4 | 需求方（A 主体） | 核对目录列表与产品详情页内容 | 不含资源数据本体与个人信息原文（数据本体零接触） |
