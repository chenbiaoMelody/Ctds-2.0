## 剧本 S1：交付准入与 API 交付（凭合约交付、网关调用放行、计量与记录）

**验证规格行为**：行为 1 规则 1 / 2 / 4 / 5；行为 2 规则 1 / 2 / 3 / 6

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 在「交付记录」页选择**已生效合约**（含策略条款）发起一次 **API 交付** | **受理成功**；生成一条交付记录（含合约编号、形态 = API、发起人、时间） |
| 2 | 需求方（B 主体） | 以**约定的用途"风控建模"、本市域内**发起合规调用（次数在 100 次以内、期限内） | **调用放行**并返回数据；交付 / 调用记录新增；**计量事件产生 1 条**（3.7.5 计量口径，界面可见"已计量"标记） |
| 3 | 需求方（B 主体） | 查看该合约的「调用记录」 | 记录含**谁 / 何时 / 哪份合约 / 结果**；**不含数据本体与数据原文** |
| 4 | 提供方（**A 主体**） | 以提供方身份登录，查看同一合约的交付与调用记录 | **可查看**（合约双方均可查）；内容同样不含数据本体 |
| 5 | 需求方（B 主体） | 对同一次交付发起**幂等重放**（同一幂等键） | 返回首次结果；**交付记录不增加** |
| 6 | 平台运营管理员 | 在治理档查看该合约的交付记录 | **可查看**，且产生**治理查看留痕** |

## 剧本 S2：文件交付（加密交付包、完整性校验、记录）

**验证规格行为**：行为 3 规则 1 / 2 / 3 / 4 / 5

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 对**数据集形态已生效合约**（附录 A 补充凭据；**G1 修订口径**）发起**文件交付**，并按附录 B 填写**用途"风控建模"、本市域**要素 | **生成加密交付包**（国密加密）并返回**完整性校验值** |
| 2 | 需求方（B 主体） | 查看交付详情 | 可见**产物标识与校验值**；**不含文件本体与数据原文** |
| 3 | 需求方（B 主体） | 重新领取 / 重放同一交付请求（同一幂等键） | 返回首次交付包信息；**交付记录不增加、不重复生成交付包** |
| 4 | 需求方（B 主体） | 提交一个**超出合约约定范围**的文件交付请求（技术侧配合项：以合约外范围参数发起） | **被拒绝**；**不生成交付包**、不产生交付记录 |
| 5 | 提供方（**A 主体**） | 查看该文件交付记录 | **可查看**（含校验值）；不含文件本体 |

## 剧本 S3：边界与绕过被拒（凭据门槛、越界拦截、服务端强制、治理留痕）

**验证规格行为**：行为 1 规则 1 / 2 / 3 / 4；行为 2 规则 2 / 3 / 5（含状态失效后"调用"面，步骤 2 双动作）；行为 3 规则 4 + 行为 7 规则 1 / 2（非参与方查看他人交付记录防枚举，步骤 9）；行为 7 规则 3 / 5

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（B 主体） | 用**协商中（未生效）合约**的编号发起交付 | **被拒绝**（合约未生效）；无交付记录 |
| 2 | 需求方（B 主体） | 先以**已终止合约**的编号**发起交付**、再以该合约**发起一次调用**（技术侧配合项；两个动作的预期结果相同 = 均被拒绝） | **被拒绝**（状态不允许，口径与合约域"合约当前状态不允许该操作"同语义域） |
| 3 | 提供方（A 主体） | 以提供方身份**代需求方**发起一次交付 | **被拒绝**且留痕（发起主体唯一 = 合约需求方） |
| 4 | 平台运营管理员 / 技术侧配合项 | 以一个**非合约参与方**主体（C-1.1 剧本预置的第三方主体）发起交付 | **被拒绝**；且拒绝提示与"**该合约不存在**"**完全一致（同码同文）**——防枚举 |
| 5 | 需求方（B 主体） | 发起一次**越界调用**（超次数 / 超期 / 用途不符 / 域外 / 再分发动作，按 C-4.3 剧本 S3 口径逐类演示） | 每类**一律被拒绝**、**不触达数据源**、**不产生计量事件**；提示沿合约域统一文案，触发要素入留痕 |
| 6 | 需求方（**B 主体**）+ 技术侧配合项 | **绕过界面直接调用接口**重放步骤 5 的越界请求 | **同样被拦截**（服务端强制；界面与参数均不构成绕过路径） |
| 7 | 平台运营管理员 | 查看被拒的越权探测记录 | **可查看**且留痕齐备（谁 / 何时 / 对象 / 结果） |
| 8 | 需求方（**B 主体**）+ 技术侧配合项 | 以**数据集合约**发起一次 **API 交付**（交付形态与合约锚定产品形态不符，技术侧配合项） | **被拒绝**（形态须与合约锚定产品形态及条款一致）；**不产生交付记录** |
| 9 | 平台运营管理员 / 技术侧配合项 | 以一个**非合约参与方**主体查看**他人的交付记录** | **被拒绝**；且与"**该记录不存在**"**完全一致（同码同文）**——防枚举，拒绝留痕齐备 |
| 10 | —— | 交付 / 调用列表与详情页全量检查 | **不出现数据本体与原文字段**（链路外零接触口径） |
| 11 | 需求方（**B 主体**）+ 技术侧配合项 | 以**API 形态合约**（附录 A 主凭据）发起一次**文件交付**（G1 修订新增反向锚：交付形态与合约锚定产品形态不符的另一方向） | **被拒绝**；**不生成加密交付包**、**不产生交付记录** |
