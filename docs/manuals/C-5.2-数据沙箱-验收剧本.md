## 剧本 S1：沙箱申请与开通（合约门槛、隔离环境、配额与生命周期）

**验证规格行为**：行为 1 规则 1 / 2 / 4；行为 4 规则 1 / 2 / 3 / 4

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 在「沙箱任务」页选择**已生效合约**发起沙箱申请 | **开通成功**；任务含**状态、资源配额与生命周期**信息，全程留痕 |
| 2 | 需求方（B 主体） | 查看任务详情 | 可见**绑定合约、可用数据集、配额（计算 / 内存 / 时长）、有效期**；**不含数据本体与数据原文** |
| 3 | 需求方（B 主体） | 进入「沙箱工作台」 | 沙箱环境**可用**且与生产链路隔离（沙箱内可查看合约约定数据的结构 / 可用性，**不可直接带出本体**） |
| 4 | 提供方（**A 主体**） | 以提供方身份查看同一沙箱任务 | **只读可见**（不可代发起、不可修改） |
| 5 | 平台运营管理员 | 在治理档查看该沙箱任务 | **可查看**，且产生**治理查看留痕** |

## 剧本 S2：沙箱内使用与结果审核（使用留痕、隔离、审核通过 / 驳回）

**验证规格行为**：行为 5 规则 1 / 3 / 4；行为 6 规则 1 / 2 / 3 / 5

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 在沙箱内以**约定用途"风控建模"、本市域**使用合约数据做一次开发 / 分析动作 | **可用**；产生**使用留痕**（谁 / 何时 / 哪个沙箱任务 / 动作），**不含数据本体与数据原文** |
| 2 | 需求方（B 主体） | 尝试从沙箱**直接导出原始数据**（非结果物路径） | **被拒绝**（原始数据带不出，唯一出口 = 审核后导出） |
| 3 | 需求方（B 主体） | 尝试访问**其他沙箱任务**或其他合约的数据（技术侧配合项：以其他任务 / 合约标识发起） | **被拒绝**（环境隔离，默认拒绝）且留痕 |
| 4 | 需求方（B 主体） | 在沙箱内以合约**约定外用途**（如"营销外呼"）使用数据 | **被拒绝**（策略在沙箱场景同样生效；触发要素 = 用途） |
| 5 | 需求方（B 主体） | 将沙箱内产出的一份**结果物提交审核** | 提交成功；结果物状态进入**待审核**；**此时导出入口不可用（带出为前置条件）** |
| 6 | 平台运营管理员 | 在「导出审批」区对该结果物执行**审核通过** | 审核**通过**并留痕（审核人 / 时间 / 结论）；结果物状态转为**已通过（可导出）** |
| 7 | 需求方（B 主体） | 提交**第二份结果物**审核，运营管理员执行**驳回**（含理由） | 驳回成功；结果物状态为**已驳回**；**理由可查**、留痕齐备 |
| 8 | 平台运营管理员 | 查看审核留痕列表 | 两条审核记录（通过 / 驳回）**结论与理由齐备**，**不含数据本体** |

## 剧本 S3：结果导出与绕过被拒（唯一出口、服务端强制、策略校验、治理留痕）

**验证规格行为**：行为 6 规则 1 / 3 / 4 / 5；行为 4 规则 1 / 2 / 3 / 5（凭合约申请 / 隔离环境 / 配额与生命周期 / 不绕合约）；行为 5 规则 5（配额到顶即止，步骤 9）；行为 7 规则 1 / 2 / 3 / 5

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 对**审核通过**的结果物发起导出 | **导出放行**；产生**导出记录**（谁 / 何时 / 合约与沙箱任务 / 结果物标识 / 结果） |
| 2 | 需求方（B 主体） | 对**未提交审核**的结果物发起导出 | **被拒绝**（唯一出口规则） |
| 3 | 需求方（B 主体） | 对**审核驳回**的结果物发起导出 | **被拒绝**（含驳回理由可查） |
| 4 | 需求方（**B 主体**）+ 技术侧配合项 | **绕过界面直接调用导出接口**导出未审核的结果物 | **同样被拒绝**（服务端强制；界面与参数均不构成导出路径） |
| 5 | 需求方（B 主体）+ 技术侧配合项 | 导出一份**审核通过但策略校验越界**的结果物（技术侧代造：用途约定外 / 含禁止再分发形式） | **被拒绝**且留痕含触发要素（**审核通过 ≠ 免策略**） |
| 6 | 需求方（B 主体） | 对**已到期 / 已关闭**的对照沙箱任务继续使用或导出 | **被拒绝**（生命周期终止生效） |
| 7 | 需求方（B 主体） | 先以**未生效合约**、再以**已终止合约**各申请一次沙箱（对照） | **两次均被拒绝**（凭据门槛，同行为 1 口径；已终止合约沿合约域状态失效 `1008C0013` 语义域） |
| 8 | 平台运营管理员 / 技术侧配合项 | 以**非合约参与方**主体查看他人沙箱任务或结果物 | **被拒绝**；且与"**该沙箱任务不存在**"**完全一致（同码同文）**——防枚举，拒绝留痕齐备 |
| 9 | 需求方（B 主体）+ 技术侧配合项 | 对一份**配额已耗尽**的对照沙箱任务继续使用（技术侧配合项：以配额耗尽的对照任务发起） | **被拒绝**（配额到顶即止；配额判定在服务端，界面不构成绕过路径） |
| 10 | 平台运营管理员 / 技术侧配合项 | 以一个**非合约需求方（非参与方）主体**发起**沙箱申请** | **被拒绝**且留痕（发起主体唯一 = 合约需求方；防枚举口径同行为 1 规则 4） |
| 11 | —— | 沙箱任务 / 结果物 / 导出列表与详情页全量检查 | **不出现数据本体与原文字段**（链路外零接触口径） |
