## 剧本 S1：接入准入与身份锚（主体前提、身份锚唯一、防枚举留痕）

**验证规格行为**：行为 1 规则 1 / 2 / 3；行为 3 规则 1 / 2

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 未入驻主体（第三方主体） | 发起连接器接入申请（提交连接器名称 / 类型 / 版本 / 所属主体） | **被拒绝**（主体资格不满足——主体未入驻）；拒绝留痕齐备（谁 / 何时 / 对象 / 动作） |
| 2 | 需求方（**B 主体**） | 发起连接器接入申请（名称"星河标准连接器"、类型 = 标准连接器、版本 V1.0.0、所属主体 = 星河） | **受理成功**；登记记录生成，状态 = **待核验**；记录含名称 / 类型 / 版本 / 所属主体 / 状态 / 时间，无凭据明文 |
| 3 | 需求方（B 主体） | 通过连接器**查验本主体身份**（身份管理功能；技术侧配合项：连接器身份查验端点） | 返回**本主体**身份要素与 DID 状态（可解析、状态有效）；**不含其他主体信息** |
| 4 | 需求方（B 主体） | 尝试经连接器查验**其他主体**（A 蓝天）的身份信息 | **被拒绝**（跨主体查验不允许） |

## 剧本 S2：六项功能框架演示（路由一致、交付凭据、使用控制双向、fail-closed）

**验证规格行为**：行为 2 规则 1 / 2 / 3；行为 4 规则 1 / 2 / 3；行为 5 规则 1 / 2 / 3

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（**B 主体**） | 经连接器**依次发起六类业务动作各一次**：①查身份（身份管理）②登记 / 查看资源（资源管理）③查看产品（产品管理）④查看已生效合约（合约管理）⑤发起一次文件交付（交付，凭据 = 已生效数据集合约）⑥发起一次合规使用（使用控制，凭据同上）——技术侧配合项：连接器功能入口 | 六类动作**均受理成功**，结果与在平台直接操作**一致**（同一主体、同一数据、同一校验）；每类动作在平台对应域产生**留痕**（同源同要素） |
| 2 | 需求方（B 主体） | 经连接器发起一次**越界使用**（超次数 / 约定外用途，沿 C-4.3 剧本 S3 口径） | **被拒绝**（平台策略判定拒绝）；连接器**终止动作、不得本地放行**（fail-closed）；拒绝留痕含触发要素 |
| 3 | —— | 全量检查：连接器各功能入口的页面与输出 | **不出现数据本体与原文字段**（沿平台"本体零接触"口径）；六项功能均不提供平台不允许的动作 |
