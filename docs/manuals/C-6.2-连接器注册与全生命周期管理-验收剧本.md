## 剧本 S1：注册与核验（两步制、核验三查、DID 绑定）

**验证规格行为**：行为 6 规则 1 / 2 / 3 / 4；行为 7 规则 1 / 2 / 3；行为 8 规则 1 / 2 / 3

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 平台运营管理员 | 对 C-6.1 剧本产出的待核验连接器执行**核验**——核验三查（主体资格 / DID 有效 / 信息完整）（技术侧配合项：连接器核验端点） | **核验通过**：状态 = **已注册**；签发**唯一连接器编号**；**DID 绑定建立**（绑定记录可查：连接器 ↔ 所属主体 DID ↔ 建立时间） |
| 2 | 需求方（B 主体） | 提交一份**要素不全**的注册申请（缺版本号） | **被拒绝受理**（信息不完整，理由业务可读）；补正重提后正常受理 |
| 3 | 平台运营管理员 / 技术侧配合项 | 对**未入驻主体**的连接器申请执行核验 | **核验拒绝**（主体资格不满足）+ 留痕（谁核 / 何时 / 对象 / 结论） |
| 4 | 平台运营管理员 / 技术侧配合项 | 对**主体 DID 已吊销**的连接器申请执行核验 | **核验拒绝**（DID 校验不通过）+ 留痕 |
| 5 | 需求方（B 主体） | 以同一主体、同一名称重复提交注册申请 | **提示重复**，不新建档（同主体同名唯一；版本变更走升级） |
| 6 | 平台运营管理员 | 查看连接器注册记录与版本历史 | 记录含编号 / 名称 / 类型 / 版本 / 所属主体 / 状态 / 时间；全程留痕链完整 |
| 7 | 平台侧 / 技术侧配合项 | 凭连接器绑定做一次"**取 DID → 验身份**"业务查验 | 查验通过（可取到所属主体 DID 并完成身份验证）；**真实联调另卡**（CHG-C-1.2-V1.1——3.6.3 交付后另行立卡），本步骤为业务语义级演示 |

## 剧本 S2：升级与版本兼容（兼容原子替换、不兼容显式确认）

**验证规格行为**：行为 9 规则 1 / 2 / 3

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（B 主体） | 对已注册连接器提交**升级登记**（V1.0.0 → V1.1.0，声明**兼容**）（技术侧配合项：升级端点） | **升级成功**：版本**原子替换**；留痕含旧版本与新版本；连接器业务动作**不中断**（状态保持已注册） |
| 2 | 需求方（B 主体） | 提交**升级登记**（V1.1.0 → V2.0.0，声明**不兼容**） | **不自动替换**；进入运营方**显式确认**路径；确认前旧版本 V1.1.0 **继续有效** |
| 3 | 平台运营管理员 | 对该不兼容升级执行**显式确认** | 版本替换生效并留痕（含确认人与时间）；连接器按 V2.0.0 生效 |
| 4 | 平台运营管理员 | 查看连接器**版本历史** | 可见完整版本变更链（V1.0.0 → V1.1.0 → V2.0.0）及每次变更留痕（旧 / 新版本、兼容性声明、确认人〔如走显式确认〕、时间） |

## 剧本 S3：注销（前置检查、终态不可逆、编号不复用）

**验证规格行为**：行为 10 规则 1 / 2 / 3

| 步骤 | 操作人 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需求方（B 主体）/ 平台运营管理员 | 对**存在进行中交付作业**的连接器发起注销（技术侧配合项：以该连接器承载一笔进行中交付后发起注销） | **被拒绝**（前置检查不通过——存在进行中交付作业；提示先完结或终止） |
| 2 | 需求方（B 主体）/ 平台运营管理员 | 对**无在途作业的对照连接器**发起注销 | **注销成功**；状态 = **已注销（终态）**；注销动作留痕 |
| 3 | 需求方（B 主体） | 以**已注销连接器**尝试发起任意业务动作（身份查验 / 交付等） | **被拒绝**（已注销不可发起任何业务动作） |
| 4 | 需求方（B 主体） | 重新注册同名连接器并核验通过 | 新编号**不复用**已注销编号；旧连接器的登记 / 版本 / 绑定 / 业务留痕**保留可查** |
