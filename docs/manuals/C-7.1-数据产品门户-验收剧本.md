## 剧本 S1：产品浏览幕（行为 B1、B2）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需方 A | 登录平台，点击侧边栏「数据产品门户」打开产品卡片列表 | 列表展示全部"已上架"产品（含 P1/P2/P3/P0），无需任何审批环节；不出现待上架 / 审核中产品（B1-1、B2-1） |
| 2 | 需方 A | 在门户首页检索框以关键词检索（名称 / 简介关键字） | 检索结果与目录服务同一条件的查询结果一致（B2-4） |
| 3 | 需方 A | 在 P1 卡片点击「查看详情」打开详情页 | 详情展示产品元数据 + 定价四档口径：按次单价清晰可见；P0 详情页定价显式为"免费"（不得空缺）（B2-3） |
| 4 | 需方 A | 检索 P4（已下架）与 P5（待上架）名称（列表不可见）；以详情深链 `/portal/products/{编号}` 直接访问二者 | 均不可见或明确提示不可用——门户不出现已下架与待上架产品（B2-2，负向） |
| 5 | （未登录） | 退出登录后直接访问 `/portal` 或详情深链 | 被引导至登录页，不返回任何产品数据（B1-2，负向） |
| 6 | 需方 A | 浏览前后各查看一次目录管理端的产品列表 | 两次完全一致——门户浏览未改变目录任何数据；A 的主体状态与资格亦无变化（B1-3、B1-4，观察点） |

## 剧本 S2：订购订单与评价幕（行为 B3、B4、B5、B6）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需方 A | 对 P1 发起订购 | 订单生成且仅一份，四要素完整可查：需方 A / 产品 P1 / 定价快照（按次单价）/ 发起时点（B3-1） |
| 2 | 需方 A | 对 P1 再次发起订购（进行中订单未了结时） | 被拒绝，理由业务可读（如"已有进行中订单"）；进行中订单仍只有一份（B3-2，负向 + 幂等） |
| 3 | 需方 A | 查看订单详情 | 订单已衔接合约草案：草案可见且其定价口径 = 订单定价快照（合约签署本身沿 C-4.2 剧本执行，此处只验衔接）（B3-3） |
| 4 | 需方 A | 沿 C-4.2 完成本订单合约的协商签署，使合约生效 | 订单状态自动转为"已完成（已订购）"，状态变更留痕可查、与合约状态一致（B3-4） |
| 5 | 供方 B | 对另一笔预置订单（需方 A 对 P2 的订单 + 未生效合约草案，见附录 A）让合约走"拒绝 / 撤回"分支 | 该订单状态自动转为"已关闭"，关闭原因留痕可查（B3-4，负向腿） |
| 6 | 主体 C | 以主体 C 身份查询需方 A 的订单明细 | 被拒绝，错误信息业务可读、不暴露内部实现（B4-4，负向——C 与该订单无任何当事关系） |
| 7 | 运营方 | 按"产品 P1 / 需方 A / 状态"三个条件分别检索订单 | 三次检索均返回全量口径下的正确订单集合，可读可查（B4-2） |
| 8 | 需方 A | 对 P1 提交评价：评分 4 + 文字（A 对 P1 已有有效交付） | 评价提交成功，留痕（评价人 / 产品 / 评分 / 时点）可查（B5-1） |
| 9 | 需方 A | 以非法评分 0 分再次提交 | 被拒绝，1~5 合法值校验生效（B5-1，负向） |
| 10 | 需方 C | 对 P1 提交评价（C 无任何交付记录） | 被拒绝，理由业务可读（须完成有效交付后方可评价）（B5-2，负向，防刷评） |
| 11 | 需方 A | 更新本人对 P1 的评价（改评分） | 评价总数不变（一人一评），本人既有评价被更新（B5-3） |
| 12 | 运营方 | 查看 P1 详情页统计；随后隐藏一条违规评价（预置） | 隐藏前均分与评价数 = 全部有效评价统计值；隐藏后该评价不再计入展示，且隐藏动作留痕可查（B5-4） |
| 13 | 需方 A | 查看订单列表与详情获取订单当前状态 | 列表 / 详情所示状态 = 订单权威状态，与合约状态联动一致；列表仅含本方订单、详情字段（状态 / 关联合约 / 时点）完整（B4-1）；订单留痕时间线连续可读（B4-3，创建 / 变更 / 关闭沿步骤 1/4/5 留痕）；平台无任何"站外推送"承诺与动作（B6-1、B6-2，观察点） |
