## 剧本 S1：计量采集与流水幕（行为 B7、B8）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 需方 A | 查询本方 P1 合约的计量流水 | 放行 N 次 → 计量可勾稽事件数 = N（**放行 1 次 ≡ 计量事件 1 条**），每条含事件时点、动作、合约编号（B7-1） |
| 2 | 需方 A | 对 P1 合约发起一次越界调用（沿 C-4.3 越界场景构造） | 调用被拒；计量事件数仍 = N 不变；拒绝留痕独立存在且**不进入**任何计量聚合（B7-2，负向：拒绝零计量） |
| 3 | 运营方 | 对同一交付动作做三方勾稽：交付记录 / 合约策略计数 / 计量流水 | 三方各恰好 1 条且相互一致——**不双计**（交付记录与策略计数分工沿 ADR-023，计量侧无第二份流水）（B7-3） |
| 4 | 运营方 | 查沙箱作业与导出的计量记录；随后执行一次策略模拟器 / 测试台自检 | 沙箱作业与导出各计一次使用且不互相叠加（单一事件源不双轨）；自检执行后计量流水**零新增**（B7-4） |
| 5 | 需方 A | 查 P0（免费档）合约的计量与计费情况 | 计费金额 = 0、无计费明细行；但其调用事件留痕完整可查（B8-2） |
| 6 | 运营方 | 核对 P1 合约"第 1~N 次放行 + 第 N+1 次越界被拒"序列的计数与计量 | 计数表 = N、计量聚合 = N——拒绝未触碰任何计数与计量（B8-3，负向核对） |
| 7 | 需方 B | 以需方 B 身份查询需方 A 合约的计量记录 | 被拒绝，错误信息业务可读（B8-4，负向） |

## 剧本 S2：出账幕（行为 B9、B10、B12）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 运营方 | 对 P1 合约手动触发即时出账 | 账单生成：金额 = N × 次单价，明细逐条可溯至计量流水；账单字段最小集齐备（编号 / 合约与双方 / 周期 / 金额构成 / 状态 / 生成时点）（B9-1、B10-1） |
| 2 | 运营方 | 对 P1 合约同周期再次触发出账 | 被拒绝（幂等），理由业务可读（B10-1，负向） |
| 3 | 运营方 | 对 P2（包月）合约触发本周期出账 | 账单金额 = 订单周期费，与调用次数无关（调用次数变化不影响包月金额）（B9-2） |
| 4 | 运营方 | 对 P3（交易额分成）合约触发出账 | 账单金额 = 约定交易额 × 分成费率，基数与费率均可追溯至合约 / 订单定价快照（B9-3） |
| 5 | 需方 A | 按账单明细 + 定价快照独立复算 P1 账单金额 | 复算结果 = 账单金额（同输入同输出，计费可复算）（B9-4） |
| 6 | 供方 B | 变更在售产品定价（走目录域既有流程），随后核对已出账单 | 定价变更留痕、只向后生效；**已生成账单金额逐字不变**（B9-4，负向：不得追溯改账） |
| 7 | 运营方 | 尝试直接修改已生成账单的金额字段；随后演示更正路径（另出更正单 / 红字冲正） | 直接修改被系统拒绝；更正单生成后原账单内容逐字未变且全程留痕（B10-3，负向 + 留痕） |
| 8 | 运营方 | 抽查全部账单编号 | 编号全库唯一、终身不复用（含已关闭 / 冲正账单）（B10-2，观察点） |
| 9 | 需方 A / 供方 B | 分别按合约、周期、产品过滤查询本方计量与账单 | 各自结果完整且仅含本方数据（B12-1） |
| 10 | 需方 B | 查询供方 B 与需方 A 之间的账单（非本方） | 被拒绝，错误信息业务可读、无内部实现细节（B12-3，负向） |
| 11 | （说明步） | 编排师核对出账触发口径 | 本剧本以手动即时出账承载演示；**自然月周期自动出账的实现验证归 3.7.6**（诚实边界，规格 §4-3 / §7 Q6） |
