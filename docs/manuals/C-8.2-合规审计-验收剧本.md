## 剧本 S1：审计查询与日志调阅幕（行为 B5、B6）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 监管方（运营方治理档） | 打开监管审计视图 | 四环节存证总览可读（授权 / 合约 / 交付 / 使用分列）；异常项（待上链 / 上链失败 / 核验不一致）单独可见且计数与 C-8.1 剧本现状一致（B5-2） |
| 2 | 监管方 | 按业务单据号检索任一笔交付单 | 唯一定位到该笔存证事件，并展开"存证事件 + 业务留痕"时间线（B5-2） |
| 3 | 监管方 | 按主体 + 时间窗过滤 | 返回该主体在窗口内的全部四环节存证事件；换用另一主体，结果集随之切换（B5-2） |
| 4 | 监管方 | 对步骤 2 的业务单据号发起日志调阅 | 时间线连续：存证事件（含核验结论）→ 上游业务留痕逐条可读，无断点（B6-1） |
| 5 | 监管方 | 尝试不设任何条件的全量调阅 / 全量导出 | **被拒绝**，提示需给出条件（业务单据号 / 主体 / 时间窗 / 环节至少一项）（B6-2，负向） |
| 6 | 监管方 | 查看调阅留痕 | 每次调阅生成 1 条留痕：调阅人、时点、条件、返回条数齐备（B6-3） |
| 7 | 普通主体（非监管） | 直接访问审计视图与调阅入口 | 被拒绝；错误提示与"对象不存在"口径一致（同码同文，不泄露对象是否存在）（B5-4，负向） |
| 8 | 监管方 | 抽查调阅结果内容 | 不出现数据原文与个人信息；敏感字段按截断标记展示（B6-4，负向 + 观察点）；视图内无修改 / 删除 / 补录按钮（B5-3，观察点） |

## 剧本 S2：审计报告导出幕（行为 B7、B8）

| 序号 | 角色 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| 1 | 监管方 | 按条件（时间窗 + 环节）生成审计报告 | 生成成功；报告含编号、生成人、生成时点、范围与口径、存证清单、核验结论汇总、异常项清单；编号唯一（B7-1） |
| 2 | 监管方 | 打开报告，与同条件审计视图读数对照 | 存证清单条数、核验结论分布、异常项数量与视图**逐项一致**（B7-2） |
| 3 | 监管方 | 用同一条件再次生成报告 | 生成**新编号**报告，不覆盖前一份；两份均保留且各自可追溯（B7-2 / B7-3） |
| 4 | 监管方 | 下载 / 导出报告文件 | 导出成功（CSV / JSON 形态）；导出动作留痕（导出人 / 时点 / 范围 / 报告编号）（B7-3） |
| 5 | 普通主体（非监管） | 尝试生成 / 下载审计报告 | **被拒绝**，提示与权限口径一致；不返回任何报告内容（B7-4，负向） |
| 6 | 监管方 | 抽查报告内容 | 不含数据原文、个人信息、商业密文与密钥材料；仅含存证摘要与元数据（负向） |
| 7 | 监管方 | 尝试修改 / 删除既有报告或审计数据 | **无相关入口**；报告不可篡改，更正只能生成新编号报告并留痕（B7-2 / B8-3，负向 + 观察点） |
| 8 | 监管方 | 核对留存与合规边界说明 | 视图 / 报告说明中明示：留存目标 ≥6 个月、集中日志与留存期限配置未闭环（G-07）标"待生效"、自建链不单独承诺对外出证（B8-2 / B8-4，观察点） |

### 操作路径说明（V0.9 占位）

> 审计端点（视图查询 / 日志调阅 / 报告生成与下载）由 3.8.4 落定，权限点随实施包登记；本剧本立卡期不预设端点与端口。3.8.4 / 3.8.5 交付后按实测补逐步接口与界面路径，**业务判定不变**（沿 C-7.2 V1.1 修订先例）。
