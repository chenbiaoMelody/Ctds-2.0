# AI 评审流水线（第二道防线 · WBS 2.3.2）

## 流程定位

实现与评审必须来自**不同 AI 会话**（新鲜上下文）。编码智能体提交评审后，编排师开 4 个独立会话，各加载一张评审卡（`cards/` 目录），分别从 4 个视角独立审查，互不通气。

## 怎么执行（编排师操作）

1. 准备评审输入包：本次变更文件清单 + 对应规格/ADR 链接 + 仓库路径；
2. 开 4 个新会话，分别粘贴 `cards/01…04` 的卡片全文 + 评审输入包；
3. 每个会话按卡片输出**统一格式结论**（见下）；
4. 任一视角 verdict = FAIL → 打回编码智能体修复后重审（循环 ≤3 轮，第 3 轮仍不通过 → 升级 9.5：拆小任务/更换模型/外部顾问）；
5. 全部通过 → 文档智能体生成业务语言"待验收报告"，交第三道防线（人工业务验收）。

## 统一输出格式（每视角）

```json
{
  "reviewer": "01-规格与设计符合性",
  "verdict": "PASS | FAIL",
  "findings": [
    { "severity": "P0|P1|P2", "file": "路径", "issue": "问题描述", "evidence": "依据（规格条目/章程条款）" }
  ],
  "summary": "一句话结论"
}
```
