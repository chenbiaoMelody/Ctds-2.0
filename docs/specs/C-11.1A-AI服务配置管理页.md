## 1. 用户故事

作为**平台管理员**，我希望在系统管理界面有一个"AI 服务配置"页面：查看并修改模型网关的**总开关、token 预算上限、默认供应商和各供应商连接参数**，每次修改都经校验、有留痕、受权限控制；V1.0 这些配置仅落库备用——**平台尚无任何真实 AI 调用消费它们**（零外呼零消耗），本页面是 AI-0 底座的配置面，为 V1.5 真实接入打底。

## 2. 行为清单（业务语言）

### 行为 1：配置查看（B1）

**业务规则**

1. 读面返回当前 AI 网关配置**合并视图**：数据库已保存值优先；无保存值时展示 C-11.1 缺省（开关=关闭 / 默认供应商=glm / token 预算=0=未设限 / 四供应商连接参数=未配置）；
2. 展示字段 = 网关总开关、token 预算上限、默认供应商、四供应商（glm/deepseek/qwen/kimi）的**服务地址**与**默认模型名**；供应商未配置显式标注"未配置"，不以 0/空串冒充已配置；
3. **密钥永不出现**（Q4-A）：密钥引用列（`api_key_ref`）不进入任何读面响应、不渲染任何页面元素；页面在密钥位置显示固定灰字"部署期经配置中心/KMS 注入，页面不显示"；
4. 读面挂权限点 `platform.ai.config.read`，无权限明确拒绝（403 文案统一）。

**验收标准（Given/When/Then）**

- Given 全新库（V6 seed 后未修改），When 读配置，Then 返回 C-11.1 缺省视图（关闭 / glm / 0 / 四供应商未配置）；
- Given 已保存过配置，When 读配置，Then 返回已保存值；
- Given 任意读面响应与页面渲染，When 检查，Then 零密钥值、零密钥引用字段（固定灰字除外）；
- Given 无 `platform.ai.config.read` 权限的调用方，When 读配置，Then 403 拒绝。

### 行为 2：配置编辑与校验（B2）

**业务规则**

1. 写面为**唯一写入口**：全量保存（开关 + 预算 + 默认供应商 + 四供应商连接参数），挂权限点 `platform.ai.config.write`，操作者取 `X-Ctds-Subject` 头（经网关/演示链剥离重建，不可直连伪造）；
2. 写入校验（统一 1014 段错误码，**拒绝原因文案可区分**）：供应商编号必须在封闭清单 glm/deepseek/qwen/kimi 内；默认供应商必须在清单内（= "已注册"语义，V1.0 清单即注册面）；token 预算必须为 ≥0 整数（0=未设限）；服务地址必须为 http(s) URL 或空（空=未配置）；默认模型名 ≤128 字符或空（空=未配置）；
3. 保存成功后**逐字段变更留痕**：字段路径 + 变更前值 + 变更后值 + 操作者 + 时间（留痕只读、不提供界面回滚）；值未变化的字段不产生留痕行；
4. 写面缺权限明确拒绝（403），库与留痕零变化。

**验收标准（Given/When/Then）**

- Given 合法全量载荷，When 保存，Then 落库成功、返回保存后视图、产生逐字段留痕（仅变化字段）；
- Given 供应商编号不在清单 / 默认供应商不在清单 / 预算为负或非整数 / 服务地址非 http(s) URL，When 保存，Then 拒绝、错误码为 1014 段、各原因文案可区分，库与留痕零变化；
- Given 无 `platform.ai.config.write` 权限，When 保存，Then 403 拒绝且零变化。

### 行为 3：当前判定预览（B3）

**业务规则**

1. 预览 = 按当前合并视图配置执行 C-11.1 B3 判定语义（**先开关后预算**，与 `GatewayControl.check` 同语义），返回 允许 / 网关未启用 / 超预算 三态之一（业务可读文案）；
2. V1.0 无用量累计源，预览按**已用量 = 0** 执行——**超预算分支在 V1.0 预览中不可触发**，页面明示该口径；判定语义本体由 3.10.1 交付的单测承载，本页仅做配置态的可读演示；
3. 预览为**纯判定**：零网络调用、零计费写入、零用量落库（零消耗红线，ADR-003 §4）。

**验收标准（Given/When/Then）**

- Given 开关关闭（含缺省态），When 预览，Then 返回"网关未启用"；
- Given 开关开启且预算上限 0（未设限），When 预览，Then 返回"允许"；
- Given 任意预览，When 检查实现，Then 无网络调用、无计费写入、无用量落库；页面明示"已用量恒为 0（V1.0 无用量源）"。

### 行为 4：密钥红线与边界（B4）

**业务规则**

1. **零真实密钥**：页面零输入零回显；数据库仅 `api_key_ref` 引用占位列（V6 seed 为空值）；仓库、测试、日志零真实密钥（门禁 secretsScan 零命中）；真实密钥部署期经配置中心/KMS 注入（ADR-003 红线 / AGENTS §2.7）；
2. **零真实外呼**：本页全部能力 = 读配置 / 写配置 / 判定预览 / 留痕查询，不发起任何模型调用、不引入 HTTP 客户端或模型 SDK、不新增外部构件；
3. **配置即预留**（诚实边界）：V1.0 无运行时消费方，**配置落库 ≠ 配置已生效**；生效对象 = 未来 V1.5 / C-11.x 绑定（C-11.1 :101）；规格与交付说明禁止表述为"配置已生效于真实调用"；
4. **既有面零变化**：`common/model-gateway` 主源与测试零改动（纯库消费）；既有迁移脚本零改动（V6 为增量）；门禁配置零改动；不新增服务/端口/网关路由（前端代理键 = 复用既有 `/api/v1/platform` + 新增 `/api/v1/ai-config` 1 键——编码段修正 E-01-2，见 §6 补正说明）。

**验收标准（Given/When/Then）**

- Given 全仓检索（secretsScan + 人工核对），When 检查本卡交付，Then 零真实模型密钥；
- Given 本卡交付 diff，When 核对，Then `common/model-gateway` 与既有迁移脚本零改动、门禁配置零改动、无新增服务/端口/网关路由；
- Given 交付说明与页面文案，When 检查，Then 无"配置已生效于真实调用"类表述；页面含"配置即预留"提示。

3. 密钥输入 / 回显 / 轮换界面（部署期 KMS 通道）；密钥引用的界面化管理（V1.5 再议）；
4. 审计落库 / 上链（C-8.4 / DB-137）；AI 调用日志（3.10.3 已预留，本页零关联）；
5. 智能路由 / 降级 / 灰度、模型资产目录、计量计费（C-11.1 P1 面）；
6. 变更留痕的界面级回滚 / 归档 / 删除操作（留痕只读）；

## 5. 边界声明

1. **规格-实现边界**：本规格只约束"配置查看 / 编辑校验 / 判定预览 / 密钥红线"四行为；任何真实调用、用量统计、密钥管理界面、审计落库均为规格外，实现即打回；
2. **落位边界**：API 与表落 evidence-service（Q2-A，系统管理域既有落位）；页面落 frontend `views/platform/`（系统管理动线）；`common/model-gateway` 零改动（纯库消费）；
3. **密钥边界**：`api_key_ref` 仅引用占位（seed 空值），页面与读 API 均不返回；真实值部署期经配置中心/KMS 注入（红线 7）；
4. **错误码与权限边界**：1014 段本卡启用（分域先例）；新权限点 `platform.ai.config.read` / `platform.ai.config.write` 仅授 `platform.sysadmin`（沿 V5 三员分立先例：secadmin / audadmin 不持新点，负向 403 天然可演）；
5. **诚实边界**：配置即预留（B4-3）；本页 ≠ AI 服务可用（零外呼）；预算上限 ≠ 已生效熔断（无运行时拦截链）；判定预览 ≠ 真实调用结果（V1.0 已用量恒 0）。
