## 一、范围与设计要点（立卡段）

- **业务目标一句话**：把资源域"非属主 / 跨空间 / 不存在"三态的拒绝提示从"404 + `1007C0005` + 资源不存在或无权访问"改为规格 B3-2 派生口径"**400 + `1000C0003` + 与对象不存在同文**"，在保持防枚举（三态同码同文）与内部拒绝留痕不变的前提下，消除 CHG-C-10.1-V1.3 裁决 A 案所指的规格-实现偏差。
- **改造面极小、但边界重要**：真正的拒绝分支只有 `DatasetQueryService` 两处（R2 详情、R14 留痕读面），但共享常量与异常映射被写面/治理面复用——**设计必须先画清"仅读面两分支改、其余面零变化"的隔离线**，否则会把口径改造变成全模块错误码重构。
- **不新增错误码**：复用平台公共码 `1000C0003`（`ErrorCodes.RESOURCE_NOT_FOUND`）；HTTP 400 由全局处理器按 `ErrorType.CLIENT` 落定；文案为服务端常量（禁止拼接用户输入，章程 4.3）。
- **验收基准已固定**：剧本 C-10.1 V1.6 S2-4 正文预期字面（400 + `1000C0003`）即本卡验收基准；规格与剧本正文均不改，改造完成后按剧本正文复验 S2-3/S2-4/S2-5。
- **首动作（编码段新会话）**：读本卡 → 读规格 B3-R2/B3-AC2/B4-R2/B4-AC2 + CHG §7 + 剧本 :39-41/:111/:115/:117 → 复读 `DatasetQueryService`/`CatalogExceptionHandler` → 产出 lofi/hifi V0.9 → 提请一次确认。
