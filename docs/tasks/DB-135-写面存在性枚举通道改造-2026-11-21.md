## 一、范围与设计要点（立卡段）

- **业务目标一句话**：把资源域写操作（资源更新 / 资源注销）对"不是你的资源 / 别的空间的资源 / 不存在的资源"三种情况的提示统一为规格 B3-R2 派生口径"**400 + `1000C0003` + 资源不存在**"（与读面 DB-132 交付口径同一字典），消除"用 403 区分'存在但非属主'与'不存在'"的存在性枚举通道。
- **改造面极小、但边界重要**：真正的属主分支只有 `DatasetCommandService.requireOwner` 两处调用点，但 `1007C0006` 同时服务**入驻资格门槛**（另一语义、Q8-A 已裁决防枚举设计）、共享"不存在"常量服务治理面/产品面——**设计必须先画清"仅写面属主门槛改、资格门槛与共享常量零变化"的隔离线**（DB-132 同款隔离手法）。
- **不新增错误码**：复用平台公共码 `1000C0003`（`ErrorCodes.RESOURCE_NOT_FOUND`）与读面文案常量 `DATASET_READ_NOT_FOUND_MESSAGE`（"资源不存在"）；HTTP 400 由全局处理器按 `ErrorType.CLIENT` 落定；文案为服务端常量（禁止拼接用户输入，章程 4.3）。
- **验收基准已固定**：规格 B3-R2/B3-AC2 字面即本卡验收基准（剧本无写面属主正文步骤，双向参照沿 DB-132 思路由既有 S2-3/S2-4 承载思路对照）；规格与剧本正文均不改。
- **首动作（设计段）**：读本卡 → 复读规格 B3-R2/B3-AC2/B4-R2/B4-AC2 + 台账 DB-135 行 → 复读 `DatasetCommandService` 写面全链（update/cancel + 留痕）与 `CatalogExceptionHandler` 映射 → 产出 lofi/hifi V0.9 → 提请一次确认。
