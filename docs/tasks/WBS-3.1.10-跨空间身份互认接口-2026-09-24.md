## 一、范围与设计（本卡设计见两级设计文件，正文不重复）

- **做什么 W1~W8 / 不做什么 N1~N7**：见 `docs/designs/WBS-3.1.10-lofi.md` §1；
- **结构组成**：lofi §2；**主要流程**：lofi §3；
- **编码契约**（接口契约表 / 库表 / 错误码 / 配置与衔接 / 边界值与异常 / 测试锚点 / 演示口径 / 变更登记 / 实施前置检查项）：见 `docs/designs/WBS-3.1.10-hifi.md` §1~§10。

**设计要点摘要（供快速表决）**：

1. **落位**：协议实现落 `std-adapter` 的 `did` 域（替换占位、`implemented=true`），HTTP 端点落 `services/did`（`/api/v1/did-interop/...`）——收口纪律 + std-adapter 为无端口纯 jar 库（ADR-008 §2）；
2. **协议签名**：只冻结"业务口径方法"（来访验证 / 出向验证 / 样例清单），并在 ADR-008 补记明示"非信通院协议签名，规范文本入库后按变更流程冻结协议签名"；
3. **模拟对端**：三态样例（有效 / 对端已吊销 / 签名被篡改）以资源 JSON 入库，签名为制作期**真实 SM2 签名**（私钥不入库、运行期不内置）；
4. **三查对端口径**：签名 / 对端状态 / 对端绑定全部经互认通道取数，**不查本空间主体库**（规格行为 5 规则 2 明示）；
5. **留痕**：新表 `did_interop_log`（方向 / 对端空间标识 / DID / 结果 / 原因 / 时间），不存原文，不改 3.1.9 既有表；
6. **错误码零新增**：复用 `1005C0004` / `1005S0002` / `1003C0001`；
7. **出向验证**：端口倒置（`LocalDidStatusPort`），不引入 HTTP 自调用。

### 7.3 建议项（未阻塞，供后续包吸收）

1. **① 可达性口径**：`samples()` 与 `callInbound/callOutbound` 的 1005S0002 收敛在装配期资源缺失时不可达（Spring 上下文启动即失败 = fail-fast）；入向 `UNAVAILABLE` 分支在生产不可达（样例为进程内数据）——建议在 hifi §6/ADR-017 §8 补一句可达性说明，避免后续评审误判为"未承载"。
2. **② 传递依赖登记**：`std-adapter → common-crypto` 使 std-adapter 消费方类路径新增 `bcprov-jdk18on`（基线已锁定，非新坐标）；建议 ADR-008 §9 补"传递影响"一句。
3. **② 样例公开边界**：`GET /samples` 公开 `data`/`signature` 等价于公开演示凭证（可重放为 PASS）；建议 ADR-017 §8 诚实边界补一句，并注明"无鉴权端点每次调用写一行留痕"的演示期量增面。
4. **② 装配约束**：`DidInteropStandardConfig` 的 `@ConditionalOnMissingBean` 由使用方 `@Import` 触发——若使用方在**同一**配置类内自定义实现，条件求值顺序可能不稳定；建议 ADR-008 §9 记一句使用约束（自定义实现放独立配置类或不 `@Import`）。
5. **③ 词汇重复理由**：`InteropResult/InteropReason` 与 `VerificationOutcome/VerificationReason` 平行存在是模块依赖方向所迫（std-adapter 不得依赖业务域），映射处为穷尽 `switch`（新增枚举值即编译失败）+ 逐值映射测试；建议 ADR-008 §9 补一句存在理由。
6. **③ 错误码差异注记**：出向 DID 格式非法用 `1005C0004`，3.1.9 同类场景用 `1005C0001`（hifi §2/§4 明确指定）——建议 ADR-017 §8 注记该差异，避免后续误判为一致性缺陷。
7. **③ 留痕表收敛评估**：`did_interop_log` 与 `did_verification_log` 字段部分重叠（did/result/reason/时间），独立表已由 lofi Q5 裁决——建议 3.1.12 或统一审计视图阶段做一次收敛评估。
8. **④ 测试加固**：① 增加"实现结论 == 样例 `expectedResult/expectedReason`"遍历断言（现由 3 条硬编码断言间接覆盖，缺直接护栏）；② `verifiedAt` 只断言非空，未钉 ISO-8601 秒级口径（hifi §2 要求，3.1.9 同样偏弱）；③ `InteropSeamTest#互认应用服务仅依赖互认域接口类型` 为构造器签名检查，可扩展为"did 服务源集不得引用 did 域具体类型（接口/端口/DTO 之外）"；④ T9 目前只扫进程内 appender，可加 `services/did/logs/*.log` 落盘扫描。
