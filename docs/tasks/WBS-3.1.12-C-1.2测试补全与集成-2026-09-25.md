**设计要点摘要（供快速表决）**：

1. **本包不加业务功能**，只做三件事：补测试缺口（含上游登记欠账）+ 实测覆盖率/变异数字 + 端到端联调留痕；
2. **达标线**：`did` 核心模块行覆盖 ≥80%、变异杀除率 ≥60%；触及模块整体 ≥70%（章程 4.2 / AGENTS.md §4）；
3. **工具形态 = 命令行临时注入**（沿 3.1.6 先例）：不改 pom、不开门禁，实测数字与接入建议交 2.2.8（DB-06）承接；
4. **补测清单**：后端 T1~T8（互认测试加固 4 项 + 3.1.11 S6/S7/S8 + 并发幂等）、前端 F1~F5（分页越界 / 空态 / 取消零留痕独立断言 / 恢复模式反向探针 / 类型收口）；每条均带"删锚验证（必红项）"；
5. **联调**：真实环境跑通 C-1.2 端到端六项链路，并以"第三方视角取 DID → 验身份"闭环证明**下游可消费性**；
6. **本卡最大不确定点 = "与连接器注册联调"**：连接器注册服务（WBS 3.6.3）**无规格、无实现、未开工**，且不在本卡依赖链内 → 处置见 lofi **Q1**（建议 A：本卡只做接口级可消费性证明，真联调顺延并走变更流程同步规格表述）。
