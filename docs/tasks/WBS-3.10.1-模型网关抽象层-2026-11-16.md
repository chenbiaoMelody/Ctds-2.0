## 一、范围与设计要点（立卡段）

- **业务目标一句话**：为平台装一个"模型插座"——定义统一的 OpenAI 兼容接口和国产模型（GLM/DeepSeek/Qwen/Kimi）适配器接口，换模型只改配置不改代码；V1.0 只装插座不通电（零真实调用、零费用、零业务功能），V1.5 的 AI 功能（C-11.x）即插即用。
- **为什么现在做**：WBS 3.10 AI-0 底座预留是 V1.0 P0 承诺（PRD :291），3.10.1 是 3.10.2~3.10.4 与 V1.5 全部 AI 功能的地基；依赖 2.1.3（ADR-003）已批准，无前置阻塞。
- **规格先行缺口是本卡第一决策点**：AI-0 无已评审规格（11 份规格均不覆盖），必须先按 Q1 裁决补齐规格再进设计/编码，禁止以 ADR 直接代替规格猜测需求。
- **体量控制**：纯抽象 + 配置 + 契约测试，无 DB/无 HTTP 端点/无集成容器，预计单 PR 可承载；若实测超 400 行按 AGENTS §6 拆分并呈报。
- **首动作（编码段新会话，定稿确认后）**：读本卡 + 规格 V1.0 + hifi V1.0 → 建分支 `feat/WBS-3.10.1-模型网关抽象层`（自本地 main 梢，须编排师提交/建分支指示）→ 模块骨架 + 根 pom 登记 → T1~T6 红相留痕 → 实现 → 绿相 → 门禁。
