## 一、范围与设计

- **做什么 / 不做什么**：见 lofi「做什么 / 不做什么」两节与 hifi 端点表 / 错误码表 / 表设计 / 校验链；落地对象 = 规格行为 1 规则 3（受控词表选取）与 §末未定义项（词表集合），并承接确认行为 1 规则 5（数据标识，3.3.2 已兑现）。
- **两级设计一并提交**（章程 2.6.3 ≤1 天卡）：lofi = 方向（宿主与迁移 / 表清单 / 校验通道 / 端点 / Q 清单），hifi = 编码契约（端点契约 / 错误码 / 表结构与约束 / 校验链与顺序 / 匹配口径 / 测试计划 / 分级落级 / 骨架）。

**设计要点摘要（供快速表决）**

1. **宿主续建、不新建服务**：仍在 `catalog-service`（8084 / `ctds_catalog`）加功能，迁移顺延 **V2**；目录域"一域一服务"（3.3.2 Q1-A）不变；
2. **2 表承载词表**：`tag_vocabulary`（词表册）+ `tag_term`（词条，含 `normalized_term` 与业务编号 `term_code`）；种子词条 12 条随 V2 迁移内置（沿 3.2.5 平台基线种子先例）；**不预置未用列**（无状态列、无排序列——V1.0 无维护写面）；
3. **`semantic_tags` 载体形态不变**（JSON 文本），词表只作**字典校验**——免改 3.3.2 表结构、免走变更流程、免回填既有演示数据（Q2-A）；
4. **写面成员校验接入 2 处**（登记 / 变更），插入点选在**判重与取号之前**（非法入参零库内副作用，保持 3.3.2 既有性质）；匹配口径 = 复用 `DatasetNameNormalizer` + DB 侧 `IN`（`0900_ai_ci` 折叠大小写），**不新增第二套归一化**（呼应 DB-30）；
5. **读面 2 端点 + 权限点 `vocabulary.read`**（1 行 yml 映射；不做 ADMITTED 门槛——词表为平台公开字典，Q8-A）；
6. **错误码顺延 2 枚**：`1007C0009`（标签非受控词表 → 400）/ `1007C0010`（词表不存在 → 404），文案不回显被拒标签原文；
7. **分级落级**：词表册与词条 = **CAT-03 L1**（公开目录词汇），回写分级规范 §6.1（沿用 3.2.2/3.3.2 先例）；
8. **剧本同步两处待批**（Q9）：C-3.1 增补"非词表标签被拒"一步 + C-3.2 前提⑤归属措辞校正（业务判定一字不改）。
