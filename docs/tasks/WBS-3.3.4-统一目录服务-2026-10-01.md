## 一、范围与设计

- **做什么 / 不做什么**：见 lofi「做什么 / 不做什么」两节与 hifi 端点表 / 错误码表 / 表设计 / 校验链；落地对象 = 规格行为 5（统一目录检索与分类）、行为 6（订阅与收藏）与 §末未定义项四件（类目树与种子类目 / 排序口径 / 通知渠道 / 语义检索预留接口形态）。
- **两级设计一并提交**（章程 2.6.3 ≤1 天卡）：lofi = 方向（宿主与迁移 / 表清单 / 端点 / 资格门槛 / Q 清单），hifi = 编码契约（端点契约 / 错误码 / 表结构与约束 / 校验链与顺序 / 排序与过滤口径 / 测试计划 / 分级落级 / 骨架）。

**设计要点摘要（供快速表决）**

1. **宿主续建、不新建服务**：仍在 `catalog-service`（8084 / `ctds_catalog`）加功能，迁移顺延 **V3**；目录域"一域一服务"（3.3.2 Q1-A）不变；
2. **产品载体最小表随本卡落**（Q1-A）：规格行为 5 的检索对象 = 已上架产品，而产品写面（封装/上下架）归 3.3.5——本卡建 `data_product` 最小载体表（字段全部来自规格已裁决明文），3.3.5 在其上做封装写面并按其落定权扩展字段（其迁移增列）；本卡端点对着该表实现，集成测试自造产品数据验证；
3. **类目树 = 平台唯一受控类目集合**（Q2-A）：单表 2 级树 + 种子类目随 V3 内置；资源分类申报 `declare_category` 接入"类目成员校验"（沿 3.3.3 词表成员校验同款模式：只作用新写入、不回填历史、复用既有校验链插入点）——兑现 3.3.2 移交的"类目树校验"；产品挂 `category_code` 字符串载体（沿 declare_category 先例），写入归 3.3.5；
4. **状态联动 = 读时计算**（Q5-A）：收藏/订阅条目不带状态列，列表查询联产品当前状态返回——"下架/注销后条目保留但标记当前状态"自然成立，**免 3.3.5 动作回调、免跨包写耦合**；
5. **订阅感知最小面**（Q6-A）：`product_action_log` 产品变更留痕表本卡建载体、**写入归 3.3.5**；本卡读面 = 我的订阅列表（含产品当前状态）+ 订阅产品的变更留痕可查（限定本人订阅者）；实时推送不做（归 3.7.2 评估）；
6. **检索资格 = ADMITTED 门槛复用既有通道**（Q8-A）：检索/详情/收藏/订阅全链经 `SubjectAdmissionPort` 既有判定，未入驻拒绝口径与 1007C0006 同款防枚举统一文案；未上架/不存在/已下架产品详情同形拒绝（新码）；
7. **排序默认上架时间倒序**（Q4-A，规格建议口径），不设排序参数；
8. **语义检索预留 = 契约落定、代码零占位**（Q7-A）：检索端点路径/参数/响应结构在本卡 hifi 登记为 3.10.2 语义扩展基线，不写占位端点（不留死代码）；
9. **错误码顺延**：1007C0011 起（码值与 HTTP 映射随 hifi 定稿）；**分级落级**：类目树/种子/收藏/订阅/交互留痕 = CAT-03（级别随 hifi 定稿），回写分级规范 §6.1（Q9）。
