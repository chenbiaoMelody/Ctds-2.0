## 一、范围与设计

- **做什么 / 不做什么**：见 lofi「做什么 / 不做什么」两节与 hifi 端点表 / 错误码表 / V4 迁移 / 校验链 / 状态机矩阵 / 测试计划；落地对象 = 规格行为 3、行为 4、行为 2 规则 2、行为 7 规则 3 与 §末未定义项五件。
- **两级设计一并提交**（章程 2.6.3 ≤1 天卡）：lofi = 方向（宿主与迁移 / 端点 / 状态机 / 治理留痕 / Q 清单），hifi = 编码契约（端点契约 / 错误码 / V4 表扩展 / 校验链与顺序 / 动作码值域登记 / 测试计划 / 分级落级 / 骨架）。

**设计要点摘要（供快速表决）**

1. **宿主续建、迁移 V4 增列扩展**：仍在 `catalog-service`（8084/`ctds_catalog`）；`data_product` 增 `price_amount` + `normalized_product_name` + 归一化唯一键；留痕动作码值域注释登记（DB-29 V4 先例）；
2. **产品编号不取号**（Q1-A）：沿 R2/R7 先例以自增 id 为路径参数，`dataset_no_seq` 预留位零触碰；
3. **定价单列 + 草稿态宽容、上架门槛强制**（Q2-A）：`price_amount DECIMAL(12,2) NULL`，免费档恒 NULL；付费档草稿态可缺失、**上架时强制齐备**（C-3.3 剧本 S2-2 判定面 1007C0020）；
4. **跨形态封装允许**（Q3-A）：规格"不同形态"明文支持；**数量上限不设**（Q4-A，门槛四重管控，3.3.7 再评估）；
5. **状态机封闭在服务端**：DRAFT→LISTED/CANCELLED；LISTED⇄DELISTED；LISTED→CANCELLED 拒绝（须先下架）；CANCELLED 一切拒绝；`listed_at` 上架写下架清（V3 注释锚定口径）；
6. **治理例外两侧齐备**（Q5-A）：R12 产品 + R13 资源治理详情（admin + 新权限点 `catalog.governance`），每次查看写 `GOVERNANCE_VIEW` 留痕（DB-29 同款：通用码 + 实际登录主体 + 仅运营方触发）；**DB-37 落定 = 读面拒绝不留痕**；R8 订阅者可见值域 = 变更类六码；
7. **引用保护实体化**：`NoopProductReferenceGuard` → 实体检查（既有 W3 接线零改动，命中拒 1007C0021）——C-3.1 剧本 S3-4 兑现；
8. **DB-34 顺手收口**（Q6-A）+ **新写面并发唯一键第一天即转业务码**（0017）；**DB-35 评估 = V1.0 不做服务内频控**（Q7-A 留痕）；**DB-36 = 新端点沿产品面中文显示名轨，DatasetView 不动**（Q8-A 收窄移交 3.3.6）；
9. **分级维持 CAT-03 L1**（Q9-A 复核结论回写 §6.1）；错误码 1007C0015~0021 共 7 码（码数锚 16→23 合法同步）。
