## 一、范围与设计（本卡设计见两级设计文件，正文不重复）

- **做什么 / 不做什么**：见 `docs/designs/WBS-3.3.7-lofi.md` §1、§2；
- **待确认问题**：lofi §3（**Q0~Q5**）；**体量**：lofi §4（预估 400~600 行有效变更，测试与 SQL 脚本为主、业务代码零改动——沿 3.3.6"含测试与注释"D1 豁免口径申请不拆分）；
- **编码契约**（达标口径与工具形态 / 盘点方法与映射骨架 / 补测清单 / 万级数据集构造与基准 / 联调方案 / 交付门禁 / 边界值 / 前置检查项）：见 `docs/designs/WBS-3.3.7-hifi.md` §1~§8。

**设计要点摘要（供快速表决）**：

1. **本包不加业务功能**，四件事：补测试净缺口（T1~T4）+ 行覆盖实测达标数字 + 万级目录数据集构造与检索基准（首例，产出可复用脚本）+ 真实环境联调留痕；
2. **达标线**：catalog-service 行覆盖 **≥70%**（非核心模块，沿 3.2.7 space 口径；ADR-018 归档档位开工核读锁定）；基线 **186 例** → 预计 **190± 例**；
3. **工具形态 = jacoco 命令行临时注入**（沿 3.2.7 先例）：不改 pom、不开门禁，数字留痕；
4. **万级基准 = SQL 造数/清理脚本（单一事实源）+ 集成测试容器内实测**（资格门 stub 诚实边界注明；演示库零污染；正式并发压测与阶梯加压归 4.2.1）；检索 P95 ≤500ms 判定（章程指标锚）；
5. **联调 = 演示环境真链复验三剧本关键链 + F1/F2 修复点抽验**（沿 3.2.7 Q1-A 一次性走查留痕；新增写数据留置登记，沿裁定②）。
