**设计要点摘要（供快速表决）**：

1. **新模块 `services/delivery-service`（Servlet，8087，MySQL `ctds_delivery`）**——交付域宿主；不改造网关（网关保持 API 调用链四件），不把文件交付塞进 contract/catalog；零新第三方依赖。
2. **承接 3.5.2 Q5-A 交付记录宿主**：`delivery` 通用模型同时承载 **API 交付记录**（S1-1）与 **文件交付记录**（S2）；提供参与者读面 + 治理读面 + 幂等；API 交付发起**不消耗策略次数**（真正计数在网关调用链），文件交付作为一次使用消费 `check` 一次（Q4）。
3. **准入链路固定**（Q3/Q7）：身份 → 幂等查重 → **合约内部只读摘要**（参与方 + 生效 + productId/applicantNo/providerNo，**不计数**）→ 发起人=需求方 → 目录内部产品 `productType` → 形态/范围校验 →（文件）策略 `check` → 生成加密包 → 记录；任一拒绝**不产生交付记录**、不生成包。
4. **跨域最小加性**：contract 新增 `GET /api/v1/contracts/internal/contract-summaries/{contractNo}?requesterNo=`（只读、不计数、复用 `ContractVisibilityGuard` + 生效门槛）；catalog `InternalProductView` 增 `productType`；`delivery-internal` 服务身份各 1 行授权；ADR-016 §6 第 8 位消费方。**ADR-022 内部判定响应零改动**（不破坏网关契约）。
5. **文件源 = 配置化清单**（`ctds.delivery.files`：fileId/productId/相对路径/展示名；源根 + 存储根配置；启动校验 fail-fast；fileId 仅作精确键，**不接受用户路径**）——演示期合成 CSV；生产级文件接入/对象存储登记演进（3.6.x / 后续包）。
6. **国密加密与完整性**：SM4/GCM（`common-crypto`）生成加密交付包 + SM3 明文摘要；**明文 ≤64MiB**（ADR-006 上限），超限 400 明确拒绝；流式分块登记演进；**不自行实现任何密码学**。
7. **领取形态**：需求方下载**加密交付包**（`application/octet-stream` + `X-Ctds-Sm3` 头）；**接收方密钥分发不在 V1.0**（登记边界，演示剧本只校验包与校验值）。Q5 可选叠加“演示用服务端受控明文领取”，默认不做。
8. **交付记录不含本体**：只记 deliveryNo/contractNo/product 快照/deliveryType/fileId/fileName/fileSize/packageId/SM3/result/时间；DB、审计、日志、界面均无文件本体与原文（行为 3 规则 2 / 行为 7 规则 5）。
9. **幂等**：`@Idempotent`（memory 结果复用）+ **DB 唯一键 `(requester_no, idempotency_key)`** 永久兜底；重放返回首次结果，**不重复生成包、不增加记录**。
10. **读面与防枚举**：参与者详情/列表；治理例外读面（admin + 审计）；非参与方/不存在**同码同文 1009C0007**；需求方专属包下载（`delivery.package.download`）；pageSize ≤100。
11. **错误码**：1009 段顺延（`1009C0005~0009`、`1009S0002/0003`）；合约域 C 型码原码透传（1008C0008/0012/0013/0020）；未认证/无权限复用 1000 段。
12. **契约与合规**：新建 **ADR-023 文件交付契约**（记录模型/包格式/准入链/访问边界/接收方密钥边界/演进）+ 分级规范 §6.1/§6.2 回写；k8s 两文件 + kustomization 2 行；**前端零改动**（界面归 3.5.6）。

| **G1** | **剧本 S2 与规格形态一致性缺口（需变更流程）** | **A 建议（推荐）**：认定剧本 S2 应使用**数据集形态已生效合约**（附录 A 补充凭据）而非“同一 API 合约”，并按 Q4 补 purpose/territory；业务判定不变（文件交付仍须“合约生效 + 数据集/报告/模型形态 + 参与方 + 策略合规”）；由剧本维护流程修订 S2 步骤 1 与附录说明，**PO 批准**后生效；可选加一步“API 形态合约 + 文件交付 → 拒绝”（反向锚）；B：允许 API 形态合约做文件交付（违反规格行为 3 规则 3，不采）；C：S2 暂不执行等后续包（剧本不完整，关闭条件⑥无法达成） |
