**设计要点摘要（供快速表决）**：

1. **落位 `delivery-service` 沙箱子域内**（Q1-A 沿 3.5.4）：同库 Flyway **V3**、端口 8087 不变、零新模块 / 零新依赖；`Sandbox*` 前缀划界不变。
2. **结果物 = 提交审核时登记**（Q1-A）：`sandbox_result` 表（一任务一文件名一行），状态 待审核 / 已通过 / 已驳回；**提交时快照 SM3 + 字节数**，导出时复核——结果物在审核后又被作业覆盖 → 拒绝导出、须重新提交审核（防"审 A 交 B"）。
3. **驳回不是死路**（G2-A）：已驳回结果物可**重新提交**（进入新一轮审核，轮次与历史全留痕）；已通过不可再提交；**规格未定义项，沿 G1 先例请 PO 批准留痕（§7 补 G2 行），剧本步骤与业务判定一字不改**。
4. **审核 = 治理写面新端点**（Q2-A）：运营方 `sandbox.review` 权限点，通过 / 驳回（驳回理由必填）；结论一经作出**不可修改**（纠错走重新提交流程）；审核留痕 = 专用 `sandbox_result_review` 表（谁审 / 何时 / 结论 / 理由）+ 审计。
5. **导出 = 一次交付动作**（Q3-A）：审核通过 → 策略 `check`（一次导出一次计数，拒绝零计数零记录）→ **SM4 加密导出包 + SM3 头**（复用 3.5.3 加密包机制，`common-crypto` 唯一入口）→ **导出记录 = `deliveries` 新增 `SANDBOX_EXPORT` 类型**（加列 `sandbox_no` / `result_name`；3.7.5 计量与 3.8.3 存证的**单一交付事件源**不双轨）→ 领取复用交付包下载端点先例。
6. **生命周期门槛**（Q4-A）：提交 / 审核 / 导出均要求任务 **RUNNING**；到期 / 已关闭一律 `1009C0011`（锚剧本 S3-6"继续使用**或导出**被拒"）。
7. **服务端强制 + 防枚举**（Q6-A）：未审核 / 已驳回 / 快照不一致导出 → `1009C0016`；绕过界面直调同拒；非参与方查看 / 导出他人结果物 → `1009C0015` 与"结果物不存在"**同码同文**；错误码 1009 段顺延 0015~0016。
8. **无本体纪律不变**（Q8-A）：登记 / 审核记录 / 导出记录 / 审计 / 日志 / 响应只含业务要素（文件名 / 字节数 / SM3 / 结论 / 理由 / 结果码），无内容、无路径、无容器、无命令；导出包为唯一带内容物且**仅密文出服务**。

## 二、决策点与确认留痕（待编排师一次确认；章程 2.6.3）

> 决策点全文与备选业务影响见 `docs/designs/WBS-3.5.5-lofi.md` §3；下表为摘要。

| 编号 | 问题 | 建议口径 |
| --- | --- | --- |
| **Q1** | 结果物登记与状态机 | **A 建议**：提交审核时登记 `sandbox_result`（一任务一文件名一行）+ 快照（SM3 / 字节数）；状态 = 待审核 → 已通过 / 已驳回；导出不改状态、可多次（每次一次计数）；B：结果物全量预登记（无提交动作，状态语义弱）；C：不落库纯文件判定（审核留痕无处落、导出复核无锚） |
| **Q2** | 审核操作形态 | **A 建议**：治理写面新端点（`POST …/governance/{sandboxNo}/results/{fileName}/actions/review`）+ 新权限点 `sandbox.review`（仅 admin）；body `{conclusion: APPROVE\|REJECT, reason}`，驳回理由必填（≤256 字）；结论不可修改；审核记录专用表 `sandbox_result_review`；B：需求方自审（违反行为 7"治理例外唯一"）；C：复用治理读权限点（读写不分权，越权面大） |
| **Q3** | 导出链路与载体 | **A 建议**：导出 = 一次交付动作——`check`（放行计数）→ SM4 加密导出包 + SM3 头（复用 3.5.3 `FilePackageStore` 与下载端点先例）→ **导出记录复用 `deliveries`**（新增 `SANDBOX_EXPORT` 类型 + 加列 `sandbox_no` / `result_name`）；B：独立 `sandbox_export` 表（交付事件源双轨，3.7.5 / 3.8.3 需读两表）；C：导出即明文流式下载（违反国密唯一入口与 CAT-04 传输加密口径） |
