**设计要点摘要（供快速表决）**：

1. **本包不加业务功能**，四件事：达标盘点与映射回填（**规格 7 行为 38 条验收标准层面零净缺口**——立卡前两路只读子智能体盘点结论：全部锚点类#方法级承载、章程 4.3 双向用例四条链路面双腿齐备、防枚举同码同文各端点齐备、幂等五写端点全覆盖）+ 补测净口子（**B2 跨域对账锚 = 唯一测试侧缺口** + DB-50 + DB-53 八项逐项核对 + gateway 择项）+ 行覆盖实测达标数字 + 两剧本真链联调；
2. **达标线**：delivery-service 行覆盖 **≥70%**（ADR-018 overall 档现行口径）+ gateway-service 实测数字留痕（同批注入零额外成本）；基线 delivery 194 / gateway 35 / 前端 548 → **用例数只增不减**；jacoco 命令行临时注入只测量不开门禁（沿 3.4.8 Q2-A；档位修正归门禁增强卡）；
3. **联调 = 演示环境真链复验两剧本关键链 + ⚙ 技术侧步全量补走**（沿 3.4.8 Q1-A 先例）**+ 网关 8086 交付链补走**（3.5.6 走查全经 5173→8087 直连，网关链未复验）+ G8 治理面抽验；"与计费联调" = **B2 对账锚 + 对账本体转移 3.7.x 登记**（3.7.5/3.7.6 未开工，沿 3.4.8 口径声明依赖边界）；**造数收口 = 新增留置并入 DB-64 第⑤段登记、严禁清理脚本**（DB-64 红线）+ 沙箱容器清场（非库数据）；
4. **评估留痕件零实施**：受控执行端点退役评估（触发已成立，结论留痕默认不动代码）+ ADR-025 §6 四项 + DB-54/56~62 再排期建议 + DB-63/66 裁决建议（建议维持现状，裁决权在编排师）+ DB-65 顺手勘正 + 性能豁免留痕（正式归 4.2.3）+ 台账计数残段补记；
5. **DB-64 本体清理与 F-W1 修复不在本卡默认范围**（F-W1 单列 Q4 供裁决；DB-64 严禁脚本人工处置）。
