## 一、范围与设计

- **做什么 / 不做什么**：见规格 `docs/specs/C-6.1-6.3-接入连接器.md` §3（**14 条行为**）与 §4（非目标 10 项）；本卡不做设计类文件（免设计，理由见下）。
- **免设计声明（章程 2.6.2 免设计类）**：本卡为**纯文档类**任务——交付物即"规格 + 剧本"本身，**没有可设计的产品形态**（无界面、无服务、无数据模型）；连接器域的 SDK 骨架 / 注册核验 / 生命周期 / 适配器 / 控制台设计分别在 **3.6.2 / 3.6.3 / 3.6.4 / 3.6.5 / 3.6.6 / 3.6.7** 实施包内走两级设计门禁。故本卡**不产出 lofi/hifi**，以规格 §7 决策点清单（Q1~Q9）承接"方向确认"，以规格全文承接"实施包的上游输入"（沿 WBS-3.1.7 / 3.2.1 / 3.3.1 / 3.4.1 / 3.5.1 同款免设计先例）。

**设计要点摘要（供快速表决）**

1. **一份规格覆盖三条 P0**（C-6.1 标准连接器 / C-6.2 注册与全生命周期 / C-6.3 多源适配），拆为 **14 条业务行为**（5+5+4），每条带 3~4 条可判定的验收标准（共 49 条）；
2. **身份锚 = 所属主体 DID + 唯一连接器编号**：连接器不另设独立 DID（DID 服务对象模型零扩展）；设备级凭证体系归 3.9.1 统一演进；
3. **注册两步制 + 核验三查**（沿 C-1.1 注册-审核惯例）：主体资格 ADMITTED / 主体 DID 有效 / 信息完整；拒绝可读理由 + 留痕 + 补正重提；
4. **生命周期三主态**（待核验 → 已注册 → 已注销终态）：升级 = 兼容原子替换 / 不兼容运营方显式确认；注销前置 = 无进行中交付作业；**编号终身不复用**；
5. **执行点全在平台侧**：交付统一经平台网关唯一入口、策略判定唯一权威在合约域引擎；连接器"使用控制功能"= **消费判定结果 + fail-closed**（拒绝即终止、不得本地放行）；
6. **多源适配四类源全量 + 凭据国密加密存储**：政务共享交换平台 / 数据库 / 对象存储 / API 网关；凭据只显掩码（ADR-006 / 015 唯一加解密入口）；连通性自检只读探测、三类失败原因可读；**先判定后取数**；
7. **健康度最小语义预留**（在线 / 离线）：承载归 3.6.3、展示归 3.6.7、监控对接归 3.9.4——3.6.7"健康度"页面的规格依据；
8. **错误码预留 1010 段**（立卡时实测 `1010C` / `1010S` 全库零占用）；编号前缀与码值随实施包落定；
9. **三份剧本四幕分布**（C-6.1 接入幕 / C-6.2 注册核验幕 + 升级注销幕 / C-6.3 适配幕），界面入口占位待 3.6.7 一次性核对修订；
10. **沿承净承接七项落位**：CHG-C-1.2-V1.1"下游消费方"预留 → 行为 3 / 8；真实源接入归连接器（3.5.2 承接）→ 行为 14 + §6-4；跨机构不出域划界（3.5.1 承接）→ §4-8 / §6-1；3.5.3 / 3.5.4 / 3.5.5 三卡纪律汇总 → §6-5；本地 main 领先 2 笔纯文档随本卡 PR 入库；台账行 19 预挂的一次确认 = 本卡 §二；踏勘三件（connector-sdk 空目录 / 无 C-6.x 规格 / 3.6.3 依赖 3.1.9 已闭环）入 §五。
