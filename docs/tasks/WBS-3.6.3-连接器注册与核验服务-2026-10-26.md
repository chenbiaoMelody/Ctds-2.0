## 一、范围与设计

- **做什么 / 不做什么**：见 lofi §1（业务可读行为清单 9 条）与 §2（边界划清 9 条）；技术契约见 hifi（装配 / 表结构 / 类清单 / 接口签名 / 端点契约 / 错误码 / 状态机 / 测试清单）。
- **设计组织**：非界面类两级设计——lofi（方向确认：行为清单 + 决策点 Q1~Q8 + 边界值）→ hifi（定稿确认：表结构 + 端点契约 + 错误码表 + 测试清单 = 编码契约）；≤1 天一并提交，请编排师**一次确认**。

**设计要点摘要（供快速表决）**

1. **新服务 `services/connector-service`**（8088 / `ctds_connector`）：四层沿 delivery-service，JDBC 手写 SQL + Flyway，零新依赖、零 jacoco 显式声明（门禁脚本承载）；
2. **双轨编号**：申请单号 `CA` + 6 位（登记即签发，待核验态可寻址 / 可补正）+ 连接器编号 `CN` + 6 位（**核验通过事务内签发**，规格行为 6-4 / 7-3 明文；终身不复用）；
3. **核验三查**：主体资格（subject 既有内部端点）+ DID 有效（**did 新增内部只读端点** `GET /api/v1/did/internal/subjects/{subjectNo}/current`）+ 信息完整（本域校验）；**跨域不可达一律 503，不冒充业务结论**（fail-closed）；
4. **防枚举同码同文**：非属主 / 不存在一律 `1010C0003`「未找到该记录或无权访问」，不给相邻记录线索；
5. **绑定实时联动**：绑定表只存 `connector ↔ did ↔ 时间`，**不冗余 DID 状态**；每次查验实时查 DID 域，吊销后查验立即不通过（行为 8 验收 3）；
6. **健康度最小预留**（Q8-A）：`last_heartbeat_at` + 心跳端点 + 读时派生 `online`（阈值默认 5m，越界启动 fail-fast），零调度；
7. **1010 段落定**：`1010C0001~0007` + `1010S0001~0002`（`1010S0003` **段位预留、代码不声明**，500 由 common `1000S` 段承载），**不设 B 型**（核验拒绝 = 200 业务结论）；占用留痕写 ADR-027 §2.7。
