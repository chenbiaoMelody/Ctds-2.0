## 一、范围与设计

- **做什么 / 不做什么**：见 lofi §1（业务可读行为清单 9 条）与 §2（边界划清 10 条）；技术契约见 hifi（模块装配 / 迁移 / 类清单 / 端点契约 / 错误码 / 适配器与模拟源口径 / 测试清单）。
- **设计组织**：非界面类两级设计——lofi（方向确认：行为清单 + 决策点 Q1~Q8 + 边界值）→ hifi（定稿确认：表结构 + 端点契约 + 错误码表 + 自检 / 读取流程 + 测试清单 = 编码契约）；≤1 天一并提交，请编排师**一次确认**。

**设计要点摘要（供快速表决）**

1. **适配器落 SDK、登记落服务**（Q1-A）：`connector-sdk` 新增 `adapter/gov` 包（适配器随连接器分发，兑现行为 11-1）；`connector-service` 增量承载源登记 / 凭据保护 / 自检编排 / 内部读取；**零新模块、零根 pom 改动、零门禁配置改动**，仅 +2 个模块依赖。
2. **模拟源 = 进程内标准报文模拟器**（Q2-A）：仅 `mock://gov-exchange/**` 生效，五类演示路径覆盖通过与三类失败；`http(s)://` 走真实客户端但 V1.0 不承诺真实平台可达；**零新容器、零部署清单改动**，界面上如实标注"模拟"。
3. **凭据三列并存**（Q3-A）：`credential_ref`（不透明引用）+ `credential_ciphertext`（SM4 信封）+ `credential_masked`（掩码）；`common-crypto` 唯一入口；**密钥不可用 → 503 `1010S0004` fail-closed，禁止明文降级**。
4. **自检失败 = 200 业务结论**（Q4-A）：`passed=false` + 三类失败原因枚举 + 可读文案 + 失败留痕；非预期异常 502 中性文案（不暴露内部）。
5. **未开放类型诚实拒绝**（Q5-A）：四类源均登记受理（行为 11 验收 1）；自检 / 读取遇无适配器类型 → `1010C0011`"该源类型的适配承载尚未开放"（3.6.6 承接）。
6. **先判定后取数边界**（Q6-A，诚实口径）：本卡只提供内部读取端点 + 本地四校验（登记 / 归属 / 状态 / 类型）；**判定次序与"拒绝不触达源"的完整证明归 3.6.8 交付链**；本卡以"前置拒绝时适配器零调用"证明可证伪部分。
7. **权限 1 个 / 错误码 2 个**（Q7-A）：`connector.source.manage`（属主登记 / 变更 / 自检）+ `1010C0011` / `1010S0004`；读面复用 `connector.read`、内部复用 `connector.internal.read`；**不启用 3.6.4 预留的 `1010S0003`**（零回改 ADR-028）。
8. **注销不级联源**（Q8-A）：注销后源不可读取（读面校验 `REGISTERED`），源档案与留痕保留可查；零回改 3.6.4 注销事务。

## 七、业务可读交付说明（编码段）

**完成了什么功能**（接口级，界面归 3.6.7）：

1. **四类源都能登记**：政务共享交换平台 / 数据库 / 对象存储 / API 网关，登记成功签发 `SR` + 6 位源编号；同一连接器同类型同地址不能重复登记。
2. **凭据只显掩码**：访问凭据加密后落库（国密 SM4），接口只回显 `****abcd` 形态的掩码与一个不透明的"凭据引用"；**任何响应、日志、留痕都查不到明文**。加密组件不可用（未配密钥 / KMS 连不上）时宁可拒绝登记（503），也不明文凑合。
3. **政务源可"试连"（自检）**：一次只读探测告诉您"通 / 不通"；不通时明确写清是**网络不可达 / 凭据无效 / 权限不足**三种之一，并留下失败记录。自检不会改动源端任何数据，自检通过也不等于获得授权。
4. **未开放的源类型明确拒绝**：数据库 / 对象存储 / API 网关三类可以先登记，但试连与取数会明确回"该源类型的适配承载尚未开放"，不假装支持、不虚报通过（三类实现归下一包 3.6.6）。
5. **配置变更留痕**：改源地址 / 换凭据都会记录"旧值 → 新值"，凭据只记"已变更 + 掩码"；改完可以再试连。
6. **读取能力就位（先判定后取数）**：内部取数接口只给交付链在"使用控制判定放行后"调用，返回的是**摘要**（不含数据本体）；每次取数留痕五要素（谁 / 哪个连接器 / 哪个源 / 哪份合约 / 结果）。被拒绝的四种情形（未登记 / 跨归属 / 连接器已注销 / 类型未开放）**都不会触碰源端**（有自动化断言逐项证明）。
7. **注销后源仍可查**：连接器注销后其源不能再取数，但源档案与全部留痕保留可查（历史可追溯）。

**如何演示**（接口级，需人侧提供 `CTDS_SM4_KEY_FILE` 密钥文件）：

① 先注册一个连接器并核验通过（3.6.3/3.6.4 已有剧本）→ ② 登记政务源（地址 `mock://gov-exchange/ok`）→ ③ 试连，看到"通过"→ ④ 依次登记 `mock://gov-exchange/bad-credential` / `unreachable` / `forbidden` 三个源并试连，看到三种不同失败原因 → ⑤ 查详情，看到最近一次试连结论 → ⑥ 变更其中一个源的地址，查留痕看到"旧 → 新" → ⑦ 用数据库类型登记一个源，试连得到"尚未开放" → ⑧ 内部取数接口读取政务源，得到摘要与留痕。

**验收剧本是否需要更新**：**不需要**。C-6.3 剧本的步骤与判定口径零改动（维护说明第 4 条已写明"3.6.5 / 3.6.6 落地前不执行本剧本"）；修复批只改源地址受理规则与出站错误码口径（`allow-private-endpoint` / 502 码位 / 复审批查询串凭据键与字面量规范化），不影响剧本中任何一步的期望结果。可选（经 PO 批准）在维护说明补一行："源地址只接受 `mock://gov-exchange/**`、`http(s)://` 与 3.6.6 三类源的原生 scheme；地址中不得内嵌账号口令（含 userinfo 与查询串凭据样键）"。

**注意事项**：

- **政务共享交换平台是"模拟源"**（进程内标准报文应答），界面上会如实标注"模拟"；真实平台对接属部署实施期。
- 取数的"判定放行"次序与端到端"拒绝不触达源"的完整证明在 **3.6.8** 交付链；本卡只证明"前置拒绝时适配器零调用"。
- 三类通用源（数据库 / 对象存储 / API 网关）的自检与取数在 **3.6.6**；管理界面在 **3.6.7**。
