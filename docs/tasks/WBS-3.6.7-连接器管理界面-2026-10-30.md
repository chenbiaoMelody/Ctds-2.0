**设计要点摘要（供快速表决）**：

1. **2 菜单 + 1 深链**（Q1-A）：「连接器管理」（`/connectors`，menuOrder 20，登录可见，双 Tab = 注册申请 / 我的连接器）/「连接器治理」（`/connector-governance`，menuOrder 21，`connector.review`，三 Tab = 全平台连接器 / 注册核验 / 升级确认）/ 详情深链 `/connectors/:connectorNo`（健康度 / DID 绑定 / 版本管理 / 源接入 / 留痕 / 注销分区）；WBS 三词概称映射见 Q1。
2. **演示身份双档映射**（Q2-A）：`connectorRolesHeader()` = 普通档 **`applicant`** / 运营档 **`admin`**；主体编号决定视角；硬约束普通档不带 `admin`、任何档位不带 `connector-internal`。
3. **运营方全平台列表缺口补 1 个只读端点**（Q3-A）：`GET /api/v1/connectors/governance/connectors`（`connector.review`；状态过滤 + 分页 + `online` 派生；零新表零新码零迁移零新权限点），承接 C-6.2 S1-6 与健康总览。
4. **源接入界面纳入、运营档隐藏**（Q4-A）：四类源登记 / 变更 / 自检 / 最近自检；凭据只显掩码；政务模拟源如实标注；运营档不展示源区（DB-88 挂起），避免放大规格冲突。
5. **健康度可演示**（Q5-A）：详情「上报心跳」按钮（属主 + 已注册）+ 在线 / 最近心跳 + 阈值说明 + 手动刷新；不做自动轮询、不本地计算。
6. **零前端业务判定**：三要素 / 源地址 / 版本 / 凭据留空等均可提交，服务端文案原样展示（C-6.2 S1-2 缺版本步骤可执行）；仅演示主体为空零请求前置拦截。
7. **无幂等键**：连接器端点未启用幂等，界面不做假幂等；写按钮 in-flight 禁用仅为防误触。
