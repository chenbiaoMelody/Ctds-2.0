## 一、范围与设计

- **做什么 / 不做什么**：见规格 `docs/specs/C-7.1-7.2-门户与计费.md` §3（**12 条行为**）与 §4（非目标 10 项）；本卡不做设计类文件（免设计，理由见下）。
- **免设计声明（章程 2.6.2 免设计类）**：本卡为**纯文档类**任务——交付物即"规格 + 剧本"本身，**没有可设计的产品形态**（无界面、无服务、无数据模型）；门户前台 / 订购订单 / 评价系统 / 计量采集 / 计费引擎与账单 / 计费管理界面设计分别在 **3.7.2 / 3.7.3 / 3.7.4 / 3.7.5 / 3.7.6 / 3.7.7** 实施包内走两级设计门禁。故本卡**不产出 lofi/hifi**，以规格 §7 决策点清单（Q1~Q9）承接"方向确认"，以规格全文承接"实施包的上游输入"（沿 WBS-3.1.7 / 3.2.1 / 3.3.1 / 3.4.1 / 3.5.1 / 3.6.1 同款免设计先例）。

**设计要点摘要（供快速表决）**

1. **一份规格覆盖两条 P0**（C-7.1 数据产品门户 / C-7.2 计量计费中心），拆为 **12 条业务行为**（6+6），每条带 2~4 条可判定验收标准（共 **46 条**——立卡段实测勘正，原记 45 为计数笔误）；
2. **门户 = 登录制浏览面**（§7 Q2）：平台注册主体登录即可浏览全部已上架产品（无审批），公开匿名浏览 = 非目标；浏览只读、复用目录服务同一数据面（不建第二事实源）；
3. **订单 = 合约发起的业务外壳**（§7 Q3）：状态随合约联动（生效→已完成 / 拒绝撤回→已关闭），不另设资金流；订购幂等沿 ADR-007；定价快照随单锁定（沿 C-4.1 行为 2 规则 3"发起与快照"）；
4. **评价 = 自建最小口径**（§7 Q4）：评价人 = 已完成有效交付的需方（防刷评负向必有）；1~5 分 + 可选文字；一人一评重复提交 = 更新；详情页均分只读展示；运营方隐藏留痕不删除——"对接质量评价机制"（WBS 3.7.4）无既有上游（目录域"评价/评分"grep 零出现，立卡时实证），由本规格落为最小口径；
5. **计量 = 只消费既有事件源**（B7）：网关放行事件（ADR-022 §2.6）+ 合约 V3 两表 + 交付记录 / 沙箱 / 导出（ADR-023/024/025 分工不双计）+ 模拟器零落库（ADR-021）；拒绝零计量（结构性，ADR-020 §2.4；引用节号规避 DB-51 误引——B8-3）；计量侧不改上游任何端点/表/码；
6. **计费依据 = 已生效合约 + 定价快照**（B9）：按次 = 事件数 × 次单价 / 包月 = 周期费（非事件级）/ 交易额分成 = **约定交易额 × 费率**（不采真实支付金额——§7 Q5 诚实边界，支付通道归 C-7.3）；计费可复算；快照变更不追溯已出账单；
7. **账单不可变 + 冲正更正**（B10 / §7 Q6）：自然月自动出账 + 运营方手动即时出账双轨；同合约同周期幂等防重；编号唯一终身不复用；生成后不可篡改，更正 = 更正单 / 红字冲正留痕（资金语义红线，章程 441/478）；
8. **对账 = 四方交叉验证 + fail-closed**（B11 / §7 Q7）：计数表 / 执行流水 / 计量流水 / 账单合计四方一致；**双向断言**（正向对账通过 + 账实不符必被报——AGENTS 行 74 硬约束 + 章程行 412 账单核对剧本双承载）；差异即冻结账单、人工复核留痕、不自动修数；对账剧本独立成卷（§7 Q1，沿章程行 723"账单核对"命名）；写法口径沿 DB-96 教训（业务语义钉死、实现细节两态可辨）；
9. **错误码预留 1011 段**（§7 Q8）：1000~1010 已占用，1011 Java + docs 双查实测零占用（立卡时留痕）；码值随实施包落定；
10. **沿承净承接落位**：ADR-022 行 100 次序观察项维持现状 + DB-88 维持挂起（§7 Q9 双表态入规格 §6）；3.3.4 Q6-A 推送划界沿用（B6）；章程行 723"ADR-009 计量流水"名实不符注记勘正（规格 §6-6，不回改章程示例）；前端 MainLayout 菜单计数联动预告（规格 §6-7，归 3.7.2/3.7.7）；本地 main 梢 2821993 收口批随本卡 PR 入库（链式先例）。
