**设计要点摘要（供快速表决）**：

1. **一条硬约束两条腿**：对账"正向通过 + 差异必报"必须都自动化（B11-2），当前七类差异中"多出明细"腿零覆盖 → W2 补齐；
2. **基准只做实施包内口径**：万级流水三读面 P95 ≤500ms；门户并发与网关 TPS 归 4.2.x（诚实边界写死）；
3. **DB-104 就地收口**：一处守卫 + 2 例，复用 `1000C0001`，不动端点形状；
4. **零改动面**：3.7.5 / 3.7.6 / 3.7.7 业务语义、前端界面、门禁配置、迁移、依赖、权限点、错误码。
