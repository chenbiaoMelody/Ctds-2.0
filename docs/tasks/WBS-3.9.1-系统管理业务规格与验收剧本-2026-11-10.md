## 一、范围与设计

- **做什么 / 不做什么**：见规格 `docs/specs/C-10.1-10.2-系统管理.md` §3（**8 条行为**）与 §4（非目标 12 项）；本卡不做设计类文件（免设计，理由见下）。
- **免设计声明（章程 2.6.2 免设计类）**：本卡为**纯文档类**任务——交付物即"规格 + 剧本"本身，**没有可设计的产品形态**（无界面、无服务、无数据模型）；RBAC 与三员分立 / 租户生命周期 / 监控运维集成 / 系统管理界面的设计分别在 **3.9.2 / 3.9.3 / 3.9.4 / 3.9.5** 实施包内走两级设计门禁。故本卡**不产出 lofi/hifi**，以规格 §7 决策点清单（Q1~Q9）承接"方向确认"，以规格全文承接"实施包的上游输入"（沿 WBS-3.1.7 / 3.2.1 / 3.3.1 / 3.4.1 / 3.5.1 / 3.6.1 / 3.7.1 / 3.8.1 同款免设计先例）。

**设计要点摘要（供快速表决）**

1. **一份规格覆盖两条 P0**（C-10.1 多租户与权限 / C-10.2 监控运维），拆为 **8 条业务行为**（4+4），每条带 3~4 条可判定验收标准（共 **32 条**）；
2. **三员分立 = 同一判定内核 + 三套映射**（B2）：系统管理员（业务配置 + 运维修）∥ 安全管理员（权限授予）∥ 审计管理员（审计读面）三类关键权限点两两不重叠，**不得新写第二套校验逻辑**；
3. **租户口径诚实**（B4 / Q1）：V1.0 租户 = **部署单元**（一客户一实例），业务隔离由既有**逻辑空间**承载，**不做库内 `tenant_id`**（与 C-2.1~2.3 既有裁决一致，避免 20+ 服务数据模型改造）；
4. **账号体系不虚构**（Q3）：立卡实测无用户表 / 无登录端点 / 无会话，前端登录为纯本地演示态——本卡明确 **V1.0 不做登录与令牌签发**，回答 ADR-005 行 37 的"签发归属待 3.9.1 澄清"，登记为部署期 / V1.5 立项；
5. **越权口径统一**（B3）：无权限 403 + `1000C0005`；归属不匹配 400 + `1000C0003`，与"对象不存在"同码同文（ADR-016 §2.6）；每次拒绝落 `rbac.check` DENIED 留痕；
6. **监控能力边界如实**（B5 / B7 / B8）：仅 `example-service` 暴露指标，其余服务"未接入"必须显式标注、不得显示 0；告警规则封闭两条（ADR-014 §3.3），外发通道未接（G-04 "待生效"），监控数据不持久化、无集群层指标（ADR-014 §4）；
7. **连接器健康度只消费不复制**（B6 / Q6）：复用既有 `/heartbeats` + `offline-after` 读时派生，规格只把"三态显式 / 阈值可配 / 运营可见 / 不改业务状态"定死；
8. **剧本四幕覆盖 WBS 三块**（Q8）：C-10.1 两幕（三员分立 / 部署域与空间隔离）+ C-10.2 两幕（监控读数与健康度 / 告警与处置），共 **38 步**（13 + 7 + 9 + 9）。
