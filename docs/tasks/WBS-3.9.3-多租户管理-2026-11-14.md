## 一、范围与设计

- **做什么 / 不做什么**：见 lofi §二（三个交付面）与 §四（边界）；行为清单 / 接口契约表 / 边界值与异常行为见 hifi §1~§4。
- **业务目标一句话**：把"这套平台是谁、什么版本、开着还是停了"从**部署文档里的口头约定**变成**平台自己能声明、能校验、能执行的东西**——系统管理员能打开"部署域信息"读到唯一事实；配置和实际对不上时平台明确报错而不是假装正常；退役态下业务请求被明确拒绝（503 + 专属码值）而数据与审计分毫不动、随时可恢复；每一次开通/升级/退役都有三证可查。
- **立卡实测的四个缺口**（本包存在理由，均有证据）：
  1. **部署域信息无读面**：平台没有任何端点可读出部署域标识/名称/版本/状态/schema 清单/服务清单；剧本 S2-1 与 S3-1/S3-2 操作路径标"由 3.9.3 实施卡回填"（剧本 `:75`/`:78`）。B9-1 目前只由部署文档人工核对。
  2. **退役态无拦截**：`RETIRED` 状态、503 + 1013 段码值、豁免面（审计读面与健康读数）在全仓**零实现**（`1013C0004`/`1013S0002` 未落定，1013 段现仅 RBAC 四码）；B9-R6 无承载。
  3. **配置一致性无 fail-closed**：schema 清单与实际数据源的一致性校验、启动失败机制不存在（B9-R4/B9-3）；全量一致性校验无部署脚本载体。
  4. **权限点 `platform.domain.read` 未登记未落地**：全仓代码/配置零命中（2026-11-14 实测），seed 无该点（`platform.sysadmin` 现 9 点不含）；边界 8 明文"3.9.3 落定，须在本域任务卡登记"（规格 `:213`）。

**设计要点摘要（供快速表决）**

1. **读面落 evidence-service**（Q1-A）：平台管理读面既有落点（`RbacGovernanceController` 先例），RBAC seed 与 1013 段同源，零新服务/零新路由；端点 `GET /api/v1/platform/domain`，`@RequirePermission("platform.domain.read")`。
2. **退役拦截 = `common/auth` 横切组件双适配**（Q2-A）：servlet 过滤器（11 业务服务）+ gateway WebFilter（统一入口，CHG §3 防绕过逐字对齐）；配置驱动（`ctds.domain.status`），**缺省 = `ACTIVE` 零行为**（既有演示链零影响）；豁免面 = 配置化路径模式（默认含 `/actuator/**`；evidence 增配审计读面与部署域读面）；拒绝 = 503 + `1013C0004`（"部署域已退役"）。
3. **配置 = 声明式 Spring 配置**（Q3-A）：`ctds.domain.*`（标识/名称/平台版本/生命周期状态/库 schema 清单/服务清单 + 变更单编号/操作人），由部署清单 env / 配置文件承载（Q10-A"部署清单/配置文件承载"原文）；不建租户表、不加 `tenant_id`、不做在线写面。
4. **fail-closed = evidence 启动校验**（Q6-A/B9-R4 原文口径）：持有读面的服务启动时校验自身数据源 schema ∈ 清单，不一致 → **启动失败**（S3-4 演示路径）；读面另返回"配置校验结论"字段（B9-1）；全量 schema/服务清单一致性 = **部署脚本扩展 + runbook**（B9-R4 部署期承载，Q14-A）。
5. **留痕三证不新增表**（Q5-A）：变更单（人工登记）+ 部署记录（runbook/脚本输出，含前后值）+ **启动审计事件**（`domain.lifecycle`，经既有 `AuditRecorder`，字段 = 变更单编号/操作人/时点/动作/版本与状态）；生命周期动作须配 `ctds.domain.change-order`/`operator` 才触发事件（B9-R3 登记义务）；不新增配置变更记录表（B9-R5 为"若新增"条件句，最小实现不新增）。
6. **权限点与码值登记齐**（Q4-A/边界 8）：`platform.domain.read` 授 `platform.sysadmin` 走 **V4 迁移**（V3 已应用不可改，checksum 红线）+ change_log 留痕；`1013C0004`（退役拒绝）/`1013S0002`（配置不一致）顺延落定并登记；`PermissionPointRegistryTest` 扩展纳入 V4。
