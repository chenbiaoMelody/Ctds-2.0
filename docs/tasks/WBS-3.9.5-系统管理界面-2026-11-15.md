## 一、范围与设计

- **做什么 / 不做什么**：见 lofi §1（W1~W10 / N1~N9）与 §4 界面说明书；行为清单 / 接口契约表 / 边界值与异常行为见 hifi §1~§5。
- **业务目标一句话**：把"平台管理员在界面上一处管系统"补齐——系统管理员在**监控读数页**读到四区块读数（未接入的服务如实标注"未接入"，绝不显示 0 或绿）、在**告警与处置页**看到要素齐备的告警列表并经唯一入口处置（确认/静默/升级）；**角色与权限页**让三员各看各的面（系统管理员看清单、安全管理员做授予收回、审计管理员查变更留痕）；**部署域信息页**如实呈现租户（部署域）配置与生命周期状态；同时清偿 **DB-128**（前端演示身份切到三员，"监管审计 + 连接器核验"两界面路恢复 200），并把连接器健康度**三态**（在线/离线/从未上报）在既有治理页显式呈现——"从未上报"不再冒充"离线"。
- **立卡实测的四个缺口**（本包存在理由，均有证据）：
  1. **系统管理三页面零承载**：全仓无租户（部署域）/角色权限/监控读数/告警列表页面（54 个 .vue 全量核对 + `grep platform/metrics|platform/alerts` 零命中）；两剧本 :11 界面入口均为"占位（待 3.9.5 落定）"（C-10.1 "角色与权限页 + 部署域信息页" / C-10.2 "监控读数组件页与告警列表页"）。
  2. **DB-128 界面身份未切三员**：`demoIdentity.ts` evidence/connector 两域运营档仍发 `admin`，而 jdbc 种子运行期 admin 已撤 `evidence.governance` 与 `connector.review` → 监管审计页与连接器核验面 403（C-8.2 V1.5 注记"界面路暂不可用"）；修复影响面 4 文件（`demoIdentity.ts` / `MainLayout.vue` / `router/index.ts` / 对应 spec）。
  3. **连接器健康三态前端未消费**：后端 `healthStatus` 三态字段已交付（3.9.4 加性），前端 `ConnectorRecord` 无此字段、"从未上报"按 `online=false` 显示为「离线」——B6-R1"三态显式、不得以空值代替"的最后一段缺口。
  4. **平台监控/部署域/rbac API 前端零消费 + vite proxy 缺键**：9 个后端端点零前端代码；vite proxy 无 `/api/v1/platform`、`/api/v1/rbac` 键（落兜底 `/api`→8080 example-service 错位）。

**设计要点摘要（供快速表决）**

1. **四页四菜单、扁平追加**（Q2-A）：「监控读数」「告警与处置」「角色与权限」「部署域」menuOrder 28~31，与两剧本 :11 占位口径一一对应；沿扁平菜单惯例不改造菜单机制；计数断言三处机械同步。
2. **界面 = 只读呈现 + 唯一写面为处置与授予收回**（两剧本 :9 前提"行为判定以服务接口为唯一事实源，界面为只读呈现"）：前端可触发写动作仅 ① 告警处置三动作（`platform.alert.handle`）② RBAC 授予/收回（`connector.review`，安全管理员面）；部署域生命周期零按钮（B9-R3 无在线 API）。
3. **三员视角机制承载三员分立演示**（Q3-A）：运营档新增"三员视角"下拉（系统管理员/安全管理员/审计管理员，默认系统管理员），rbac 域与 platform 新域头随视角——清单/授予收回/留痕三面各自可演示，S1-4 越权（系统管理员视角做授予→403）与 S2-7 处置写面双向界面可演；既有 evidence/connector 两域按 DB-128 修复口径固定映射（不随视角），保证"监管审计 + 连接器核验"两页在运营档恒 200。
4. **监控读数直渲染后端口径**（B5-R2 原文口径零重编）：四区块 = 服务存活 / JVM 堆内存与 GC / HTTP 速率 / 5xx 错误率与 P95；未接入行 `integrated=NOT_INTEGRATED` → 显式"未接入"标注 + note 原文，绝不显示 0/绿（B5-R4）；告警列表七要素 + `stateNote` 原文透传，封闭两规则固定入列。
5. **健康三态列替换**（Q4-A）：`healthStatus` 主展示（ONLINE→在线 / OFFLINE→离线 / NEVER_REPORTED→从未上报），既有 `online` 布尔列停止展示（后端加性字段零破坏，前端单列避免双读数）；概览条三数同步。
6. **权限点零新增、菜单 meta 用真实权限点**（边界 8 义务）：监控读数/告警菜单挂 `platform.monitor.read`、部署域菜单挂 `platform.domain.read`、角色与权限菜单挂 `connector.health.read`（其清单读面挂点，三员多视角语义在页内承载）；`hasPermission` 占位判定语义（有点仅 admin 放行）下可见性 = admin 演示档，与既有治理菜单一致；真实 key 标注为诚实口径（规格 :259 已注明前端菜单权限点与后端口径不完全一致属既有事实）。
7. **api 层沿 DB-41 横切惯例**：`api/platform.ts` 域工厂 `makeDomainJson` + URL 域文件单点 + `PlatformSourceGuard` 纪律锚；vite proxy 两键插在兜底 `/api` 之前（键序先行）。
