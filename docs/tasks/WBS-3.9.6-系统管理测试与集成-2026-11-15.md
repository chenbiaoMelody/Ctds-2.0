## 一、范围与设计

- **做什么 / 不做什么**：见 lofi §1（W1~W7 / N1~N8）；测试面契约与边界值见 hifi §1~§5。
- **业务目标一句话**：把"系统管理域已经建好"从**各包自证**升级为**域级收口证明**——RBAC 授予/收回写面从"源码文本断言"补齐为"真库真权限行为测试"，三员权限矩阵从"真机留痕"落成"自动化守卫"，规格唯一挂账口径条款 **B7-AC3 演算留档**在本包兑现（不兑现则该条 AC 不得记为通过），剧本补齐《自动化覆盖对照》与 S1-2 承载勘误，并在"监控栈未部署"的诚实前提下完成两剧本全链真机联调走查。
- **立卡实测的四个缺口**（本包存在理由，均有证据）：
  1. **RBAC 授予/收回写面零行为测试**（覆盖洼地）：`RbacPermissionService` 行覆盖 **8.1%**（3/37）、`RbacGovernanceController` **33.3%**（3/9）、`JdbcRbacStore` **8.1%**（3/37）（jacoco 2026-11-15 时点）；唯一测试类 `RbacGovernanceContractTest`（4 例）为纯源码文本结构断言，grant/revoke/roles/changes 四端点**零 HTTP 行为用例**——幂等、留痕、越权、变更单号校验全靠文本断言兜底；V5 seed（`V5__grant_monitor_permissions.sql`）**无任何测试引用**。
  2. **B7-AC3 演算留档未兑现**（规格唯一挂账口径条款 :156）：3.9.4 编码段明示"演算口径 = 剧本侧留档（编码段不构造流量）"（3.9.4 卡 :69），演算/构造留给联调——3.9.6 不兑现则该 AC 按"挂账不判定、不得记为通过"处理，域收口带债。
  3. **S1-2 承载缺口 + 剧本对照节缺失**：C-10.1 剧本 S1-2（:20）与操作路径表（:67）写"平台业务配置端点（3.9.4 落定）"，但 3.9.4 实际交付仅 metrics / alerts / alerts-actions 三端点，**"平台业务配置动作"无已交付写端点**（3.9.5 Q1-A 亦裁定无阈值编辑 UI）——联调前须勘误（Q4，PO 裁决）；C-10.1/C-10.2 两剧本均无《自动化覆盖对照》节（C-7.2×2 / C-8.1 / C-8.2 均有先例）。
  4. **联调面只有人工 + 三缺口悬置**：三员矩阵 14 格仅 3.9.5 真机实测留痕（`build-output/w395-precheck-data/precheck-summary.md:66-79`）未落代码；3.9.5 复审登记三项低风险测试缺口（copySilenceId / spanMethod / RbacView 空值拦截）"验收后如需再补"；监控栈 2.5.3 未立卡交付，本机无 Prometheus/Alertmanager（docker ps 实测）——C-10.2 联调只能按"监控栈未部署"诚实口径走查（fail-closed 呈现面本身即验证对象）。

**设计要点摘要（供快速表决）**

1. **两条腿分工沿 3.8.6 先例**：能进 CI 的进 CI（T1~T7 组件/集成测试），必须真机串链的用**演示链走查 + 演算脚本**（联调留痕，带 PASS 判定与 exit 码）；
2. **RBAC 行为测试直补覆盖洼地**（Q1-A）：MockMvc + Testcontainers 真库真迁移范式（沿 `DomainGovernanceIntegrationTest`），四端点正向 + 越权 403 + 幂等 + 留痕八列 + 变更单号校验，目标写面三类 ≥80%；
3. **演算腿不依赖监控栈服务器**（Q3-A）：两次采样各服务 `/actuator/prometheus` 真实输出，按规格 :156 PromQL 算式演算 5xx 占比，算式与取值留档——监控栈未部署不阻碍演算兑现，"演算非真机触发"如实标注；
4. **S1-2 勘误采"告警处置动作"承载**（Q4-A 建议）：系统管理员唯一在线管理写面 = 处置三动作（B8-R3），留痕四要素（B8-AC1）与 S1-2 预期结果"管理动作留痕"语义一致，业务判定零变更，PO 裁决；
5. **门禁判定面零改动**（Q2/Q8）：不扩 coreModules、不扩变异、不动 frontendE2E disabled（浏览器二进制供给归 2.5.x 部署基建）——达标口径靠"写面覆盖补齐 + 对照表 + 演算留档"三层承载，配置建议登记台账不实施；
6. **DB-129 不实施**（Q7-A）：服务层互斥守卫须先走规格/ADR 变更（新增 `platform.rbac.grant`），本卡复核登记 + 域收口呈报，测试暴露的现状行为（自我授予实际可成功与否）以红相 + 报告如实留痕。
